## 核心观点

1. **团队问题不是不努力，是努力方向没有形成合力** — 好的经验没法复制，差的方法没人纠正
2. **核心设计原则**：销售主管每天额外投入不超过30分钟做管理，所有动作通过微信群完成，每个动作有固定时间点和固定格式
3. **结构**：早报让每人知道"今天干什么" → 冲刺小时让每人"真的去做" → 晚报让每人看到"做得怎么样" → 点评让每人"被看见" → 排名让每人知道"我在哪里"

## 每日管理三板斧

### ☀️ 第一板斧：早上9:00 早报（2分钟/人）

**格式模板：**
```
【早报】姓名 + 日期
① 今日线上接待目标：____单
② 今日微信跟进客户：____人（列出名字）
③ 今日重点攻克客户：____（备注需求/卡点）
```

### 🔥 第二板斧：下午14:00-15:00 微信冲刺小时

- 14:00主管发："微信冲刺时间开始，今天小目标：每人至少主动触达5个客户"
- 这一小时：微信销售 > 线上接待（线上可设自动回复缓冲）
- 15:00每人报数："今天触达__人，意向客户__人，成交__单"

### 🌙 第三板斧：晚上20:00 晚报+点评（3分钟/人）

**晚报格式：**
```
【晚报】姓名 + 日期
① 线上接待：咨询__人，成交__单，成交额__元
② 微信销售：主动触达__人，成交__单，成交额__元
③ 新增加微：__人（来源：天猫/京东/抖音/其他）
④ 今日一句话总结：
```

**点评红线：**
- 永远不在群里批评个人，表扬在群里，批评私聊
- 点评要具体，不说"加油"，要说"你今天那个方法很好"
- 每天至少表扬1个人

## 客户分层ABC管理

| 分类 | 定义 | 跟进频率 |
|---|---|---|
| ★ A类 | 近期有明确购买意向，已咨询过产品/价格 | 每天触达1次 |
| ◆ B类 | 有兴趣但未明确需求，或之前买过未复购 | 每周2-3次 |
| ○ C类 | 新加微信好友，还未了解需求 | 每周触达1次 |

**微信备注格式**：`【A】张先生-天猫-Titleist TSR3一号木`

## 朋友圈发布节奏

| 时间 | 类型 | 内容 |
|---|---|---|
| 上午10:00 | 产品种草 | 客户好评截图 + 产品实拍 + 简短点评 |
| 下午14:00 | 专业内容 | 高尔夫知识/球杆对比/打球技巧 |
| 晚上19:00 | 生活/促销 | 生活分享/限时优惠/客户日常转发 |

**红线**：每天不超过3条；促销不超过1条/天；禁止纯图片无文字；必须加个人角度点评

## 激励机制

| 场景 | 激励方式 |
|---|---|
| 微信成交单笔≥500元 | 群里立刻"恭喜"表情包 + 一句话点评 |
| 单日成交≥3单 | 群里公开表扬 + 当天晚报重点分析 |
| 单笔大单≥2000元 | 群里发红包10-20元 + 要求分享成交过程 |
| 周微信销售额第一 | 周会公开表彰 + 红包50元 |
| 连续2周排名末位 | 主管单独谈话，了解困难 |
| 团队整体达成15%目标 | 全员额外奖励200-500元或团建 |

---

## CEO需要做的三件事

1. **开动会上给销售主管"立威"**：全员面前明确表态，销售主管全权负责，大家配合执行
2. **每周看一次周战报，私下给主管反馈**：不越级管理，但让主管知道"老板在看"
3. **月末亲自参与总复盘，兑现奖励承诺**：说到就要做到
