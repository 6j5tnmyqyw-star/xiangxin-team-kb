# 【祥新公司规则】审单·库房库存不足尽量整单转外发

> 生效日期：2026-05-25　发布人：邹祥书
> 适用范围：全店铺，顾客单笔订单含多件、我司库房库存不足以整单发出时的审单环节

## 一、规则

1. 顾客单笔下单 N 件，若库房可用库存 < N 件（无法整单从库房发出），审单时**尽量整单转外发**（第三方 / 品牌就近发货），不拆单。
2. **不默认**"一件库房发 + 一件外发"的拆法；顾客地址与品牌 / 供应商同城或临近的，**优先就近发货**，到货更快、更省运费。
3. 确实只能拆的（外发也无货 / 时效明显更差）→ **报备祥书后再定**。

## 二、原因

拆单会导致顾客分两次、不同时间收到包裹，体验差，并增加客诉与运费。

案例（2026-05-25）：顾客单笔拍 2 件、收货地址广州、品牌方也在广州；我司库房仅 1 件，系统默认拆单（1 件库房发 + 1 件外发）。审单驳回库房、整单转品牌就近发后，顾客次日两件同时收到。

## 三、执行职责（审单发货组，所有店铺统一）

1. **舒怡**（罗舒怡，采购兼审单）：审单核对库房可用库存 vs 下单件数，不足整单转外发
2. **阳阳**（罗姣阳，采销助理）：同上，配合外发渠道对接
3. **鹤子**（徐鹤）：同上
4. **九一**（袁桂平，库管）：库存核对；收到驳回的拆单及时停发、转外发

> 运营专员（嘉欣、荔枝、娜娜等）不直接审单发货，无需操作。

异常上报：外发也无货 / 时效明显更差 / 拿不准的 → 报备祥书后再定。

## 四、违反处理

因拆单造成顾客分次收货被客诉的，由当班审单人负责善后；问题登记在纠错日志（record_id `recvkCGGeGqQbc`）。
