# 供应商挂账对账 · 怎么让 AI 帮你做

> 给华华、海英看。比对两份 Excel——自家销售明细 + 供应商发来的挂账单——金额对得上的标绿、差在运费范围内的标黄、对不上或缺失的标红，两份文件都标，订单号上带批注。

## 二、对账前，先把这四个数说清楚

AI 不会猜，你少说一句它就得多问你一次。

1. **两边的金额列各叫什么**
   销售明细（吉客云导出）通常有两列：「应收合计」＝售价、「订单货品成本」＝成本价。
   供应商挂账单通常是「应收金额」，而且**多数供应商挂的是成本价，不是售价**。
   所以两列都要比，任一对上就算对上——这是这个技能的核心逻辑。

2. **运费阈值多少**
   默认 60 元，差额在这个数以内先按运费差异算黄色。哪个供应商不是这个数，你直接说。

3. **用什么当匹配键**
   默认：订单号里的日期 + 货品名称关键词。有物流单号也可以加进来。

4. **订单号长什么样**
   吉客云常见 `JY202604190024`，中间 8 位是日期。先抽几条给 AI 看，确认日期在哪一段。

表头不在第一行（上面有公司名、空行）的，先另存一份干净表，表头放第一行。

## 三、怎么开口

把两份 Excel 拖进对话，然后说：

```
帮我做供应商挂账对账。
销售明细：<文件名>，sheet 叫 XXX，订单号列「订单编号」，售价列「应收合计」，成本列「订单货品成本」，货品列「货品名称」
挂账单：<文件名>，sheet 叫 XXX，订单号列「订单编号」，金额列「应收金额」，货品列「货品名称」
运费阈值 60
```

它会先跟你确认上面那四个参数，确认完跑脚本，出两份文件：`<销售明细>_对账.xlsx`、`<挂账>_对账.xlsx`，并告诉你绿/黄/红各多少条。

**第一次跑之前，让它自检一次环境**（只需一次）：

```
检查一下这台机器能不能跑对账脚本，需要 python3 和 pandas、openpyxl
```

缺什么它会说，照装就行。

## 四、脚本跑不起来怎么办

技能里的 `scripts/reconcile.py` 要本机有 Python 环境。三种情况：

| 现象 | 原因 | 怎么处理 |
|---|---|---|
| 提示找不到 python3 / 命令不存在 | 电脑没装 Python | 让 WorkBuddy 帮你装，或找阿祥 |
| 提示 No module named pandas / openpyxl | 缺依赖 | `pip install pandas openpyxl` |
| 环境实在装不上 | 公司电脑限制 | **退一步让 AI 手工比**，但只适合 50 单以内：大额差异它找得准，几十块的运费差容易看花。结果只当第一遍粗筛，结论自己复核 |

手工比的说法：

```
这两份文件是对账用的，你按订单号逐条比金额，对上的、差 60 以内的、对不上的分三类列出来，不要下结论，只列差异。
```

## 五、红色怎么解释（内账口径，别硬套）

看到红色别急着说供应商算错，先按这个顺序排：

1. **售后退款、换货差价**——最高频的出错项，红色里优先找这两类
2. **成本价在系统里就是 0 或缺失**——2022 年及更早的老单、第三方代发、部分代购和服装类，系统成本不能直接信，不能当成「成本就是 0」
3. **运费还没出来**——有的供应商 T+3 天运费才给，对账日前 3 天的单，黄色或「无运费」先标待核，不默认 0；到付单尤其如此
4. **漏项**——赠品、定制费、印刷费、安装费、平台服务费、分期服务费、进项税点，漏一个就是差额
5. **拆单**——组装杆、多供应商拆单，成本和运费都要二次确认
6. **带「折」「清仓」「奖励价」的**——拉出来单独复核，不要和正价混着下结论

无对账单的运费：先按该供应商前几个月同款最高运费估，球杆/球/球包按品类区间估，系统里没有的标「待核」，**不要填 0**。

## 六、红线

- 只出对账表和差异清单。**不付款、不改吉客云、不把表发到供应商群或业务群**，你看完自己决定。
- 对话里不写客户手机、地址、身份证、银行卡。订单号留在 Excel 里。

## 七、海英这边：外账不是这个技能

上面这套只解决「供应商挂账 vs 销售明细」。外账那边的活（银行流水、发票、平台销售退货、交给财务公司）技能库里**还没有对应技能**，目前只能让 AI 做整理和粗对：

```
这是本月银行流水、电子回单、发票清单、平台销售和退货，帮我整理成交给财务公司的交接清单，标出缺件和金额对不上的地方。
```

能做：整理清单、按主体归类、列缺件、把两边都有的数算差额。
做不了：判断税务口径、核销、判断某张票能不能抵。

如果你一个月要干好几次，跟阿祥说一声，让他按你的实际口径单独做一个技能，比通用版准。
