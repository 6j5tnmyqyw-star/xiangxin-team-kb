## 核心信念

- **销售不是求人，是帮客户解决问题**
- 客户拒绝的不是你，是他还没有看到足够充分的理由说服自己
- 成交 = 信任 + 需求匹配 + 时机 + 临门一脚
- **主动权永远在你手里**——你决定节奏、频率和温度

## 销售漏斗

| 阶段 | 客户状态 | 你的目标 | 关键动作 |
|---|---|---|---|
| 触达 | 陌生/无感 | 引起注意 | 精准打招呼 |
| 兴趣 | 有点好奇 | 建立信任 | 提供价值内容 |
| 考虑 | 在比较 | 消除顾虑 | 剖析需求+方案 |
| 意向 | 想买但犹豫 | 推动决策 | 制造紧迫感 |
| 成交 | 准备下单 | 锁定订单 | 确认+跟单 |
| 复购 | 已成交 | 维护关系 | 定期触达+转介绍 |

## 客户四维剖析模型

| 维度 | 核心问题 | 判断依据 |
|---|---|---|
| 意向度 | 他真的想买吗？ | 主动问价、询问细节、问交期 |
| 决策权 | 他能拍板吗？ | 用"我们老板/采购"字眼 |
| 预算 | 他能花多少？ | 报价后反应、问题方向 |
| 紧迫度 | 他什么时候要？ | 问具体时间节点 |

## 微信跟进时间轴

| 时间节点 | 动作 | 注意 |
|---|---|---|
| 加微当天 | 发个性化第一条消息 | 不要发产品资料 |
| 第2-3天 | 发有价值的内容/行业资讯 | 不要推销 |
| 第4-5天 | 发相关案例或方案 | 有针对性，不群发 |
| 第7天 | 主动询问进度 | 语气轻松，不催 |
| 第14天 | 提供新信息/优惠激活 | 避免重复同一理由 |
| 第30天 | 评估级别，决定是否打电话 | 及时降级不浪费精力 |

**每条消息结构**：价值（先给有用信息）→ 关联（联系客户情况）→ 行动（问一个问题或引导动作）

## 打电话的触发信号

| 信号 | 含义 | 行动 |
|---|---|---|
| 连续3条只回"嗯/好的/了解" | 失去兴趣 | 打电话重建温度 |
| 说"再想想"超过1次 | 有隐性顾虑 | 打电话消除障碍 |
| 报完价48小时无回复 | 价格/方案有问题 | 打电话直接问感受 |
| 问了很多细节 | 高意向，快决策了 | 趁热打铁 |
| 发来竞品对比信息 | 正在货比三家 | 立即打电话，先沟通先赢 |

## 比价应对策略

**四种比价类型**：
- **预算型**（真没钱）→ 调整方案，阶段付款
- **试探型**（想要更低价）→ 坚守价值，提供额外增值
- **流程型**（公司要求3个报价）→ 帮走流程，成为首选项
- **真竞争型**（认真在选）→ 全面展示差异化，重点攻信任

**价值重构公式**：价格是现在付的钱，成本是整个使用周期真正花的钱 → 带客户算总账

**让步策略**：
- 让步要有条件："如果您这次能先付X%，我可以在[某项]上给您额外支持"
- 让步要小、要慢：第一次让5%，给成就感
- 不到万不得已不让价，先让其他条件（赠品/服务/交期/账期）

## 高频异议话术

| 异议 | 应对核心逻辑 |
|---|---|
| 太贵了 | 先问是跟谁比，再了解预算范围，找匹配方案 |
| 我再想想 | "通常是价格、方案疑虑、还是需要内部确认，您主要是哪方面？" |
| 先不急 | "大概什么时候会到那个阶段？我提前给您准备好资料" |
| 你们是小公司 | 强调深耕领域年限+具体案例，发资质/评价 |
| 我们自己做 | 问自研需要多少人力时间，引导"外包让内部聚焦核心业务" |
| 发资料给我看 | "您最关注哪方面——功能/价格/案例？发有针对性的" |

## AI辅助成交

**适合让AI帮忙的场景**：
- 不知道怎么回复客户的一段话 → 把对话粘贴给AI，让它出3-5条候选话术
- 要发跟进消息但没灵感 → "帮我写一条自然的跟进消息"
- 打电话前梳理思路 → "列一个通话框架"
- 遇到比价需要差异化分析 → "竞品是A，我们是B，帮我想差异化说法"

**问AI的正确姿势（背景+情况+目标+限制）**：
> "我是卖工业设备的，客户是制造业采购总监，上次报价后他说贵了15%，现在3天没回消息。我想发一条消息重新激活对话，不要显得太急，要自然，帮我写2个版本。"

## 成交后动作

- **24小时内**：发感谢消息，确认交付安排
- **交付后3天内**：主动问使用体验
- **成交后30天**：关心消息，不推销
- **成交后60天**：适时提转介绍
- **每季度**：发有价值的行业内容
