# 成品杆折算标准

> 公司统一口径：以后算成品杆的「杆头价」时，从整杆价中固定减掉杆身+握把费用。  
> 本标准供 **销售、采购、财务** 共同查阅与执行。

## 一、适用范围

- 仅适用于 **成品杆**（整杆）折算杆头价的场景。
- 销售报价、采购核价、财务成本/对账等涉及「从整杆价拆出杆头价」时，一律按本标准执行。
- 非成品杆（单独卖杆头 / 单独卖杆身 / 单独卖握把）不适用本折算。

## 二、折算金额（固定）

| 项目 | 金额（元） |
|---|---|
| 杆身 | 150 |
| 握把 | 50 |
| **合计（杆身+握把）** | **200** |

## 三、计算方式

以后成品杆算杆头价时：

```
杆头价 = 整杆价 − 200
```

说明：固定减掉杆身 150 + 握把 50，合计减 200；不按实际杆身/握把进货价逐笔变动（除非阿祥另行修订本标准）。

### 示例

- 整杆成交价 / 采购价为 1200 元 → 杆头价按 **1000** 元计（1200 − 200）。
- 整杆价为 800 元 → 杆头价按 **600** 元计（800 − 200）。

## 四、同步对象

本标准为公司知识，须同步并执行的岗位：

1. **销售**（含客服销售）：报价、谈价、拆价说明时按此口径。
2. **采购**：核价、对账、成本拆分时按此口径。
3. **财务**：成本核算、利润拆分、相关对账时按此口径。
