## 〇、吉客云是什么 · 在祥新的定位

吉客云 = **OMS + ERP + WMS 一体**的电商 ERP（杭州，jackyun.com）。祥新用它管**全店铺订单 + 库存 + 采购 + 售后 + 财务对账**，是公司销售/库存数据的**权威源**。

祥新业务模型是**撮合分销**（自有库存 30-40% 走仓库发货 + 三方代发 50-60% 走代销发货），所以吉客云里**销售发货分两条线**、**代销对账结算**是核心高频活。

**通用操作技巧**（所有页面通用，先记这条）：
- 左上角搜索框输**菜单名/拼音首字母/菜单代码数字**直达功能（如"销售单审核"=代码 `102`，"虚拟发货"=`107`，"仓库发货"=`106`，"新建销售单"=`100`，"补偿退款单查询"=`182`，"售后设置"=`188`）。
- 表格：右键"复制选中单元格"可片选复制；按住 `Alt` 点数值单元格=求和/平均/最值；列可自定义/配背景色；查询条件可存模板。
- 绝大多数单据走 **开单 → 递交 → 审核** 三步流，每步都能在"设置"里勾**自动递交/自动审核**跳过（这是 AI 自动化的关键开关）。

## 二、核心日常流程（祥新视角）

### 1. 货品档案（一切的基础）

- **新建货品**（货品>货品档案>货品查询>新增）：必填=分类/名称/基础单位/货主（默认自营）。可设规格（颜色/尺码组合）、警戒库存上下限、计价方式（默认移动加权平均）。保存后再加**存放仓库、供应商报价、销售价格、图文**。三种建法：单建 / 复制当前货品 / **Excel 批量导入**（标红字段必填）。
- 🔑 **货品编号/条码 = 平台匹配的命脉**：导入网店商品时 `网店商品编码→货品编号`、`网店规格编码→货品条码`。自动匹配优先级：**货品条码 > 辅助条码 > 货品编号**。条码乱 = 订单转审核时"无效货品"卡单。
- **组合装**（新建组合装）：虚拟套餐，库存按子件可用量按比例算（取最小）。录分摊价→算分摊比例（用于拆单时金额分摊到货品）。实际库存里**没有组合装实体**。
- **货品调价**（货品调价）：调价申请 → 递交 → 审核 → 查询，价目页看最新价。可**智能调价策略**（参考价 ± 系数批量算）+ 自动递交/审核。价格类型最多 21 个（半价/最高/最低/内部/零售/批发/会员…可自定义）。

### 2. 采购（补货回血）

- **采购开单**（采购>采购订单>采购开单）：选供应商→货品→数量/含税金额/预计到货日。有供应商报价会自动带价；最近采购价**涨红降绿**提醒。可引用历史采购单/采购申请单/生产BOM 快速建单。流程：开单→递交→审核→（转入库申请），可设跳过简化。
- **智能采购**（采购订单>智能采购）：按库存数据算该补啥补多少。`缺货数量=库存(可用)+在途-订购量`，`建议采购量=缺货+备货量`。最多 20 条策略（按部门/业务范围），可设销量取数天数、排除渠道、取整规则。**任务式执行**（量大要等），执行完查结果→转单。→ 这是 [[project_sanfang_kpi_skill]]/补货类 AI 的系统抓手。
- **采购到货**：按采购单/采购申请/货品到货，生成入库申请单→入库后减采购在途。可设自动到货。
- **采购结算**（采购模块↔财务桥梁）：三类=采购应付/采购费用/采购预付。**采购订单不生成应付，采购结算才是供应商账款的实际依据**（吸收订单与实付的差异）。
- **采购退货**：开退货单→递交审核→出库→退货结算（冲减应付）。

### 3. 库存（看得准才补得对）

- **总库存查询**（库存>货品库存>总库存查询，看全仓自营库存）。关键字段（也是补货/清仓判断的依据）：
  - `库存数量`(含已占用未发) / `可用库存`(可自由支配) / `锁定待发`(销售单审核未发 or 出库申请占用)
  - `采购在途/调拨在途/生产在途/退货在途`
  - `近7天销量/近30天销量/总销量`(不含今天) / `支撑天数=库存数量÷(近30天销量/30)` ← **清库存/补货核心指标**
  - `最近采购价/当前成本价/库存金额`（⚠️总库存的当前成本价跨币种时可能不准）
- **库存量警戒**：最低/最高库存预警、有效期预警、采购到货逾期预警（T-1）。
- **货品调拨**（仓间转库存）：同价调拨(纯转移) / 异价调拨(像内部销售可公司间结算)。调拨单审核→自动生成出库申请→出库后生成入库申请→入库完成才算完。支持智能调拨/一键调拨/Excel 导入。撤回会删出库申请+取消发货单。
- **盘点**（在「仓储」模块）：盘点开单（13 种范围：全仓/盈亏重盘/动销货品/零负库存/差异盘/扫描/选货品货位/Excel…，可盲盘）→ 盘点录入（`盈亏=盘点数-库存数`自动算，扫码/Excel）→ 盘点审核。支持多人盘点合并。

### 4. 销售下单 → 发货（撮合分销的两条线）

**主链路**：网店订单下载 → 网店订单转审核 → 销售单审核 → **销售发货** → 物流跟踪

- **网店订单下载**（销售>网店订单>网店订单下载）：先在"渠道列表"建店铺→此页**授权**（订购授权/直接授权/参数型授权；淘系京东拼多多等要先去平台服务市场用主账号订购，1年期，费用走"订购/续费>平台订购返款"返还）→下载订单。**网店配置**四块：订单下载（开自动）、转入审核（开自动）、物流上传、库存同步。设店铺授权到期提醒（默认<7天）。
- **网店商品下载 + 匹配**：把平台商品拉下来跟系统货品建匹配关系，否则订单转审核报"无效货品"。匹配作废规则：编码/条码任一改动→匹配关系作废。
- **网店订单转审核**：待发货网店订单转成系统销售单（一般开自动转）。含无效货品的不自动转，停在此页，右键"匹配货品"（自动/手工）。
- **销售单审核**（代码 `102`）：可编辑/拆分/合并/同步平台信息→审核。审核即**锁定待发库存**。`处理时间`=当前/发货时间 − 付款/下单时间（时效考核依据）。
- **销售发货三选一**：
  - **仓库发货**（代码 `106`，自营 30-40%）：递交仓库→仓储作业（配货/验货/打包/发货）→"发货在途"→物流跟踪。支持分批发货、预约物流单号。
  - **虚拟发货**（代码 `107`）：纯虚拟物品人工点"直接发货"完成，可设自动。
  - **代销发货**（代码 `144`，三方代发 50-60%，**祥新核心**）：把订单递交给供应商发货。两种方式：①直接递交**吉链供应商**（系统对接）②**导出 Excel 给供应商**人工发。可设自动递交吉链。完成发货时若填了物流单+开了同步→自动回传物流到店铺。

- **代销对账结算**（销售>销售结算>代销对账结算，代发的钱货核对）：
  1. 分销商按供应商+账期筛订单 → **一键下载供应商账单**
  2. 三栏核对：货款金额 vs 货款金额(供应商)、邮资 vs 邮资(供应商)、订单金额 vs 订单金额(供应商)
  3. 核对无误→确认账单（⚠️已确认暂不支持驳回重确认，要核准再确认）
  4. 确认后→"采购待结算"转采购结算→"采购结算审核"（可设自动）→"付款开单"向供应商付款
  - 可在"采购流程配置"开自动结算 + 采购开单/费用开单设自动递交审核，实现后续单据全自动。

### 5. 售后（服务模块，代码区 177/182/188）

**网店售后单处理**（下载平台退换货/退款单→转审核为系统售后单）：
- 退款→**补偿退款单**；退货→**退换补货单**；换货→退换补货单。建议开自动下载+自动转审核。
- "售后设置"(代码 `188`)：一堆开关——组合装自动拆子件、退换单默认收货仓、网店售后转审核自动合并/匹配赠品、退换审核后自动"同意退货"回传平台、补偿退款审核后自动"同意退款"(目前仅淘系AG)等。

三类售后单：
- **退换补货单**（退货/换货/补发，可一单混合）：新建→审核→退货等待(仓库收货入库)→结算→查询。结算类型=先入库后结算/先结算后入库；补发类型=先入库后补发/先补发后入库。结算后生成"售后退货"负数订单冲销售额。大促可 **Excel 批量导入**（含拒收件按物流单整单退）。
- **补偿退款单**（好评返现/破损补偿，货没问题只退钱，代码查询`182`）：新建→审核→支付→查询。结算方式=网店平台退款/转账支付/转客户账户余额。
- **错发漏发单**：错发漏发处理 = 先"库存修正"（生成盘点/出入库单修库存）→后"错漏处理"（按处理方式生成退换补货单/补偿退款单），两步顺序不可逆。

### 6. 财务对账（撮合分销的对账压力大）

**平台账单线**（资金>账单管理）：
- **账单下载**：T+1（今天账单明天才能下）。先在"结算账户档案"开启对账+**授权**（已支持支付宝/微信/拼多多/京东/工行；京东要发资料到 jdopen@jd.com 周三开通；银行只有工行/招行可银企直联）。可设每日凌晨自动下载。不支持的平台用 Excel 模板导入。
- **账单审核**：按"解析规则"自动给账单打类型/收支项目/客户→审核（审核后不可改）。可拆分账单。
- **销售对账**（资金>销售收款账单>销售对账）：拿实收账单核销售订单。自动对账（按网店订单号/支付单号匹配，后台异步）→ 三种结果：完全对上(生成对账单)/金额差异/单据缺失。差异和缺失走**手动对账**（可一对多、正负互抵、记差异原因+收支项目）。无账单的订单（取消产生售后的）走"无账单销售对账"。

**往来账款线**（账款模块）：
- **应收/应付单**：业务单据结算后自动生成；也可手工创建。保存即进"应收应付余额表"，审核后才能核销。
- **账款报表**：现金银行日记账、结算账户余额表、应收应付余额表、账龄分析表、客户/供应商往来对账单、核销明细表。→ 经营分析/现金流可直接取这里（呼应 [[project_financial_baseline_2026q1]]）。

### 7. 报表 / 数据（统计模块，决策驾驶舱）

祥新最该常看的报表：
- **进销存报表**（库存>进销存报表，T-1）：每货品的采购入库/销售出库/销售订单/库存结余 + 15/30/60/90天销量。清库存看这个。
- **库存台账**（实时）：期初/收入/发出/结存。**呆滞库存**：X天未动销且正库存→呆滞天数。
- **货品分析-畅销/滞销**：按销量阈值筛，给销量/日均/销售额/支撑天数 → 优化采购+配货。
- **销售日报表/月报表**：本日新增/取消/收款/发货/退货/毛利/营业额（`营业额=新增−取消−售后退款−仅退款`），每列都标了"如何对账"。
- **决策驾驶舱**：销售分析（销售额/笔单价/48h发货率/毛利环比）、库存量预警（缺货/低库存/呆滞/即将超期）、采购分析、售后率分析（退货率/售后率/各渠道占比）。多为 T-1，注意看"更新时间"。

### 8. 系统管理（管理员）

- **组织架构**：一个会员号=虚拟集团，下设多公司（祥新4主体：深圳/廊坊/长沙/新化），公司间可相互结算+权限隔离。是绩效/统计/结算/权限的维度。
- **权限角色**：三维权限——功能权限(菜单/按钮)、数据权限(按仓库/渠道/供应商/公司隔离数据)、字段权限(藏敏感字段如成本价/毛利/手机/供应商)。账号多角色取并集。
- **员工档案**：工号/姓名/手机即登录账号；开通登录权限才占用户数；可重置密码/强制下线/Excel 批量导入。

### 🔴 重大发现：吉客云有开放平台 API

「系统集成 > 数据同步中心 > 系统授权管理」里明确：**吉客云开放平台有 Appkey/Secret，对接方式仅支持 API**，且有完整"业务接口查询"+接口文档（例：销货出库拆聚查询、`tradeStatus=9090`=已完成、`pageSize/pageIndex` 分页、按创建/审核时间/店铺id 筛单）。

**意味着**：将来 AI 读吉客云的订单/库存/对账/报表数据，**可以走官方 API 直连，而不是浏览器抓取**——更稳、更快、能定时。这是把吉客云接进 AI 工作流的最大杠杆。
→ **下一步**：找祥书在吉客云开放平台申请 Appkey/Secret（走环境变量，铁律6），AI 封装一个 jackyun-api 调用层，现有 [[07-AI协作/skills/jackyun-inventory-weekly/SKILL|jackyun-inventory-weekly]]、库存/经营分析类 skill 全可升级成 API 版。

### 三个最值得做成 skill 的点

1. **🥇 代销对账结算自动化**（撮合分销 50-60% 代发的核心痛点）
   - 现状：人工逐供应商下载账单→三栏(货款/邮资/订单金额)核对→确认→转采购结算→付款，量大且重复。
   - AI 可接：下载供应商账单 → 自动三栏比对 + 标差异（对得上/差邮资/对不上，像 [[07-AI协作/skills/supplier-reconciliation/SKILL|supplier-reconciliation]] 的三色对账）→ 出待确认清单给人核 → 人点确认。对账逻辑明确、规则化，最适合 AI。

2. **🥈 经营数据/报表自动拉取 + 分析**（已部分有，可 API 化深化）
   - 进销存/畅滞销/呆滞库存/销售日报/库存台账/账款余额全是结构化报表，API 直连后可每日定时拉 → 出经营分析/清库存建议/现金流视图，喂给运营决策。
   - 已有 [[07-AI协作/skills/jackyun-inventory-weekly/SKILL|jackyun-inventory-weekly]]（库存周报）、[[07-AI协作/skills/xiangxin-jingying-analysis/SKILL|xiangxin-jingying-analysis]]（经营分析）、[[07-AI协作/skills/xiangxin-replenish-advisor/SKILL|xiangxin-replenish-advisor]]（补货建议）——都可从"读本地导出 csv"升级成"API 直连吉客云"。

3. **🥉 智能采购/补货策略联动**
   - 系统自带智能采购策略（缺货+备货算建议采购量）。AI 可调策略参数、读执行结果、按动销+支撑天数生成补货单建议 → 呼应 2026 北极星清库存 [[project_2026_north_star]]（哪些该清、哪些该补一眼清）。

**其他可自动化的小点**：网店订单转审核的无效货品匹配（维护匹配规则）、平台账单自动下载+解析+销售对账（差异单挑出来给人）、售后单自动下载转审核（已是系统功能，AI 做异常兜底）。
