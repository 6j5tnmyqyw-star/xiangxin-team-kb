# 【祥新公司规则】品牌限价/禁活动 · 活动报名前置校验 SOP

> 生效日期：2026-05-30　发布人：邹祥书
> 适用范围：全店铺，任何报名/触发平台优惠的商品活动环节
> 起因：2026-05-21 魔镜品牌方反馈，店铺商品违规参与平台优惠活动，与"不参加任何优惠活动"要求不符，险被罚款。这个坑不能再踩第二次。
> 一句话：**活动报名前先过品牌方红线，禁报商品先挑出来，别让平台优惠误带飞。**

## 一、适用范围

- **渠道**：天猫倍视能旗舰店 / 京东倍视能旗舰店 / 京东祥新运动旗舰店 / 抖店
- **动作**：所有商家自主报名的平台活动（聚划算、淘抢购、官方营销节点、品牌日、大促）+ 系统/平台自动卷入的优惠（满减、券池、限时秒杀、跨店凑单）
- **对象**：所有受品牌方"限价"或"禁活动"约束的商品

## 三、商品打标机制（前置校验的基础）

受约束商品必须在以下三处同步打标，活动报名前才能一键过滤：

1. **天猫/京东商品后台**：商品标签里挂"禁优惠" / "限价" 标
2. **吉客云商品资料**：商品备注栏写明"禁优惠：品牌方要求 + 日期"
3. **飞书 Base「品牌限价商品清单」**（待罗舒怡牵头建表）：字段含 商品 ID / 品牌 / 约束类型 / 最近核对日 / 责任运营，权威源以此为准

## 四、活动报名前 4 步必检（每次都走一遍）

1. **过红线清单**：打开「品牌限价商品清单」Base，过滤本次活动涉及的品牌，把禁报商品挑出来
2. **核对当下规则**：本次活动涉及的品牌方，最近 30 天有无新规则下来。不确定 → 找采购对接人或品牌方确认，得到肯定答复才报
3. **后台勾选时排除**：在活动报名页面，禁报商品逐个取消勾选，**留截图存证**（操作时间 + 商品列表 + 勾选状态）
4. **二人复核**：报名后由非本人复核一次（运营 A 报 → 运营 B 抽查），异常当场撤回

## 五、平台自动优惠的应对（特别注意）

平台有些优惠是商品被自动卷入的（满减、券池、限时秒杀、跨店凑单）——**报名后 24h 内必须复查**：

- 进商品后台「营销活动」页，逐个检查受约束商品当前生效的活动
- 误入的优惠立即取消 / 移出活动池
- 已经开始取消不掉的，立即同步品牌方说明 + 道歉 + 留证据

## 六、见违规必停（异常处理）

一旦发现已经违规参与了禁报活动：

1. **立即取消违规活动**：第一时间通知店铺负责人取消违规商品的活动参与，确认商品价格恢复至品牌方要求的日常定价
2. **同步品牌方致歉**：跟品牌对接人说明误操作原因，告知已完成取消的处理结果，争取不上罚单
3. **登记纠错日志 Base**：录入「Claude 纠错日志」+「公司问题登记表」
4. **48h 内提交复盘**：责任运营写明"为什么没拦住"，迭代本 SOP 对应条款
