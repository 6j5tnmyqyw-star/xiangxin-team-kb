# 生意参谋市场行情 一键导出 CSV

> 配套数据产物：[[2026-05-21-0933-生意参谋球包类目商品榜-喜力克斯]]。同类浏览器抓取工具：[[2026-05-13-0717-淘宝客服聊天记录抓取插件需求]]。

## 它解决什么
生意参谋（sycm.taobao.com）有反爬：程序去刷新 / 自动翻页 / 直接打接口 → 弹扫码验证（`bixi.alicdn.com/punish/...`）。
本脚本反过来——**只读你眼前已经加载好的页面**，不发请求、不刷新、不导航，风控碰不到。你自己手动翻页，每页点一下按钮导出 20 条。

## 适用页面
生意参谋 → 市场 → 市场排行（URL 含 `market_rank`），标准 Ant Design 榜单表格，每页 20 条。

## 脚本（控制台 / 油猴 两用）

```javascript
// ==UserScript==
// @name         生意参谋市场行情导出
// @namespace    xiangxin
// @version      1.0
// @match        https://sycm.taobao.com/mc/free/market_rank*
// @grant        none
// ==/UserScript==
(function () {
  const abs = u => !u ? '' : (u.startsWith('//') ? 'https:' + u : u);
  function grab() {
    const rows = {};
    // 同一行在主表 + 固定列副本各出现一次（data-row-key 相同），取 td 最多的那行 = 含全部列
    document.querySelectorAll('tr[data-row-key]').forEach(tr => {
      const k = tr.getAttribute('data-row-key');
      const n = tr.querySelectorAll('td').length;
      if (!rows[k] || n > rows[k].n) rows[k] = { tr, n };
    });
    const data = [];
    Object.values(rows).forEach(({ tr }) => {
      const a = tr.querySelector('a.goodsImg');
      if (!a) return;                       // 只要商品行
      const href = abs(a.getAttribute('href'));
      const id = (href.match(/[?&]id=(\d+)/) || [])[1] || '';
      const title = (a.getAttribute('title') || (tr.querySelector('.goodsName a') || {}).innerText || '').trim();
      const img = a.querySelector('img');
      const thumb = abs(img ? img.getAttribute('src') : '');
      const big = thumb.replace(/_\d+x\d+(\.[a-zA-Z]+)?$/, '');   // 去尺寸后缀还原大图
      const rank = ((tr.querySelector('.current-rank') || {}).innerText || '').trim();
      const trend = ((tr.querySelector('.last-rank') || {}).innerText || '').trim();
      const cells = [...tr.querySelectorAll('td')].map(td => td.innerText.replace(/\s+/g, ' ').trim());
      data.push({ rank, trend, id, title, href, big, thumb, cells: cells.join(' | ') });
    });
    return data;
  }
  function download() {
    const data = grab();
    if (!data.length) { alert('没抓到商品行，确认在市场排行榜单页且表格已加载完'); return; }
    const page = ((document.querySelector('.ant-pagination-item-active') || {}).innerText || '').trim();
    const esc = v => { v = (v == null ? '' : '' + v); return /[",\n]/.test(v) ? '"' + v.replace(/"/g, '""') + '"' : v; };
    const head = ['页码', '排名', '升降', '商品ID', '标题', '商品链接', '主图原图', '主图缩略', '全部单元格'];
    const lines = [head.join(',')];
    data.forEach(r => lines.push([page, r.rank, r.trend, r.id, r.title, r.href, r.big, r.thumb, r.cells].map(esc).join(',')));
    const csv = '﻿' + lines.join('\n');   // BOM，防 Excel 中文乱码
    const t = new Date(), p = n => ('' + n).padStart(2, '0');
    const stamp = `${t.getFullYear()}${p(t.getMonth()+1)}${p(t.getDate())}_${p(t.getHours())}${p(t.getMinutes())}${p(t.getSeconds())}`;
    const a = document.createElement('a');
    a.href = URL.createObjectURL(new Blob([csv], { type: 'text/csv;charset=utf-8' }));
    a.download = `生意参谋市场行情_第${page || '?'}页_${stamp}.csv`;
    document.body.appendChild(a); a.click(); a.remove();
    console.log('✅ 导出', data.length, '条；表头供参考：', [...document.querySelectorAll('.ant-table-thead th')].map(th => th.innerText.trim()).filter(Boolean));
  }
  const btn = document.createElement('button');
  btn.textContent = '⬇ 导出本页';
  btn.style.cssText = 'position:fixed;right:24px;bottom:90px;z-index:99999;padding:10px 16px;background:#3d5eff;color:#fff;border:0;border-radius:8px;font:14px/1 sans-serif;cursor:pointer;box-shadow:0 2px 10px rgba(0,0,0,.25)';
  btn.onclick = download;
  document.body.appendChild(btn);
})();
```

## 两种用法

### A. 临时跑一次（零安装）
1. 在榜单页按 `F12` → `Console`
2. 整段粘贴 → 回车
3. 右下角出现蓝色「⬇ 导出本页」按钮，点它下载当前页 CSV

### B. 长期常驻（推荐）
1. Chrome 装 Tampermonkey（油猴）扩展
2. 油猴 → 添加新脚本 → 整段粘贴 → 保存
3. 以后每次进市场排行页，右下角自动出现按钮，翻一页点一下

## CSV 字段
排名 / 升降名次 / 商品ID / 标题 / 商品链接 / 主图原图URL / 主图缩略URL / **全部单元格**（该行所有列文本，店铺名 + 各项指标都在这，用 ` | ` 分隔，防漏数据）。

## 待校准
- 指标列（交易指数 / 搜索人气等）目前先塞在「全部单元格」里没拆。跑一次把导出的 CSV 或控制台打印的表头发给 AI，即可把每个指标拆成独立列。
- 店铺名同理，确认 DOM class 后可单列。

## 反爬注意
- **翻页务必手动点**，别让任何脚本自动翻 / 自动刷新。
- 弹扫码验证就自己扫一下过。
- 多页：每页点一次会下多个 CSV，攒一起交给 AI 本地合并 + 分析。
