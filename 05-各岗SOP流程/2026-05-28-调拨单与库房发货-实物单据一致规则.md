# 调拨单与库房发货·实物单据一致规则

> 背景：5/13 调拨单（CRK202605130030）做的是「整套礼盒入库」，但实际只调了测距仪+配件（发到了办公室），礼盒留在原仓未发。系统因此显示「有礼盒有测距仪」，实际只有测距仪没礼盒，导致后续审单发货时卡住、临时补救。固化以下规则，避免再发生。

## 一、调拨制单：单据 = 实物，做了什么就录什么

1. **实际调拨什么、调多少，单据就录什么、录多少。** 严禁"按整套 / 按订单 / 按系统建议"想当然录入。
2. **套装类（含礼盒 / 赠品 / 配件，如 FastDeer C2 礼盒装）拆开调拨时，测距仪、礼盒、配件要分别如实记录**，不能整套一笔带过。哪些发出、哪些留库，单据上要分得清。
3. 调拨入库后，制单人**当场核对系统数量与实物数量一致**，再确认入库，不留"系统已入、实物没到"的差。

## 二、实物与单据分离时，必须同步告知

- 出现"配件先发、礼盒 / 主件留库"这类**拆分发货**时，制单人第一时间在**三方发货群**告知采购 + 审单发货组：哪些物到了、哪些没到。**不能默默操作**，否则发货时才发现，已经晚了。

## 三、库房发货前核对

- 审单 / 发货前，库房对照系统库存**核实实物**（尤其礼盒装、套装）。
- 系统显示有、实物找不到时，**立即在三方发货群上报，查清再发**，严禁"系统有就当有"直接发出。

## 四、发办公室 / 拍视频用的样品，按整套套装发

- 发到办公室给拍视频用的，多半是礼盒套装这类。**拍视频要完整呈现，所以默认按整套发过去（礼盒 + 测距仪 + 配件全套），不要只发配件、把礼盒留库。**
- 这次问题就是反例：只把配件发到了办公室，礼盒留在原仓，既造成系统不符、又让拍视频拿不到整套。涉及拍视频样品的调拨/发货，制单人和库房都按整套走。

## 红线

1. **单据必须等于实物**——宁可慢一点，也不做"想当然"的整套入库。
2. **库存不符马上报**——不擅自发货、不擅自合并凑单。
3. **拍视频样品按整套发**——发办公室的礼盒套装别拆，整套发。
