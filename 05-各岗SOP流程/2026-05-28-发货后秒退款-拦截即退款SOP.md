# 发货后顾客秒申请退款 —— 拦截成功即退款 SOP

> 适用对象：客服销售、库房、库管、采购/助理（重点）
> 发布：2026-05-28　负责人：邹祥书
> 背景：发货后顾客货还没收到就申请退款，我们要做拦截。过去拦截成功了不直接退款，非等货退回仓库才退，售后时效被拉长，影响店铺体验分。**核心变化：拦截成功 = 立即退款，不等实物退回。**

## 一句话原则

**货未到就退款的单，第一时间拦截；拦截一旦成功，立刻退款，绝不等货退回仓库。** 全程走「三方发货群」话题闭环。

## 一、自营 / 库房发货

1. 客服发现顾客货未收到就申请退款 → 立刻在「三方发货群」开话题 @库房（彭彭 / 阿娟 / 九一），说明订单要拦截。
2. 库房收到马上拦截（拦快递 / 召回包裹）。
3. **拦截成功 → 库房在话题回复"已拦截" → 客服立即给顾客退款，不等货退回仓库。**
4. 拦截失败（已签收 / 拦不住）→ 在话题说明，转正常退货流程，等货回仓再退。

> 旧做法（等货退回仓库才退）作废。拦住了就是货回得来，没必要让顾客和店铺时效一起等。

## 二、第三方发货

1. 客服发现问题 → 在「三方发货群」开话题 @助理（顺位：罗姣阳 → 罗舒怡 → 徐鹤，谁忙不过来在话题里 @ 下一位），请助理向第三方供应商安排拦截。
2. 助理联系第三方拦截。
3. **拦截成功 → 助理在话题回复"已拦截" → 客服立即操作退款。**
4. 拦截失败 → 在话题说明，转正常退货流程。

## 红线

1. **拦截成功即退款**——任何情况下不再等实物退回仓库才退款。
2. **第一时间拦截**——客服看到"货未收到就退款"的单，先拦再说，越快拦截成功率越高。
3. **话题闭环**——拦截走「三方发货群」一事一话题，拦成 / 拦不住都要在话题里给明确结论，不挂着。
