# 销冠话术库 · 凌晨

> 公司销冠凌晨的真实销售话术，按「客户常见说法 → 应对策略 → 可发客户话术」组织。客服副驾起草回复时会自动检索命中的场景注入。话术按当前产品/客户口吻改一下即可发。
> ⚠️ 平台订单(天猫/京东/淘宝)退款、退差价一律走原路退回(客服红线1)。本库「退单挽留」指的是成交前/未走退款流程时的挽留话术，不是答应私下退款。

## 议价砍价 · 客户嫌贵、要便宜、压价

【客户常见说法】太贵了 / 能不能便宜点 / 优惠点 / 便宜点 / 降价 / 少点 / 抹个零 / 价格高 / 贵了 / 再低点 / 多少能成 / 给个底价 / 实价多少 / 最低多少 / 划不划算 / 还能少吗 / 给个最低价

【应对策略 · 销冠心法】
- 硬价格 + 软态度：报价干脆给数字；拒绝还价时态度一定软（"真的抱歉哈""您是老客户"）。
- 守价只给客观理由，绝不说"我不愿降"：成本涨 / 这是批发价 / 再低出不了库 / 再低就平出了。
- 不被客户带偏：客户拿低价截图、直接转账逼单，先核实、守住自己的节奏，别一慌就降。
- 实在要让步，给"台阶"而不是直接降价：换个低配置 / 送个小赠品 / 给足面子。
- 报价前先问预算 / 机型 / 用途，别一上来报最高价。

【可发客户话术（按产品改）】
- "这已经是最低优惠价了哈""成本加运费算下来真没有空间了，这是特价的"
- "再低了真出不了库""现在零售价和成本都比原来高了不少"
- "我要是能做，肯定不会让您浪费时间的""现在生意也难，有单子能往外推吗"
- 给台阶："这样，X 给您换成 Y(低配)，价格能到 Z""价格真到底了，我送您个 X"
- 发票台阶（2026-11-26）：砍价拉锯或临门收口时先问「X哥，这单您需要开发票吗？」——不要票和要票报价完全一样（内部成本一样，绝不另开不含票低价、不提税点成本）；不要票就顺势说「行，您不要票，我就按这个价给您定了，顺丰包邮」；要票就说「要票也是这个价哈，您要专票还是普票？」（小规模店要 13% 专票需引导改拍祥新主体，绝不借票拆票）
- 守住后收口："您觉得合适咱就定了""觉得行我这就给您安排"

## 正品顾虑 · 客户怕假货、要验货、问保障

【客户常见说法】是正品吗 / 是不是真的 / 会不会是假货 / 能验货吗 / 怎么保证 / 有发票吗 / 官方验证 / 海外版 / 日本没有这型号 / 行货还是水货 / 怎么保修 / 售后怎么弄 / 有质保吗

【应对策略】真伪疑虑一次给足保障组合，再用最近成交记录做背书；无实体店的疑虑，把"线上"说成专业代理优势。

【可发客户话术】
- "假一赔十，正品行货，都含发票的""您收到可以官方验证""支持验货哈""我们支持7天内退换货"
- 成交背书："这款我经常卖，前两天还出了 X 套"
- 海外版疑虑："有些型号是只在中国出，但货都是原厂出的，放心"
- 无实体店："我们主要做线上，北上广 X 仓发货，一线品牌都代理了，质量和价格都有保证"

## 退单挽留 · 客户要退、要退款、不想要了

【客户常见说法】退了吧 / 我想退 / 不想要了 / 申请退款 / 先退了 / 要退货 / 不喜欢 / 算了不要了 / 我再考虑考虑 / 这个先不要了

【应对策略 · 销冠王牌】先爽快答应退（降防备）→ 紧跟一句"正好有客户要"（造稀缺）→ 把选择权交回给客户（不逼单但有压力）。很多客户会因此犹豫、甚至转给朋友。
⚠️ 一旦客户坚持退、或已走平台退款流程：严守红线1原路退回，不纠缠。大额卡单（客户犹豫/要退/反复比价）按红线2第一时间加微信转私域再谈。

【可发客户话术】
- "可以的，X 给您退哈"（先答应、降防备）
- "正好这两天有个客户在问这款"（造稀缺感）
- "不着急，您再看看哈"（把选择权交回）

## 比价试探 · 客户拿别处低价、说要去海外/代购买

【客户常见说法】别家才多少 / 网上更便宜 / 想去日本买 / 海外便宜 / 找代购 / 你看人家的价 / 截图给你看 / 同款更低 / 凭什么比别人贵 / 拼多多多少

【应对策略】先核实对方低价真假（很多是假价、小配件单价、水货），不跟客户比低价，比"低价背后的风险 + 我们能提供的价值/服务"。

【可发客户话术】
- "您把那个链接发我看下"（先核实）
- "那款其实是 X 多的，哪有那个价"（点破假低价）
- "网上/海外是便宜，但坏了找谁修？我们这边坏了直接给您换，服务不一样"
- "肯定会有点价差，这能理解，但咱真没法跟水货比，成本就差一截"

## 沉默跟进 · 客户咨询后不回、怎么激活

【客户常见说法 / 场景】客户没回 / 怎么跟进 / 客户沉默了 / 没下文 / 说考虑一下就没消息 / 试打完没动静 / 好久没联系 / 催不催

【应对策略】别催单、别群发感，给一个"利他"由头让客户愿意回你。
- 朋友圈点赞唤醒：长时间没联系的客户，给他朋友圈点个赞，"想起你了"就可能回来下单——成本最低的激活动作（凌晨实测有效）。
- 新品/热销品激活：拿一款新品或热销品（公司发的情报图/实物图）去给沉默客户看，作为重新搭话的由头，比干巴巴问"还要吗"转化高。新客户首次加上后没成交的更要靠这招——凌晨新客转化率≈50%，靠的就是持续给由头跟进，而不是加了就不管。
- 激活三件套（2026-11-25 祥书×月月一对一补充）：① 别只发文字问价，配实拍图或视频；② 用「限时限量」「送礼袋/赠品」做钩子；③ 先查客户历史买过什么（吉客云），再针对性推补货或新品，比群发式问候有效。

【可发客户话术】
- "X 总，最近是不是太忙啦？不着急哈～就是想着先帮您把 XX(尺寸/配置/适不适合)看一下，省得后面您费心"
- 新品由头："X 总，刚到一批 XX(新品/热销)，我第一时间想到您，发您看下图，喜欢我给您留一个"

## 临门促成 · 客户快定了、推一把

【客户常见说法 / 场景】差不多了 / 怎么付 / 要下单 / 考虑得差不多 / 就这个吧 / 能今天发吗 / 下单了

【应对策略】打包说清（含发票运费）消除顾虑 → 加紧迫（今天能发）→ 赠品/定制再加一把火 → 收款后立刻确认款式 + 叫尊称让客户安心。

【可发客户话术】
- "X 给您，含发票、含运费""您要的话今天还能发""订的话送您个 X"
- 收款后："好来，给您发 X 哈，X 总"
- 顺势增购："可以给您印个名字，X 天就好，也不贵"

## 主动给方案 · 客户纠结配置、或某款缺货

【客户常见说法】有没有 XX / 能不能换 / 这个没有吗 / 我要 XX 款 / 缺货吗 / 有别的颜色吗 / 不用加钱吧 / 还有啥推荐

【应对策略】别让客户自己纠结，直接把替代方案 + 优势 + 图给到，降低决策成本；客户怕加钱就主动给不加钱的性价比款。

【可发客户话术】
- "这个确实没出哈，建议您选 XX，质量好、还一包两用，我发您看下"
- "不想加钱的话那就不用挑了，直接给您配个性价比高的"

## 假货客诉应对 · 客户收货后认定/被同行说是假货

> ⚠️ 适用于"调货/圈t来的货被客户拿去验、或被同行一口咬定是假"的售后场景（高仿高发品牌如 LAB 推杆常见）。客户坚持要退就退，别硬刚。凌晨多次实战验证的处理逻辑。

【客户常见说法 / 场景】这东西一眼假 / 我拿去验了是假的 / 别人说你这是假货 / 你给我发的有问题 / 我朋友说这不对

【应对策略 · 销冠心法】
- 先给证明、不争辩：遇到问题第一反应是降低客户抵触，不要跟客户辩"我没卖假货"，越辩越僵。
- 真实付款记录背书：把真实付款记录截给客户证明"没赚黑心钱"（选利润低的那笔截图，别截赚得多的，否则客户更难受）。
- 共情 + 甩锅给客观原因："当时您着急要、我们家正好没这个颜色，就给您从同行调了一只，是我们也被同行坑了"——把自己和客户放在同一边。
- 站客户这边一起怼：遇到品牌商/同行难说话，直接和客户一起怼那个货源方，客户的气消一半，关系反而更近。
- 客户坚持是假货时不硬推：不要硬塞给他"你就拿着吧"，改成"要不咱们重新定一只正品的吧（从美国/正品渠道定），您也放心"，给台阶下。
- 货确实有问题就退：要退就退，公司有付款记录、没赚黑心钱，退得起。

【可发客户话术】
- "您别急哈，我们从来不做假货——这单当时您着急，我家没现货就帮您从同行调的，要真有问题那是我们也被坑了，我先给您把钱退了/换一只"
- "我把付款记录截给您看，您看我这单真没挣您多少，绝不是黑心货"
- "这个品牌确实假货多、又难说话，我跟您一样窝火。要不这样，咱们直接从正品渠道（美国）给您定一只，肯定正品，您放心"

## 新客首次转化 · 加微信后怎么让第一单成交

> 来源：2026-06-18 销售周会。凌晨新客首次转化率≈50%，珊珊/月阳<20%，差距核心在下面这套首次跟进策略。

【背景】顾客加微信=对你有兴趣，但还没信任。第一单是信任门槛，过了之后复购就靠关系了。

【应对策略 · 销冠心法】
- **多给证据**：陌生人不信你说的话，相信你展示的实物图、成交截图、客户反馈。第一句别聊价，先给实物图做背书。
- **让一点利**：新客第一单价格空间可以稍微多给一点，目的是"让他买上"，长期客户价值 >> 第一单利润。
- **加上后不能不管**：加微信后不发出动作，绝大多数新客会沉默到忘掉你。要有后续跟进节奏（新品/热销/点赞）。
- **定期激活**：一周至少发一个"利他由头"去触达——可以是新到的热销品图、公司发的情报图，让客户记起来"这人能搞到货"。
- **用Claude Code记录**：每次加了新微信就让Claude Code记下来（客户偏好/上次聊的内容），方便下次回访用有针对性的内容触达，而不是乱发一通。

【可发客户话术】
- 加好后第一句："Hi，感谢加我哈，以后有什么高尔夫相关问题都可以找我，老客户价、专属服务 ✅"
- 一周后激活："XX，刚到一批（新品图），知道你喜欢XX，第一时间发你看一下，感兴趣给你留一个"
- 朋友圈互动后："哈哈，看你最近在（XX地打球），这款XX特别适合你们那边球场…"
