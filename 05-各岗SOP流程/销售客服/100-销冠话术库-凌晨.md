# 销冠话术库 · 凌晨

> 公司销冠凌晨的真实销售话术，按「客户常见说法 → 应对策略 → 可发客户话术」组织。客服副驾起草回复时会自动检索命中的场景注入。话术按当前产品/客户口吻改一下即可发。
> ⚠️ 平台订单(天猫/京东/淘宝)退款、退差价一律走原路退回(客服红线1)。本库「退单挽留」指的是成交前/未走退款流程时的挽留话术，不是答应私下退款。

## 议价砍价 · 客户嫌贵、要便宜、压价

【客户常见说法】太贵了 / 能不能便宜点 / 优惠点 / 便宜点 / 降价 / 少点 / 抹个零 / 价格高 / 贵了 / 再低点 / 多少能成 / 给个底价 / 实价多少 / 最低多少 / 划不划算 / 还能少吗 / 给个最低价

【应对策略 · 销冠心法】
- 硬价格 + 软态度：报价干脆给数字；拒绝还价时态度一定软（"真的抱歉哈""您是老客户"）。
- 守价只给客观理由，绝不说"我不愿降"：成本涨 / 这是批发价 / 再低出不了库 / 再低就平出了。
- 不被客户带偏：客户拿低价截图、直接转账逼单，先核实、守住自己的节奏，别一慌就降。
- 实在要让步，给"台阶"而不是直接降价：换个低配置 / 送个小赠品 / 给足面子。
- 报价前先问预算 / 机型 / 用途，别一上来报最高价。

【可发客户话术（按产品改）】
- "这已经是最低优惠价了哈""成本加运费算下来真没有空间了，这是特价的"
- "再低了真出不了库""现在零售价和成本都比原来高了不少"
- "我要是能做，肯定不会让您浪费时间的""现在生意也难，有单子能往外推吗"
- 给台阶："这样，X 给您换成 Y(低配)，价格能到 Z""价格真到底了，我送您个 X"
- 守住后收口："您觉得合适咱就定了""觉得行我这就给您安排"

## 正品顾虑 · 客户怕假货、要验货、问保障

【客户常见说法】是正品吗 / 是不是真的 / 会不会是假货 / 能验货吗 / 怎么保证 / 有发票吗 / 官方验证 / 海外版 / 日本没有这型号 / 行货还是水货 / 怎么保修 / 售后怎么弄 / 有质保吗

【应对策略】真伪疑虑一次给足保障组合，再用最近成交记录做背书；无实体店的疑虑，把"线上"说成专业代理优势。

【可发客户话术】
- "假一赔十，正品行货，都含发票的""您收到可以官方验证""支持验货哈""我们支持7天内退换货"
- 成交背书："这款我经常卖，前两天还出了 X 套"
- 海外版疑虑："有些型号是只在中国出，但货都是原厂出的，放心"
- 无实体店："我们主要做线上，北上广 X 仓发货，一线品牌都代理了，质量和价格都有保证"

## 退单挽留 · 客户要退、要退款、不想要了

【客户常见说法】退了吧 / 我想退 / 不想要了 / 申请退款 / 先退了 / 要退货 / 不喜欢 / 算了不要了 / 我再考虑考虑 / 这个先不要了

【应对策略 · 销冠王牌】先爽快答应退（降防备）→ 紧跟一句"正好有客户要"（造稀缺）→ 把选择权交回给客户（不逼单但有压力）。很多客户会因此犹豫、甚至转给朋友。
⚠️ 一旦客户坚持退、或已走平台退款流程：严守红线1原路退回，不纠缠。大额卡单（客户犹豫/要退/反复比价）按红线2第一时间加微信转私域再谈。

【可发客户话术】
- "可以的，X 给您退哈"（先答应、降防备）
- "正好这两天有个客户在问这款"（造稀缺感）
- "不着急，您再看看哈"（把选择权交回）

## 比价试探 · 客户拿别处低价、说要去海外/代购买

【客户常见说法】别家才多少 / 网上更便宜 / 想去日本买 / 海外便宜 / 找代购 / 你看人家的价 / 截图给你看 / 同款更低 / 凭什么比别人贵 / 拼多多多少

【应对策略】先核实对方低价真假（很多是假价、小配件单价、水货），不跟客户比低价，比"低价背后的风险 + 我们能提供的价值/服务"。

【可发客户话术】
- "您把那个链接发我看下"（先核实）
- "那款其实是 X 多的，哪有那个价"（点破假低价）
- "网上/海外是便宜，但坏了找谁修？我们这边坏了直接给您换，服务不一样"
- "肯定会有点价差，这能理解，但咱真没法跟水货比，成本就差一截"

## 沉默跟进 · 客户咨询后不回、怎么激活

【客户常见说法 / 场景】客户没回 / 怎么跟进 / 客户沉默了 / 没下文 / 说考虑一下就没消息 / 试打完没动静 / 好久没联系 / 催不催

【应对策略】别催单、别群发感，给一个"利他"由头让客户愿意回你。

【可发客户话术】
- "X 总，最近是不是太忙啦？不着急哈～就是想着先帮您把 XX(尺寸/配置/适不适合)看一下，省得后面您费心"

## 临门促成 · 客户快定了、推一把

【客户常见说法 / 场景】差不多了 / 怎么付 / 要下单 / 考虑得差不多 / 就这个吧 / 能今天发吗 / 下单了

【应对策略】打包说清（含发票运费）消除顾虑 → 加紧迫（今天能发）→ 赠品/定制再加一把火 → 收款后立刻确认款式 + 叫尊称让客户安心。

【可发客户话术】
- "X 给您，含发票、含运费""您要的话今天还能发""订的话送您个 X"
- 收款后："好来，给您发 X 哈，X 总"
- 顺势增购："可以给您印个名字，X 天就好，也不贵"

## 主动给方案 · 客户纠结配置、或某款缺货

【客户常见说法】有没有 XX / 能不能换 / 这个没有吗 / 我要 XX 款 / 缺货吗 / 有别的颜色吗 / 不用加钱吧 / 还有啥推荐

【应对策略】别让客户自己纠结，直接把替代方案 + 优势 + 图给到，降低决策成本；客户怕加钱就主动给不加钱的性价比款。

【可发客户话术】
- "这个确实没出哈，建议您选 XX，质量好、还一包两用，我发您看下"
- "不想加钱的话那就不用挑了，直接给您配个性价比高的"
