# 首单奖励规则更新（2026-05-13）

> 来源：祥书口述补充 → 已同步更新到飞书《[客户添加、首单奖励规则及网店报备规范](https://xiangxingolf.feishu.cn/docx/Ga3ndCMWeoGQQGxjBOKcXSbKnAe)》第三节。

## 一句话理解

**上班时间原款成交不算；上班时间有转推成交算；下班后 / 跨天跟进成交，5 天内算。**

## ✅ 计算首单奖励

- 客户**下班后、第二天或跨天**继续跟进后成交（5 天内有效）。
- 上班时间内沟通**有转推行为**导致成交，包括但不限于：
	- 原产品没库存，客服推荐其他产品成交；
	- 客户型号 / 款式反复不确定，由客服推荐成交；
	- 客户咨询 A 款，经客服推荐最终购买 B 款。
- 客户咨询但未明确表达购买意向，客服通过跟踪促成下单。
- 订单沟通中明显是客服沟通努力促使顾客下单的。

## ❌ 不计算首单奖励

- 客户在**上班时间内咨询并当天成交**，且只购买原本咨询的产品；客服仅回复价格、库存、发货、优惠、链接等基础问题。
- 有明确购买意向，仅问优惠，客服在权限内给予优惠后下单。
- 有购买意向，主动咨询使用方法，沟通几句即下单。
- 引导客户在网店下单，**不得引导顾客微信下单给与优惠**，从而下单。
- 清仓奖励产品不算首单，只享受清仓价。

## 奖励结构（未变）

| 订单金额区间 | 奖励 |
| --- | --- |
| 2000–5000 元（含 5000） | 50 元 |
| 5000–10000 元（含 10000） | 100 元 |
| 10000–30000 元（含 30000） | 200 元 |
| 30000–60000 元及以上 | 500 元（封底） |

- 须线上客户在 **5 天内**完成首次订单。
- 由客服登记《首单奖励明细表》；评判人：凌晨；财务核算时再与运营复核。

## 本次更新要点

| 旧规则 | 新规则 |
| --- | --- |
| 「上班时间内沟通后下单」一律不区分，只笼统说"沟通努力促使下单的给奖励" | **明确二分**：原款当天成交不算；**有转推 / 跨天跟进**才算 |
| 转推行为未单列 | 单列 3 种典型转推场景（断货推、犹豫推、A→B 推） |
| 跨天 / 5 天内成交 | 明确写进"计算条件"，与"奖励条件 5 天"对齐 |
