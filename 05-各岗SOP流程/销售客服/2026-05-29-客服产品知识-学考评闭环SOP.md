# 客服产品知识 · 学—考—评 闭环 SOP

## 为什么要这套
光发卡片让客服学、没有考核交付 = 跟没做一样。这套让学习有闭环：**定期口答考核**检验真掌握，**录音防作弊**（口头即时答、来不及查 AI/资料），**AI 转写判分**让老板不用一段段听。

## 四阶段闭环

### ① 学（每天）
Anki 每天 10 张、每月一轮，先学测距仪 + Garmin（客户问得最多）。卡片项目见 `客服高尔夫Anki学习卡片/`。

### ② 考（每月一次 · 口答录音）
- 月底，豆包用 `make_exam.py` 给每人随机抽 **15 题**（按组加权：测距仪4 / Garmin4 / 球杆3 / 常识2 / 客服2），**每人题不同**（防对答案）
- 员工拿到自己的考卷 → **对着题口头回答、手机录音**：开头报名字 + 日期、一口气录完、**不查资料 / 不问 AI**
- 录音传到本人**飞书考核任务的评论区**

### ③ 评（AI 判分 + 老板抽听）
- 豆包把录音用**飞书妙记**转成文字 → 逐题对标准答案版判分 → 出**评分表**（谁得几分 / 错哪题 / 哪组最弱 / 是否疑似念稿）
- 祥书只看评分表，**可疑的（像念稿、分数异常）才抽听原音**核实

### ④ 反哺（形成进步）
- 分数进台账（后续建飞书 Base，看每人每月进步曲线）
- 高频错题 → 下月重点考 + 提示重学；不及格 → 重考
- 错题暴露的知识缺口 → 补 / 改卡片（回流到 cards.json）

## 防作弊三层
1. **随机抽题**：各人题不同、每月不同，互相对不了答案
2. **一镜到底口答**：说话时来不及查 AI/资料，磕巴 / 想不起来真实暴露
3. **报名字 + 日期**：证明本人、本时段录的

## 角色分工
| 谁 | 做什么 |
|---|---|
| 员工（月月 / 月阳 / 珊珊） | 平时学卡片；考核时对题口答录音、传考核任务评论区 |
| 豆包（AI） | 出题、转写录音、判分、出评分表、维护台账、错题反哺 |
| 祥书 | 看评分表、抽听可疑录音、定夺及格 / 重考 |

## 评分标准（祥书 2026-05-29 定）
- **满分 100 分，≥ 85 分及格**；< 85 下月重考
- 由**豆包(AI)判分**：转写录音后逐题对标准答案打分
- 每题答到**要点**即算对（口语化、说法不同没关系，看意思对不对）
- **开放性话术题酌情给分（含部分分）**——说法对、意思到位就给，不抠字眼（及格线略低于满分正是为这类题留弹性）
- 带 ⚠️ 未定稿口径的题（防水 / A1 坡度等）：答「保守话术 / 会去帮客户确认」即算对
- 评分表同时给：错题清单 + 最弱卡组（指导下月重点）

## 频率与试跑
- **频率**：每月一次（跟学习节奏一致），和每月自动复学任务挂钩
- **首轮试跑（2026-06）**：就月月 / 月阳 / 珊珊 3 人手动跑一遍全流程，验证出题 / 录音 / 转写 / 判分顺不顺、评分准不准、及格线合不合理，再固化成每月半自动

## 工具
- 出题：`scripts/make_exam.py --names 月月 月阳 珊珊 --ym 202606` → 员工卷 + 答案版到 `exams/年月/`
- 转写：飞书妙记（lark-minutes，上传录音出逐字稿）
- 判分：豆包对答案版逐题判，出评分表
- 台账：试跑用 md，稳定后建飞书 Base

## 这套怎么慢慢教会他们
全程对员工只有两个动作：**手机录音、在飞书任务评论区上传**，没有新软件要学。技术活（出题 / 转写 / 判分 / 台账）全在豆包这边，员工和老板都不碰。等他们熟了，再逐步教更高阶的（自己看评分表复盘、自己挑薄弱卡组加练）。
