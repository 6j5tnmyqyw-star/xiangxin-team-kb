# 【倍视能测距仪·刻字定制】客服标准化流程 SOP

> 🎯 **目的**：测距仪支持免费激光刻字，但刻字内容必须经客户确认后才能上机雕刻。本 SOP 唯一目标——让"等客户确认刻字"不拖累发货时效，**杜绝揽收超时 / 48 小时延迟发货扣款**。
> 适用：天猫 / 京东倍视能旗舰店 · Bushnell 测距仪（V6 / V6S / V7S / PRO XM 等支持刻字型号）

> ⭐ **核心顺序（背下来，不许跳步）**
> 客户提刻字 → **先发「协商发货申请 + 时效话术」** → 做刻字排版图给客户核对 → 客户确认后再雕刻发货
>
> 最容易翻车的点：别等排版图做完才发协商发货。一发现是刻字单，第一时间把"协商发货 + 时效话术"发出去，先把时效口子堵上。

## 🛠️ 操作步骤

| 步骤 | 动作 | 责任人 | 时间节点 |
|---|---|---|---|
| 1 | 识别刻字需求（客户沟通提刻字 / 订单备注写了刻字） | 客服 | 接单即时 |
| 2 | **一次性发两段给客户**：①平台协商发货申请　②时效告知话术（话术见下，直接复制） | 客服 | 识别后立即 |
| 3 | 千牛发起协商发货：**千牛工作台 → 智能客服 → 协商发货**，约定 3–5 天发货 | 客服 | 同步进行 |
| 4 | 按客户文字做刻字**排版截图**，发给客户核对确认 | 客服 | 当日内 |
| 5 | **每日 17:00 统一核对**所有待确认刻字订单 | 客服 | 每天 17:00 |
| 6 | 17:00 前已确认 → 通知库房 / 雕刻：**当日雕刻、当日打包、当日揽收发出** | 客服 → 库房 | 当日 |
| 7 | 17:00 前未确认 → 今日无法加工，**次日确认后优先发货** | 客服 | 次日 |
| 8 | 客户始终联系不上 → 走兜底流程，库房发无刻字原机，避免揽收超时 | 客服 → 库房 | 协商期限到期前 |

> ❗ 协商发货卡片：买家点"同意"后，结果通过**系统消息**同步，**商家侧卡片按钮不会变化**——别以为没生效，以系统消息为准。

## 💬 话术（直接复制）

**1. 识别到刻字后，一次性发给客户**
> 球友您好，您购买的倍视能测距仪支持免费激光刻字，刻字内容必须经您核对确认后才能上机雕刻。
> 因刻字需要等待您确认文字，我这边已给您发起平台协商发货申请，麻烦您在订单页面点击同意一下。
> 和您说明发货时效：今天下午 17 点前您确认好刻字内容，货品当天就能正常打包发出；若 17 点前未收到您的刻字确认，今日无法完成雕刻，只能安排次日发货。

**2. 发排版图时（核对话术）**
> 这是按您提供的内容做的刻字排版图，麻烦您仔细核对**文字、有无错别字、位置**，确认无误回复"确认"，我这边就安排上机雕刻啦～（激光为灰白色、不可选颜色，建议 5 字以内最好看，刻在机身侧面）

**3. 下单前必说项（红线，刻字单每单都要说）**
> 亲，**刻字属于定制款，非产品质量问题不支持 7 天无理由退换货**，质量问题照样 2 年保修，所以下单前帮您把刻字内容确认好～

**4. 联系不上时的兜底告知（发原机前留言 / 旺旺）**
> 球友您好，您的刻字内容我们多次联系暂未收到确认，为避免影响您收货时效，我们先按**原机（不刻字）**为您安排发出，刻字服务不受影响——您后续方便时联系我们，可协商补刻 / 后续补偿方案。给您带来不便请谅解～

## 🚨 兜底流程：客户一直联系不上（防揽收超时）

> 💡 **触发条件**：已多次联系客户、协商发货约定的发货期限即将到期（建议到期前 1 天为最后节点），客户始终未确认刻字内容。

1. 客服在协商期限到期前，通知库房：该单按**"无刻字原机"**发出。
2. 库房按普通订单正常打包、当日揽收，**先把货发出去，杜绝揽收超时 / 延迟扣款**。
3. 客服在订单 / 旺旺留言告知客户（话术 4），**全程留痕**：已多次联系、已发起协商发货、为避免超时发原机。
4. 客户后续回来 → 按补刻 / 补偿协商处理（涉及返厂或补偿的，按公司售后规则走，拿不准报主管）。

> 💡 **原则**：刻字是免费增值服务，不影响客户主体权益；时效超时才是会扣钱、伤评分的硬伤。两害相权，联系不上就先发原机保时效。

## 📅 每日固定动作

**每天 17:00**，客服统一拉一遍"待确认刻字订单"清单，逐单核对状态：
- 已确认 → 当日雕刻 + 当日揽收
- 未确认 → 标记次日优先 / 评估是否触发兜底
- 接近协商期限仍联系不上 → 触发兜底流程

## 🔴 红线提醒

1. **客户隐私**（姓名 / 手机 / 地址 / 订单号）不进任何 AI 输入输出。
2. **刻字内容必须客户确认后才上机**，绝不凭备注自己猜着刻。
3. **下单前必说"刻字定制非质量问题不退换"**，每单都说。
4. **品牌 / 型号拼写**：Bushnell（倍视能），写排版图、对外回复前核对。
5. 涉及补偿 / 返厂 / 退款的，拿不准**先报主管**，不自作主张。
