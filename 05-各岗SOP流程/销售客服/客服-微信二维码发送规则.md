# 客服微信二维码发送规则

> 来源：2026-06-13 工作会议 + 2026-06-15 珊珊/祥书群聊确认
> 核心原则：**一个客户只加一个客服的微信**

## 规则

1. **首发者负责到底**：第一个发出微信二维码的客服，负责该客户的后续微信跟进，不换人。

2. **后续客服/销售看到已发过二维码 → 直接跳过，彻底不联系**
   - 不管客户加上没加上，统一跳过
   - 包括销售电话跟进（月阳等）：看到聊天记录有发过 = 免联系

3. **客户没加上怎么办**：由当初发二维码的客服继续跟进，不换人再发新二维码。

4. **聊天记录滞后问题**：暂不处理，边缘情况不过度复杂化（祥书 2026-06-15 确认）。

## 执行标准

- 判断依据：千牛/京东助手聊天记录里是否有发过二维码
- 有发过 = 后续客服免联系
- 没有发过 = 正常流程，可发二维码
