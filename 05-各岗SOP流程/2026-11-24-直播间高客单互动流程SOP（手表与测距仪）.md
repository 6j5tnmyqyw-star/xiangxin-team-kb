# 小直播间高客单互动流程 SOP（手表 / 测距仪专场）

> **一句话定位**：人少的直播间，不要演几百人的「321 上链接」，要把它当成**实体高尔夫球具店的专柜**——陈先生推门进来，店里只有两三个客人，主播就是柜台后面懂货、实在、不催单的导购。
> **核心目标**：用「轻打招呼 + 下场场景勾子 + 真机实操对比」留住精准球友，把直播间过客转成**当场下单**或**店铺客服窗口有效咨询**。

## 一、核心认知：为什么高客单小直播间不能照搬叫卖套路

我们卖的 Garmin 手表、Bushnell 测距仪多在 1,800–5,000 元区间，进直播间的人往往是自己搜型号比价、或者准备换装备的球友老板。在线只有两三个人时，如果主播还像低价快消品那样大喊大叫、反复求点赞扣 1、搞倒计时逼单，客人的第一感受就是吵、假、不专业，几秒钟就会划走。

相反，人少反而是优势：主播不用同时应付几百条弹幕，可以把精力全部放在正在看直播的这一两个客人身上，用**「老球友帮避坑」**的语气，把真机屏幕、手感和下场实测直接摆到镜头前。

## 二、五步标准互动流程（以「陈先生进房，正在讲手表/测距仪」为例）

### 第 1 步：进房前 5 秒——轻接人，不断手里演示

客人刚进来时，不要堆砌夸张欢迎词（如「热烈欢迎陈总！陈总点个关注！」），容易给高客单客户带来压迫感。主播顺着当前讲解停半拍，像专柜柜员抬眼打招呼即可，同时**手上的真机展示不要停**，顺势把手表表盘或测距仪机身往近景镜头推一点。

- **可直接照念的开场话术**：「陈先生您好，正好在看这块 Garmin S70（或这台倍视能 V6S 测距仪），您先随便看，想细看哪个界面或者对比哪款型号，直接在公屏打给我。」
- **镜头配合**：第一时间让客人看到近景真机（表盘亮度、表带材质、测距仪大小与按键），不要全程只拍主播半身像。

### 第 2 步：进房 10–30 秒——抛「场景二选一」勾子，测他是不是真球友

这一步决定客人停不停留。忌讳自说自话背说明书（屏幕尺寸、续航天数、内置多少万座球场——这些商品详情页里都有）。改成抛一个**只有下场打球的人才会心生比较**的场景二选一问题，让对方哪怕不打字也在脑子里接话。

| 当前正在讲 | 场景勾子话术（可直接照念） | 预期引出的客户提问 |
|---|---|---|
| **讲 Garmin 手表（S70 / S72）** | 「不知道陈先生平时下场是用手表多，还是习惯带测距仪？不少球友从测距仪换 S70，主要是懒得每杆都掏一遍，还想在表上直接看果岭坡度和风速。」 | 「我用惯测距仪了」「42 和 47 怎么选」「S70 和 S62 差在哪」 |
| **讲 Bushnell 测距仪（V6S / V7S / PRO XM）** | 「正好说到这台 V6S 和 V7S，好多球友纠结要不要上更亮的新款红字显屏，其实主要看平时打早晚场多不多、有没有戴老花镜。」 | 「V6S 和 V7S 差多少钱」「带不带坡度开关」「PRO XM 沉不沉」 |
| **讲手表 vs 测距仪二选一** | 「很多球友刚配装备都会卡在选表还是选测距仪——追求每一杆码数稳准就选测距仪，平时不想往口袋塞东西、通勤也想戴就选高尔夫手表。」 | 「新手买哪款」「哪个不容易闲置」 |

只要陈先生在公屏敲出哪怕几个字，这场互动就成了一半。

### 第 3 步：客人一旦开口提问——「真机实操 + 补半句避坑」

客人在公屏问问题时，**不要念参数表**，按「**直接做给他看 → 一句话答核心 → 补一句他没问但买前必卡的避坑点**」三拍回应：

1. **问手表差异（例：「S70 表盘多大 / 跟旧款差在哪」）**：直接上手腕戴着比给镜头看，当场点开果岭坡度热图和虚拟球童界面，再顺手补一句：「47mm 和 42mm 上手差别挺明显，平时上班也戴或者手腕偏细，选 42mm 更贴手；纯下场图看数爽快就选 47mm。」
2. **问测距仪怎么选（例：「V6S、V7S、PRO XM 怎么挑」）**：把两台真机并排放在近景镜头下比大小和重量，讲清楚谁带外置坡度开关、谁读数视野亮、谁握感轻巧，直接告诉对方哪种下场习惯没必要多花冤枉钱。
3. **问现货 / 多图 / 复杂对比 / 高客单配单**：如果公屏几句话说不清，或者客人想看仓库现货与实拍对比，统一往**平台店铺客服**承接：「陈先生，您点一下左下角联系店铺客服，留个型号，我让后台把这两款的实拍对比图和今天仓库现货发您对话框里。」

### 第 4 步：客人全程沉默不说话——不催扣 1，演给他看真干货

人少直播间很常见的情况是：陈先生在线待了三五分钟，一个字都不打。这时主播千万别慌，**严禁连环催问「陈先生在不在」「听到的扣个 1」「帮我点点赞」**——高净值球友极反感被点名逼互动。

正确做法是把他当成在专柜前安静挑货的熟客，继续顺畅做**三项真机实测演示**（配合 3 分钟连续讲透一款的节奏）：
1. **手表实操演示**：现场切球场俯视图、放大果岭旗杆位置、拆装表带看手感，对比 42mm 与 47mm 上手贴合度。
2. **测距仪实操演示**：对着窗外远景或固定参照物实测锁旗震动提示；演示机身磁吸吸在铁架上轻轻甩两下看稳固度；现场掰动外置坡度开关，说明打友谊局与正式比赛的区别。
3. **聊真实避坑点**：讲老球友容易买错的地方（比如不常打早晚场没必要盲目追顶配、哪类配件买了常闲置），让沉默看客听出「这店懂行、实在、不忽悠」。很多沉默客户听完不打字，会直接点进客服窗口问价或直接下单。

### 第 5 步：聊完说「再考虑一下」——绝不逼单，留好承接台阶

两三千到五千块的装备很少有人五分钟冲动买单。客人说「我再看看 / 对比一下」时，守住不逼单底线，大度收尾并留一个轻量抓手：

- **标准收口话术**：「没问题陈先生，手表和测距仪买回去要用好几年，肯定得挑顺手的。您回头要是想再看刚才那两款的实拍对比，或者确认当天现货，随时戳一下店铺客服留个型号，下播后我让专人发您对照着选，不急。」
- **下播 5 分钟闭环**：主播立刻记下本场公屏被问到的 **2–3 个高频型号与卡点问题**，同步回传给运营/销售团队——既能直接喂给下一期短视频选题，也能补进客服速查卡，越播越准。

## 三、常见错法 vs 正确做法对照

| 场景 | ❌ 常见错法（立刻赶走客人） | ✅ 正确做法（专柜顾问感） |
|---|---|---|
| **客人刚进房** | 「欢迎陈总来到直播间！陈总点个关注亮个灯牌！」 | 「陈先生您好，正好在看这块 S70，您随便看，想细看哪款直接打给我。」 |
| **讲产品时** | 低头照说明书念屏幕分辨率、电池毫安、球场总数 | 抛下场二选一场景（「平时用表多还是测距仪多」），拿真机直接切界面演示 |
| **客人不说话** | 慌乱求互动：「陈先生扣个 1」「人呢帮我点点赞」 | 当成熟客安静逛专柜，持续做真机对比、磁吸实测、聊选购避坑 |
| **客人要对比/看图** | 在抖音直播间口播「加我微信发你」「私我微信号」 | 引导点左下角店铺客服 / 平台私信，在平台内发实拍对比和现货明细 |
| **客人说再考虑** | 「陈总今天不拍明天就恢复原价了，赶紧锁单」 | 「正常，这东西用好几年得选顺手的，后面想看对比随时戳店铺客服留型号」 |

## 四、四条红线（零容忍）

1. **抖音严禁站外引流**（执行 [[08-公司知识库/06-销售客服规则]]）：在抖音直播、评论、私信中，**严禁口播或引导「加微信」、严禁露微信号/二维码**；哪怕客人主动要微信，也在平台内婉拒，引导走店铺客服沟通。
2. **价格与违禁词红线**（执行 [[08-公司知识库/05-短视频运营规则（老孙）]] & [[07-AI协作/规则/03-内容创作规范]]）：价格统一说「**店铺活动价**」；严禁使用「极致、史上最低、第一、绝对、国家级、唯一、顶级、独家、军用级、百分百精准、激光武器级、超越同行」及含「最」字的极限表述；价格和库存口径开播前核准，零口误。
3. **演示必须真做，参数严禁瞎编**：能现场演示的功能必须拿真机做；遇到客人问冷门安装/配对/固件参数，拿不准就直说「我帮您核对官网说明书后让客服回复您」，严禁凭印象或拿通用闲聊工具现查乱答。
4. **严禁高压逼单**（执行客服-007 规则）：禁止使用「今天不下单就没这个优惠了」等恐吓式促单话术，只如实说明平台活动截止时间与现货发运安排。

## 五、开播前 & 下播后 5 分钟自检清单

- [ ] **开播前 · 真机就位**：主推手表充满电并调好球场演示界面；测距仪装好电池、擦干净镜片；对比机型（如 V6S + V7S，或 S70 42mm + 47mm）摆在伸手可拿处。
- [ ] **开播前 · 镜头与贴片**：双机位或近景焦段已测试清晰（能看清表盘字迹）；直播间氛围贴片已就位；当日店铺活动价与现货库存已核对。
- [ ] **直播中 · 节奏稳住**：每款产品围绕「场景痛点 + 真机实操」连续讲透 3 分钟，有人进来 5 秒内轻接人、30 秒内抛场景勾子，不催扣 1。
- [ ] **下播后 · 5 分钟留痕**：记录本场进房客户问到的高频型号、价格疑问与卡点，回填运营表并同步销售组跟进已进店铺客服的咨询客户。
