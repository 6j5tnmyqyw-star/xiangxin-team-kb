# 天猫运营标准流程 SOP

> 适用：天猫倍视能旗舰店为主，京东倍视能 / 京东祥新运动同理迁移。
> 一句话：运营不是"上架改价点点点"，是**用最少的钱，把对的货卖给对的人，并让他再买**。

## 关联条目

- 公司总览：[[00-公司全景]]

## 一、先想清楚：运营到底在撬什么

店铺成交额拆成一个乘法公式，**所有运营动作都对应其中一个乘数**：

> **成交额 = 访客数(UV) × 转化率 × 客单价 × 复购**

| 乘数 | 谁在拉它 | 主要抓手 |
|---|---|---|
| 访客数 | 流量运营 | 搜索SEO、付费推广、内容/直播、活动坑位 |
| 转化率 | 商品+客服 | 主图/详情/评价/价格力/客服承接 |
| 客单价 | 商品+活动 | 套餐、搭配、满减、连带、升级款引导 |
| 复购 | 客户运营 | 会员、私域召回、售后口碑 |

做任何动作前先问自己一句：**我这一步是在撬哪个乘数？撬动多少？花了多少钱？** 答不上来就别做。

⚠️ 公司净利率薄（2026 Q1 全店 2.92%），**付费推广必须卡投产比**，烧钱换的销量不算赢。

### 运营组职能分工

把店运营拆成 6 块，**每块必须有唯一主负责人**（一人可兼多块，但不能出现三不管的活）：

| 职能 | 管什么 | 主负责人 |
|---|---|---|
| 商品 | 主图/详情/标题/SKU/上下架、转化优化 | 待填 |
| 流量投放 | 直通车/引力魔方/万相台、ROI 管理 | 待填 |
| 活动 | 日常活动报名、大促节奏 | 待填 |
| 客户/口碑 | 评价/DSR、会员复购、客服对接 | 待填 |
| 内容/直播 | 短视频/直播/逛逛内容产出 | 孙庆弘 |
| 竞品/数据 | 竞品价格+上新监控、数据复盘 | 待填 |

> 「主负责人」由祥书按运营组（何小琴/王娜/洪丽华/于嘉欣/孙庆弘）实际分工填。一店一表，多店分别明确。

### 精力分配：80% 砸在这三件事

运营每天事多，**先保大店、大品、大渠道**，别把时间耗在不影响大盘的小事上：

- **80% 精力** → ① 主推品转化优化（主图/详情/价格力）② 付费投放 ROI ③ 大促/活动节奏
- **20% 精力** → 日常杂事（上下架、活动报名、客服同步、报表）

## 二、日 / 周 / 月固定节奏

### 每日 · 早盘（9:00 前，30 分钟）
1. **看昨日数据**（生意参谋实时+昨日）：访客、转化率、支付金额、客单价，跟前 7 天均值比，异常（涨跌 >20%）要找原因。
2. **看竞品价**：每天的竞品价格监控结果（飞书 Base）有没有异常低价，影响我们爆款的要当天决策跟不跟。
3. **看库存**：主推品 / 在投广告的品有没有快断货（断货前必须停车，否则白烧钱）。
4. **看客服反馈**：昨天有没有集中咨询的问题、差评、价格异议 → 转商品或活动动作。

### 每日 · 操作（白天）
- 直通车 / 万相台日常调整（看下面第五节）
- 活动报名（聚划算、淘抢购、官方活动的报名截止日要盯）
- 上下架优化（每天固定时段错峰上架，蹭自然搜索权重）
- 异常处理（断货改库存、错价立即修、违禁词排查）

### 每日 · 收盘（下班前，10 分钟）
- 当日花费 vs 产出对一遍，明显亏的车次/计划明天调
- 明日待办列清楚

### 每周 · 复盘（周一上午，运营周会）
- 输出**周报四段式**：摘要 / 数据 / 问题 / 下周计划（飞书格式）
- 数据段必带：分品类/分渠道流量、转化、TOP 品贡献、付费 ROI、竞品动向
- 问题段：本周没达成的、卡住的、需要老板/采购支持的

### 每月 · 计划
- 上月复盘 + 本月目标拆解（拆到周、拆到品、拆到渠道）
- 大促/活动日历提前排（618、双11、品牌日、官方营销节点）
- 商品汰换：滞销下架、新品规划（结合库存周报）

## 三、看盘：生意参谋核心指标

只盯这几个，别被一堆数据淹没：

| 模块 | 指标 | 看什么 |
|---|---|---|
| 流量 | 访客数、流量来源占比 | 手淘搜索/推荐/直通车/直播 各占多少，哪条腿瘸了 |
| 转化 | 支付转化率、加购率、收藏率 | 转化低 → 价格/详情/评价问题；加购高不付 → 价格/活动问题 |
| 价值 | 客单价、UV 价值 | UV价值=能不能为流量付费的天花板 |
| 商品 | 单品访客→转化漏斗 | 哪个品流量大不转化（救），哪个品转化高缺流量（推） |
| 竞争 | 市场行情 / 搜索词 | 行业大盘趋势、竞品排名、有没有新搜索词起来 |

### 异常排查决策树（数据掉了，照着往下查）

**A. 没流量 / 流量掉了**
1. 自然搜索掉？→ 标题被改？类目放错？主图点击率跌？动销断了？被监管降权？竞品抢了词？
2. 付费掉？→ 预算花完？计划被暂停？出价被对手超了？因 ROI 差主动降了？
3. 大盘掉？→ 看市场行情，是不是淡季全行业回落（是的话别瞎折腾，养着等旺季）。
4. 活动结束流量回落？→ 正常现象，提前规划下一波。

**B. 有流量不转化**
1. 价格 → 比天猫竞品，是不是贵了 / 活动价没跟上。
2. 主图详情 → 点击率正常吗？详情有没有硬伤、参数缺失、信任状不足。
3. 评价 → 新增差评？DSR / 体验分掉了？
4. 库存 / SKU → 缺货、主推规格没货、SKU 混乱。
5. 客服 → 响应慢？话术不行？（看客服数据）

**C. 转化了但不赚钱**
1. 付费占比太高 → ROI 低于保本线，降付费、养免费流量。
2. 优惠叠太狠 → 券 + 活动价穿了底，核算真实到手价。
3. 退款率高 → 查退款原因（质量 / 描述不符 / 物流）。
4. 引流款占比过高 → 只卖不赚的品挤掉了利润品，调结构。

## 四、商品运营（撬转化 + 客单）

### 选品 / 主推
- 主推品以《[[2026-05-13-主推品梳理评分与建议]]》为准，**有销量基础+利润率过得去的优先推**，别砸钱推 0 销量的高客单品。
- 主推品数量克制：一个店同时重点推的品不超过 5-8 个，资源集中。

### 主图（最影响点击率）
- 5 张主图 + 主图视频，第一张要素：产品+核心卖点+价格力/利益点。
- 测距仪类：突出测距精度/坡度补偿/防水等硬参数；球包/球杆类：突出品牌+质感。
- 🔴 **618 期间不随意改主图，改前必须告知祥书**（业务铁律）。

### 标题（最影响搜索流量）
- 结构：核心类目词 + 品牌词 + 属性词 + 场景/长尾词，30 字写满不堆砌。
- 关键词来源：生意参谋搜索词、竞品标题、直通车有转化的词。
- 不轻易改有权重的爆款标题；优化挑访客少的词替换。

### 详情页（临门一脚）
- 结构建议：痛点切入 → 核心卖点（FABE：特性-优势-利益-证据）→ 参数对比 → 信任状（销量/好评/授权/质保）→ 促单（活动/赠品/承诺）。
- 高客单品（球杆/球包 >2000）尤其要把"为什么值这个价"讲透，否则加购不付款。

### SKU / 上下架
- SKU 命名清晰、主推规格放前面；缺货 SKU 及时下架别挂着拉低转化。
- 每天错峰上架蹭搜索权重；滞销品（结合库存周报）走清仓或下架。

## 五、流量运营（撬访客）

### 免费流量（搜索 SEO）— 长期地基
靠这几件事积累权重：**标题关键词 + 持续动销 + 服务分(DSR/体验分) + 上新 + 坑产（单品销售额）**。免费流量是慢功夫，但最便宜，必须养。

### 付费流量 — 要算 ROI 的
| 工具 | 用途 | 怎么用 |
|---|---|---|
| 直通车（标准/智能） | 测款、卡搜索词、收割 | 新品测点击率/转化；爆款卡精准词收割 |
| 引力魔方 | 拉新、人群推荐 | 拉访客、做相似人群放大 |
| 万相台无界 | 一站式智能投放 | 上新快速起量、活动场景、日常托管 |

**ROI 红线（重点）**：
- 投产比（ROI）= 推广带来的成交额 ÷ 推广花费。
- 公司净利率约 3%，**保本 ROI ≈ 1 ÷ 净利率 ≈ 30+**（毛利高的品另算），低于保本线的计划是在亏钱拉销量，要么优化要么停。
- 测款期允许亏（买数据），但要设预算上限和测试周期，到点必须判生死。
- 每天看「花费 vs 产出」，连续亏的关键词/计划果断降价或暂停。

### 内容流量
- 逛逛、直播、短视频由**孙庆弘**对接内容制作；运营负责把内容流量承接到商品页（链接、活动配合）。

## 六、活动运营（撬客单 + 爆发）

### 日常活动
聚划算、天天特卖、淘金币、官方频道活动——挑利润扛得住的品报，活动是放大器不是亏本清仓（清仓单独走）。

### 大促节奏（618 / 双11）四阶段
| 阶段 | 时间 | 干什么 |
|---|---|---|
| 蓄水 | 大促前 2-4 周 | 加购收藏、内容种草、付费拉新人群、定金预售页准备 |
| 预售 | 大促前 1-2 周 | 定金预售、客服话术统一、库存备齐 |
| 爆发 | 大促当天 | 全力投放、坑位承接、客服满载、实时盯库存/价格 |
| 返场 | 大促后 | 收尾流量、未付尾款催付、连带销售、复盘 |

🔴 **618 主图铁律**：大促期不随意改主图，改前必须告知祥书。

## 七、价格管理

- 🔴 **比价以天猫为基准，不用京东价**（业务铁律）。
- 每日竞品价格监控（taobao-price-monitor，结果进飞书 Base，只报偏离中位数 ≥3% 的异常价），异常低价影响爆款的当天决策。
- 改价纪律：大促/主推品调价前确认毛利扛得住；错价立即修；活动价和日常价的关系理清，别自己打自己。

---

## 八、客户 / 口碑运营（撬复购）

- **客服承接**：客服是转化的最后一棒，运营要把活动/赠品/价格政策同步给客服（话术统一，见客服 SOP）。
- **评价管理**：盯 DSR / 体验分，差评第一时间响应处理；好评/买家秀沉淀到详情页做信任状。
- **复购召回**：私域老客走 xiangxin-sixu-recall（按高尔夫品类复购周期分层召回）；天猫端做会员、老客专享、复购券。
- ⚠️ 客户隐私（姓名/手机/地址/订单号）严禁出现在任何对外内容（业务铁律）。

## 九、竞品监控（固定动作）

| 看什么 | 用什么 | 频率 |
|---|---|---|
| 竞品价格异常 | taobao-price-monitor → 飞书 Base | 每日 |
| 竞品上新 | xiangxin-jingpin-shangxin（44 家竞品店快照） | 每日 |
| 市场大盘/热销榜 | sales-market-briefing 市场情报日报 | 每日 5:00 自动 |

竞品监控不是看热闹，是**找差距和机会**：他降价我跟不跟、他上的新品我有没有、他爆的款我能不能卡。

## 十、运营 KPI 与考核口径

考核运营不看"忙不忙"，看这几个结果指标：

| 考核维度 | 口径 | 数据来源 | 达标方向 |
|---|---|---|---|
| 销售额完成率 | 实际成交 ÷ 月目标 | 生意参谋 / 吉客云 | 达月目标 |
| 付费 ROI | 推广成交 ÷ 推广花费 | 推广后台 | ≥ 保本 ROI（≈30+） |
| 付费占比 | 付费成交 ÷ 总成交 | 生意参谋 | 不无限攀升，留住免费流量 |
| 支付转化率 | 环比 / 同比 | 生意参谋 | 不低于自己历史 & 竞品 |
| 客单价 | 环比 | 生意参谋 | 维持或提升 |
| 免费流量占比 | 搜索 + 推荐 占比 | 生意参谋 | 健康（不全靠买量） |
| 动销 / 滞销 | 在售动销率、滞销新增 | 库存周报 | 滞销不增 |
| 服务分 / DSR | 体验分、DSR | 商家后台 | 不掉档 |

- **具体达标数值由月度目标拆解，祥书拍板**；运营自评对标"自己上月环比 + 竞品 / 行业大盘"，不是凭感觉。
- **频率**：每周看趋势（周报里带），每月结硬账（对目标算账）。

## 十一、运营红线清单（违反必停）

1. 比价基准用天猫，不用京东价。
2. 618 期间不随意改主图，改前告知祥书。
3. 对外文案禁违禁词（"最/第一/国家级"等绝对化词、医疗功效词），详见[[03-内容创作规范]]。
4. 客户隐私不进任何对外内容。
5. 店铺后台截图、订单数据不外传。
6. 付费推广必须算 ROI，低于保本线的计划不许长期挂着烧钱。
7. 在投广告的品断货前必须停车。

## 十二、运营周报四段式模板（飞书）

```
【XX店 第XX周运营周报】
一、摘要：本周成交 X 万（环比 ±X%），完成月目标 X%。一句话定性。
二、数据：
  - 流量：访客 X，搜索/推荐/付费 占比 X/X/X
  - 转化：转化率 X%（环比），客单价 X
  - TOP3 品贡献 + 付费 ROI
三、问题：本周没达成的 / 卡住的 / 需要支持的（@相关人）
四、下周计划：3-5 条可落地动作，每条带责任人+目标
```
