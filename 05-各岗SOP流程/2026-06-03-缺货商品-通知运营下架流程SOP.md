# 【祥新公司规则】缺货商品·采购通知运营下架流程

> 生效日期：2026-06-03　发布人：邹祥书
> 适用范围：全店铺。采购 / 审单 / 助理任何渠道发现商品或 SKU 缺货时。

## 一、规则

**采购 / 审单 / 助理发现某商品（SKU）缺货（库房无货，且第三方 / 品牌短期也补不上货）后，必须立即做两件事：**

1. **发缺货通知** —— 在三方发货群（或运营群）@ 运营组，写清：**店铺 + 品牌 + 商品/SKU + 缺货情况 + 预计恢复时间（若知道）**。
2. **建下架任务** —— 给**负责该店铺的运营**建一条飞书任务，**挂【祥新任务】清单**（即写进"详情任务"），写清商品/SKU + 要求处理 + 截止时间。

> 口头喊一声不算。**必须落到飞书任务里**，否则视为没通知到位。

## 二、运营怎么处理（采购不替运营定动作）

运营收到后，**按链接情况自己判断**：

- **普通款 / 滞销款 / 非主推** → **直接下架**，别挂着拉低转化、也别让顾客下单后无法发货。
- **卖得好的爆款链接断货** → **别下架**，换同品牌新款 / 当季热款继续上，同步更新主图、标题、SKU、价格（保住链接搜索权重）。与《[[2026-06-03-运营每日工作流程-执行版]]》口径一致。

## 三、缺货恢复

商品恢复有货后，采购同样通知运营；运营按需恢复上架。

## 四、执行职责

| 角色 | 谁 | 职责 |
|---|---|---|
| 采购 / 审单 / 助理 | 罗舒怡、罗姣阳、徐鹤 | 发现缺货 → ① 群内 @ 运营组发通知 ② 给对应店铺运营建下架任务挂【祥新任务】 |
| 运营 | 各店铺负责运营 | 收到后按链接情况下架或换款；恢复有货后上架 |

> 不确定哪个运营负责该店铺 → 任务建给运营组（会签）让对应人认领，或问祥书。

## 五、为什么

采购发现缺货却没通知运营，缺货商品继续挂在店铺：① 缺货链接拉低转化；② 顾客下单后无法发货 → 超卖客诉。把"发现缺货 → 通知 + 建下架任务"固化成采购的标准动作，堵住这个缺口。

## 六、违反处理

发现缺货未按本流程通知 + 建任务的，由当班采购 / 审单人负责善后；问题登记在纠错日志。
