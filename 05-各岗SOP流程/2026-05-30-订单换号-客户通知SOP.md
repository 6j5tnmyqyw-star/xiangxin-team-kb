# 订单换号 —— 客户通知 SOP

> 适用对象：客服销售、采购对接岗（罗舒怡/罗姣阳/徐鹤）、售后处理人
> 发布：2026-05-30　负责人：邹祥书
> 触发：朱凌晨 2026-05-14 日报（某订单改地址换号未通知，客户找上来才发现）

## 一句话原则

**只要订单发货后快递单号变了，处理人 30 分钟内主动私聊告诉客户新单号。绝不等客户来问。**

## 一、什么情况算"换号"

订单已发，旧单号失效，重新发出新单号——以下场景全算：

1. 客户中途改收货地址 → 拦截退回 → 重发
2. 拦截退回（任何原因）→ 重发
3. 整单 / 部分补发（破损、丢件、漏发、错发）
4. 换货退回后重发
5. 调换商品（颜色 / 尺寸 / 型号）后重发
6. 三方发货中采购自己换快递公司 / 换号

## 二、换号后必做三件事（30 分钟内）

### 1. 私聊客户

按客户所在渠道（旺旺 / 飞书客户 / 微信）发：

> 您好，您订单 [订单号] 因 [改地址 / 拦截退回 / 补发 / 换货 / 调换商品] 已重新发出，新快递单号 **[新号]**（[物流公司]），可在 [查询入口] 查询。给您添麻烦了，有问题随时找我。

### 2. ERP 旧单号备注

> 已换新号 [新号]，原因 [...]，[日期]

### 3. ERP 新单号备注

> 原号 [旧号] 换出，原因 [...]，[日期]

## 三、旧号"显示已签收"时的加挂动作

拦截退回的旧号，物流轨迹会显示"已签收"——这是被退回到发件地的签收，不是客户签收。**通知客户时必须加一句**：

> 您原快递单号会显示"已签收"，那是被拦截退回的发件地签收，不是您本人签收，请以新单号为准。

## 四、客户主动来问"我没收到货"

1. 客服秒查 ERP 旧→新映射
2. 有换号 → 立即告知新号 + 致歉 + 解释签收口径
3. 无换号 → 走正常物流催查 / 赔付

## 五、责任归属（出问题找谁）

| 换号场景 | 通知责任人 |
|---|---|
| 改地址换号 | 处理改地址申请的客服 |
| 拦截退回换号 | 发起拦截的客服 |
| 补发 / 换货换号 | 售后处理人 |
| 三方发货采购换号 | 罗舒怡 / 罗姣阳 / 徐鹤（哪位发的找哪位） |

## 红线

1. **30 分钟内主动通知**——不能等客户找上门
2. **ERP 双备注**——旧号 + 新号都要写清楚原因 + 换号映射
3. **签收口径必说**——只要旧号显示"已签收"，通知里必须加解释那句

## 出问题怎么处理

每出一单"换号未通知→客户找上门"的，由当事人在「三方发货群」起话题登记，纠错日志 Base 同步登记。重复出现的同岗位人员，按公司绩效规则扣分（具体扣多少祥书定）。
