# 淘宝客服聊天记录抓取插件 · 需求记录

## 需求

听说**别人做了一个浏览器插件，能自动抓取淘宝后台的客服聊天记录**。
祥书想要一个同款 / 自研版本，用来**分析客服行为**。

## 想做什么（待祥书补充细化）

- 自动把天猫倍视能 / 京东倍视能 / 京东祥新运动后台的客服会话拉下来
- 结构化存储（顾客 ID 脱敏后 / 时间 / 客服账号 / 内容）
- 用来分析客服行为：
  - 响应时长
  - 话术合规（违禁词、承诺、夸大）
  - 转化漏斗（询单 → 下单）
  - 投诉/差评前兆识别
  - 个人维度复盘（哪个客服话术好、哪个需要培训）

## 待确认的问题

1. 优先级：天猫旺旺 vs 京东咚咚？还是两个都要？
2. 抓取方式：浏览器插件（Chrome 扩展）/ 油猴脚本 / 桌面端抓包 / 官方 API？
3. 数据落地：本地 CSV / 飞书多维表格 / 数据库？
4. 隐私边界：客户姓名、手机、地址必须脱敏（业务铁律 4）
5. 谁来做：祥书自研（Python + Chrome 扩展） vs 找外包 vs 买现成的？
6. 那个"别人做的插件"叫什么、在哪看到的？能不能先要个 demo / 截图？

## 合规与风险

- ⚠️ 平台 ToS：天猫 / 京东后台抓取属于灰色地带，账号有被封风险，需评估
- ⚠️ 客户隐私（业务铁律 4）：禁止把客户原始姓名 / 手机号 / 地址出现在任何 AI 输入输出，抓取后**必须先脱敏**再分析
- ⚠️ 团队心理：客服会被"全程录像"，需要提前沟通，定位是"复盘提升"而不是"监控扣分"
