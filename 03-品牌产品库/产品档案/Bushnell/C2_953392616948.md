**使用与注意**
- 旋转式调焦：顺"右"方向适合远视眼（近处看不清），顺"左"方向适合近视眼（远处看不清）
- 短按 MODE 键切换模式：扫描 / 坡度补偿 / 伙伴（球童）模式
- 长按 MODE 键切换测量单位：Y（码）/ m（米）
- 长按 SET 键进入振动设置，短按 SET 键开启 / 关闭振动
- 扫描模式操作：长按测量键不放，先瞄准旗杆后树木，准星扫过旗杆自动识别旗杆距离并振动反馈
- 坡度补偿模式：长按测量键，显示补偿距离、实际距离和高度；伴有旗杆锁定功能
- 伙伴（球童）模式：先对 A 点（自己位置）测距，再对 B 点（球友位置）测距，自动计算 AB 之间直线距离；短按 S 键可在直线模式与补偿模式间切换
- 电池显示不足时应及时充电，否则测距误差会增大
- 不要用手指触摸镜头，用擦镜布轻轻擦拭
- 避免碰撞或重压；不要烘烤、腐蚀或长期暴晒；存放在干燥、阴凉、通风处，防止灰尘和温度突变
- 不要直接对准太阳或强光源发射，以免损伤光敏器件
