## 导购要点

**1. 价位梯度清晰，按预算分类**

- **¥5000～6000 级**：轻量化主力选手  
  → Flessi 系列（超轻 40g、全系列完整）、Fiamma UT（铁木专用）  
  → 适合追求轻量但不追求极限低扭矩的业余进阶

- **¥8000～10000 级**：中高端主流  
  → α II（8 规格可选）、AAA Blade（限量 500 支）、F99、Fiamma 四代  
  → 适合职业级需求但库存相对充足的客户

- **¥15000+ 级**：旗舰限量高端  
  → AAA Pro 2025/2026、XTM Singularity（均限量 300）、The Legend 龙年（珍藏 168 支）  
  → 适合追求品质+收藏价值、预算充足的职业玩家

**2. 产品线与技术梯度**

- **Fiamma 系列**（最新代数：四代）→ 低扭矩+防右曲 → **库存最充足（165~200 支）**  
- **AAA 系列**（含 AAA Pro、AAA Blade）→ 双重加压+限量属性 → **库存紧张（8~12 支）**  
- **XTM Singularity**→ 第一代突破设计 → **极限稀缺（仅 12 支）**  
- **轻量化专线**（Flessi / Raffina DUO）→ 40g 级超轻 → **女士优先、库存不错**

**3. 限量款心理**  
- AAA Pro：每年新款（2025/2026），各限量 300 支 → 有年度收藏属性  
- The Legend 龙年：仅 168 珍藏款，¥42000 高端镇店之宝 → 展品价值  
- XTM Singularity：第一代技术突破 → 历史地位溢价

## 客服注意

**SKU 易拍错/混淆汇总**

- **AAA Pro 版本混乱**：2025/2026 各有一款，都是 ¥19800~20260，图片相似  
  → 确认前拉商品 ID 对照（933476338089 vs 1041183750022）

- **XTM Singularity 双链接问题**：  
  同一型号有两个商品链接，标价差异巨大（¥29800 vs ¥1176470）  
  → **¥1176470 那个是数据异常，客户勿拍** → 正价应为 ¥29800 左右

- **Fiamma 四代两链接**：  
  - 【The Fiamma 四代】链接：¥8800，库存 165（主力销售链）  
  - 【新款 Fiamma 四代防右曲】链接：¥5980，库存 6（待核对价格是否错标）

**限量属性协议**

- AAA Pro / AAA Blade / XTM 等限量款标注"限量 X 支" → **告知客户库存真实，避免后期缺货纠纷**
