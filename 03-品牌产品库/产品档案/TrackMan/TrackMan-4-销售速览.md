# TrackMan 4 · 销售速览（一页纸）

> 给销售/BD 转发用。参数与价格均来自 2026-10-31 阿祥提供的中文介绍册，未另编造。完整版见 [[TrackMan-4-产品介绍-重打]]。

## 30 秒怎么说

TrackMan 4 不是「单纯测一下球飞多远」的弹道仪，而是**室内外一体的完整性能方案**：专利 **OERT（光学增强雷达跟踪）= 全高清摄像头 + 双多普勒雷达**，从发球台到果岭把杆与球数据变成可练、可教、可存云端的事实；再配 Golf Pro / Performance Studio / Tracy AI，覆盖练习场、教练、模拟器与球场跟练。

## 关键卖点（话术要点）

1. **精度背书**：OERT 同步相机与双雷达，捕捉击球瞬间球的准确位置；室内搭配 Titleist RCT Pro V1 / Pro V1x，介绍册称旋转速率测量准确度最高可达 **99.5%**。
2. **真正室内外**：一套设备覆盖室内设施与室外机动场景；球场侧有 **Instant Ready**（约 **8 秒**就绪），收回后盖待机、到场打开后腿即可继续跟踪，无需重连 iOS、无需重选目标。
3. **生态闭环**：Portal / Simulator Network / Range / Pro + iPhone、iPad、笔记本应用统一体验；数据上云，教练与球员同看。
4. **教练与技师友好**：TrackMan Performance Studio（TPS）含巡回赛球员库、视频分析、挥杆对比、报告；可切教练/技师或球员模式。
5. **推杆也能量化**：Performance Putting 覆盖方向、速度控制、果岭判读；Tracy AI 基于超 **20 亿**条跟踪弹道做优先级改进提示（「Tracy 告诉你改什么，教练告诉你怎么改」）。

## 异议速回

- **「只要个测距/简单弹道」**：TrackMan 4 卖的是可教学、可经营的完整方案与生态，不是单点测距。
- **「室内准不准」**：亮出 OERT + RCT 球组合的旋转准确度表述；同时说明室外同样是同一套跟踪哲学。
- **「贵」**：对标的是教练产能、会员粘性、模拟器客单价与数据资产，不只是一台硬件；可提融资与订阅结构。
