## 二、阿祥本场展示的 7 个 AI 实践

### 实践 1：短视频自动剪辑（给老孙）
- 视频传飞书 → AI 自动提取语音 → 识别重复/语气词自动剪辑
- 下一步：豆包大模型 API 自动加视频素材 + 图片素材
- **状态**：还没完全跑通（之前剪了 2'20" → 1'30"，有问题），本周用字节的流程再试
- **老孙反应**：可以试试

### 实践 2：客服聊天记录 AI 复盘（已落地 [[lark-helpdesk-xiangshu]] skill）
- 一句话："抓最近 7 天的客服聊天记录，跟我说有什么问题"
- 倍视能旗舰店 98 条暴露 **3 个新问题**：
  1. 客户被催促产生抗拒 → 销售逼单话术触发反感
  2. 产品质量问题已跟进
  3. 充电板不耐用
- AI 自动归属责任方（凌晨/罗舒怡/彭彭）
- AI 自动派任务给嘉欣：
  - 客服话术 SOP（私密客服模板）
  - 发货质检 / 抽检流程
  - 详情页是否加产品使用视频（阿祥判断：详情一般没人放，不用弄）

### 实践 3：会议链接 → 待办 + 问题 + 流程升级
- 把运营周会链接发给 AI → **25 条待办 + 16 个问题 + 4 个升级流程**
- 本地保存 + 飞书更新
- **新规则**：以后销售周会也把链接发阿祥
- 对比：人工整理周会记录通常只能产生 1-2 个问题，AI 一次能提取 16 个，效率差距明显 → 凸显用 AI 提取的价值

### 实践 4：日报截图 → AI 自动登记纠错日志 Base
- 凌晨在群里反馈机器处理问题 → 阿祥截图发 AI
- AI 自动生成：归属（凌晨在群里反馈）+ 建议（整形二次销售）+ 处理时间（明天下午之前）+ 处理人（老孙）
- 直接登记到 Claude 纠错日志 Base，老孙看任务

### 实践 5：小爱同学复盘机器人（已落地 [[xiaoai]] skill v3）
- **每天下班 7-8 点采访阿祥**："今天干了啥、最重要的事、有没有问题"
- **只问问题不给答案**——让阿祥自己沉淀
- **每周复盘**：本周收获、推荐项目怎么样
- **基于 Obsidian 几千篇文章建立个人理解**

### 实践 6：孩子识字卡片（顺手 demo）
- 一年级识字 + 英语单词
- 加图片、加语音、根据孩子兴趣（喜欢小汽车）造句
- **几句话指令**：把一年级你这个月识一下给他做、把语音也加进去、直接放到手机文件夹
- **遗忘曲线复盘**：困难/良好/简单分级
- 凌晨提议初中孩子用 → 阿祥："工具无死角的好，看你怎么用"

### 实践 7：抖音链接 / 抖音博主 → AI 自动学习更新方法
- 看到好内容 → 发链接给 AI → AI 自动更新方法库
- "现在我是驾驶员，它是机器，我告诉我的想法，它就帮我实践"

## 三、🔥 AI 派任务的协作规则（首次公开，需固化）

> "现在我写任务我都不自己写了，都用 AI 写。AI 写得比我好。"

| 收到 AI 派的任务怎么办 | 动作 |
|----------------------|------|
| **已读类**（看一下就行的） | **直接点完成** |
| **觉得派发有问题** | 反问阿祥，调整 |
| **觉得复杂的** | 提建议跟阿祥碰 |
| **建立 SOP 类**（建立流程） | 给销售那边也发一份 |
| 时间不合理 | **可以往后推**，但最后还要看 |
| 通用 | **不要在一条任务上浪费太多时间** |

## 七、流程化沉淀点（值得固化为公司规则）

> 这部分是本场会议升级到"公司流程"的真正核心。

1. **AI 派任务的协作规则**（详见第三节，独立 SOP 草案）
2. **客服聊天记录 AI 定期复盘机制**：每周拉一次每店聊天 → AI 分析 → 派任务 / 登问题
3. **会议链接 → 待办/问题/流程 自动提取机制**：所有会议（周会、运营会、临时会）都把妙记链接喂给 AI
4. **小爱同学日复盘机制**：每天下班采访自己（先在阿祥这试，跑通推团队）
5. **日报截图法登问题**：群里反馈 + 截图 + 一句话 = 自动入 Base
6. **周报硬要求**：必须同比 + 环比 + 自己结论（不照 AI 念）→ 跟今早 5/18 运营会保持一致 [[2026-05-18-1033-周一运营会-阿祥点评待办]]
