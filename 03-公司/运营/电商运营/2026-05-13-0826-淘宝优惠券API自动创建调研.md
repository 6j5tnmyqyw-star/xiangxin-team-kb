# 问题

能不能用代码直接给淘宝/天猫商家后台批量创建优惠券？有没有比手工点更省事的现成办法？

## 背景

- 店铺：天猫倍视能旗舰店 / 京东倍视能 / 京东祥新运动
- 想法：是否能写脚本一次批量创建优惠券（店铺券 / 商品券），省掉手工在营销中心点
- 当前疑问：淘宝开放平台 (Top API) 现在对第三方调用优惠券接口卡得很严，纯店主身份能不能调？

## 待调研

1. 淘宝开放平台目前**店铺自己人**还能直接调用的优惠券接口有哪些？
   - `tmall.fuwu.promotion.coupon.*` 系列还活着吗？
   - 不需要 ISV 资质的方案？
2. 千牛工作台 / 商家工作台 是否开放给店主自建工具？
3. 第三方 SaaS（比如 网营、麦客、店小蜜、有数等）有没有提供"批量建券"的开放接口？
4. 浏览器自动化（Playwright / Claude in Chrome）路线的稳定性与合规性
5. 服务市场是否有可以"自家店铺装一下就能用 API"的应用

## 价值判断

- 如果一次性手动建一批 → 走浏览器自动化最快
- 如果长期高频（每天/每周自动发券）→ 值得折腾正规 API
- **优先级**：中（不紧急，先调研清楚再决定方向）

## 调研结果（2026-05-13 初版）

### 一、官方 API 路线（淘宝开放平台 / Top API）

- 淘宝开放平台**确实有**优惠券创建/发放接口（含批量发券，单次限授权店铺 100 张/会员）
- 但接口分等级：**公开 / 买家 / 卖家 / 商家 / 高级 / 专业**，优惠券创建大多在「商家级」以上，**需要走审批**
- 申请流程：注册开发者 → 建应用 → 申请 AppKey/AppSecret → 申请对应接口权限 → 店铺 oauth 授权
- ⚠️ 没找到「店主纯自用、不申请 ISV 就直接能调创建券接口」的便捷路径，多数攻略最后都指向"建议接入服务市场应用"

### 二、阿里官方 2026 新动向（值得重点关注）

- 2026 年阿里推出「38 大促返佣补贴计划」，附带**免费 AI 营销工具**，宣传点之一就是"帮商家精准投放优惠券"
- 含义：阿里自己在做 AI 发券工具，未来大概率以官方插件形式开放给商家，**比自己折腾 API 更靠谱**
- 行动：让运营组留意天猫商家后台 / 千牛工作台里"AI 营销/智能发券"相关入口的更新

### 三、千牛工作台原生能力

- 千牛卖家中心 →【店铺服务】→【我订购的应用】→ 优惠券设置，已经支持：
  - 店铺优惠券 / 商品优惠券 / 裂变优惠券
  - 全网渠道自动推广（详情页 + 购物车自动透出领券入口）
  - 普通券 + 有价券
- 这是**官方界面**，没有暴露 API 给商家自建脚本

### 四、浏览器自动化路线（Playwright / Claude in Chrome）

- 技术上可行：登录千牛 / 商家后台 → 模拟点击创建券
- ⚠️ 网上**没找到现成的天猫商家后台优惠券自动化案例**，意味着要自己摸 DOM、自己维护选择器
- 风控：阿里对商家后台的脚本访问有反爬，频次过高可能被风控
- 适合：一次性建一批（5-50 张），跑完就停

### 五、第三方工具

- 网上一堆 "优惠券" 工具基本都是 **淘宝客 / 返利 / 隐藏券** 方向，不是商家建券方向
- 觅芬等 SaaS 提供通用优惠券生成（非淘系）
- 没看到聚焦"天猫商家批量建券"的成熟 SaaS

## 结论与建议

| 场景 | 推荐方案 |
|---|---|
| 一次性建一批活动券 | **Claude in Chrome 跑浏览器自动化**（最快，今天能跑） |
| 长期高频自动发券 | **等阿里官方 AI 发券工具落地** + 同时关注是否值得接服务市场应用 |
| 想完全代码化、可控 | 走 Top API + 接入服务市场（成本高，得发布个应用） |

**给祥书的下一步建议**：
1. 短期：列一下未来 1 个月想批量建券的场景和数量，决定是否需要自动化
2. 中期：让运营组每周扫一次商家后台「营销中心」更新公告，找官方 AI 发券入口
3. 不建议：现在投精力自己注册 ISV / 发应用，性价比低
