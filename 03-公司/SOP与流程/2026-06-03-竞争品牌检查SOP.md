# 竞争品牌检查 SOP

每周巡查竞品/同行有没有踩品牌限价红线，发现就投诉，目的是护住各品牌的控价盘。

## 一、检查频率

- 常规期：每周 ≥ 1 次
- 活动期（618 等大促）：每周 2 次

## 二、人员分工（每人 2 个品牌）

| 负责人 | 负责品牌 |
|---|---|
| 荔枝 | 佳明、喜力克斯 |
| 红红（洪洪） | 魔镜、Vessel |
| 嘉欣 | 倍视能、fastdeer |
| 娜娜 | gocox、fit39 |

## 三、查什么

全平台扫一遍负责品牌，看竞品/同行有没有：
1. **乱价** —— 标价低于品牌限价
2. **窜货** —— 非授权渠道在卖
3. **违规参加平台优惠活动** —— 品牌方明令禁活动的还在报名（如魔镜禁优惠/禁活动）

## 四、发现违规怎么办

二选一（或都做）：
1. 在**对应品牌群**直接反馈给品牌方；
2. 或**转阳阳（罗姣阳 / 采购助理）**去安排处理。

## 五、回填留痕（必做）

发现填进飞书「**品牌检查记录**」表（竞品监控 spreadsheet 内新增页）：
- 表：竞品监控 → 「品牌检查记录」sheet
- 字段：日期 / 负责人 / 品牌 / 平台·店铺 / 发现类型 / 具体内容 / 截图链接 / 处理去向 / 状态
- **没发现也填一行"无异常"**，证明本周查过

分工速查见同表「品牌检查分工」sheet（按人配色）。
