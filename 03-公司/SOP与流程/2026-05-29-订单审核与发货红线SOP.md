# 【祥新公司规则】订单审核与发货红线 SOP

> 生效日期：2026-05-29　发布人：邹祥书
> 适用范围：全店铺，订单审核（审单）与发货安排环节
> 本篇收口"审核/发货通用红线"，与已发布的《库存不足整单转外发SOP》《调拨单与库房发货实物一致规则》《发货沟通统一到三方发货群SOP》并行执行。

## 一、审核必查（每单缺一不可）

1. **先搜后建**：审核商品一律先在吉客云按"品牌 + 型号 + 类目"搜现有货品，搜到就用现有编码，搜不到才新建。**禁止因平台标题字眼对不上就直接新建**，导致同一商品出现两个货品编码。
2. **核对备注**：必看顾客订单备注 + 客服留言 + 协商记录，按实际需求审（尺寸 / 颜色 / 快递 / 换货规格）。后台看不到的（如换货规格只写在聊天里），主动找客服或查聊天确认，**不能只按后台申请发**。
3. **礼盒 / 套装主次**：主体必须匹配价值最高的核心品（如手表），赠品只能放非核心配件。**禁止把核心品（手表 / CT1 等）当赠品**，否则后台不触发主体出库、显示未出库。拿不准的与库房确认。

## 二、见预警必停（硬红线）

吉客云弹出 **"物流单号重复 / 发货状态同步失败 / 库存异常 / 调拨异常"** 等任何预警 → **立即停手，查清原因再继续，禁止直接点"确定"放行。**

## 三、快递与单号

1. **发货即落系统（硬红线）**：安排品牌方 / 外发任何一单，**必须当场在吉客云标发 + 填收件信息和单号**；只在群里甩地址、口头说一声**不算已发货**。系统里查不到 = 视为未安排，下一个人有权按"未发"重新处理。**当天安排当天标发，不留到隔天补登。**
   > 立此条起因：HELIX（喜力克斯）一单，安排人只在群里甩了地址未标发，次日另一人查系统显示"未发"又安排一次，导致品牌方重复发货。防重复的全部前提是"安排即在系统可见"，群消息不作数。
2. 填快递单号必须与发货单据**逐一核对四要素**：订单编号、商品规格、收件信息、是否已标发——四项一致才提交，**填完回读一遍**再确认。
3. 顾客**指定快递 / 补运费差价**的单，必须按指定快递发；发错即原单驳回、重新按要求发。
4. 已标"发"的单，**改审 / 驳回前先通知原安排人**，避免两仓重复发货。

## 四、错单登记与考核

审核、发货环节拦下的差错，统一登记纠错日志（写清谁 / 哪单 / 哪类错）；**同一人同类错累计 ≥ 3 次，转专项培训并纳入考核**，不再只口头提醒。

## 五、执行职责（审单发货组，所有店铺统一）

1. **舒怡**（罗舒怡，采购兼审单）
2. **阳阳**（罗姣阳，采销助理）
3. **鹤子**（徐鹤）
4. **九一**（袁桂平，库管）：库存核对、出库核对

> 运营专员（嘉欣、荔枝、娜娜等）不直接审单发货，无需操作。异常 / 拿不准的 → 报备祥书后再定。
