# 财务岗位职责说明与优化建议

> 编制日期：2026年5月

> 适用对象：财务负责人（一人统筹四家公司全盘财务）

---

## 一、岗位概述

本岗位由一人统筹负责四家公司（祥书、球岭、分公司、迈慷）的**全盘账务、全税种报税、全员薪资核算与发放、电商数据对账、对外财务对接及财务风险控制**工作，身兼多岗，工作维度广、细节繁琐、容错率极低。

任职以来，长期满负荷、保质量完成所有财务工作，账务、税务、薪资**全年零差错、零风险**，稳定支撑公司财务合规与平稳运转。

---

## 二、工作内容详述

### 第一部分：与财务公司对接

#### 1. 银行流水整理

- 每月初下载各银行流水，逐笔备注，汇总提供给财务公司

- 下载银行电子回单备存

#### 2. 发票整理与交接

- 登录电子税务局下载全部发票

- 核查已开发票，发现错误及时沟通修改

- 接收发票按**发票类型 × 付款方式**建立文件夹分类归档，核查发票合规性，登记备注

- 编制发票交接清单，列明每月各类型发票数量，便于财务公司入账

- 提供其他财务公司所需配套文件

#### 3. 网店平台销售数据整理

- 下载所有平台销售数据、退货数据，与平台上报税务局数据比对核实

- 按**平台 → 店铺**分级建立文件夹保存并解压备注

- 记录销售退货金额，与财务公司核对并追查差异

- 下载所有店铺钱包流水，按平台分类汇总

- 下载企业微信收款数据

#### 4. 个税申报协同

- 完成工资表后拆分出财务公司申报部分，合并上月已发未申报薪资/绩效后发出

- 在财务公司完成个税系统申报后，核对申报数据准确性并确认申报

- 确保公司银行账户有足额余额用于缴税

- 实时监控高个税比例员工，预测缴费比例，必要时协调员工、领导、财务公司三方沟通调整

#### 5. 增值税申报跟进

- 全程跟踪财务公司纳税申报进度，确保在申报期内完成报税

- 核对报税金额，及时补充说明所需资料

#### 6. 政府部门配合（深圳）

- 配合经济普查、统计局、街道办等部门填报数据

- 关注深圳最新财税政策，及时提供给财务公司确认

- 处理其他临时性对接事项

---

### 第二部分：银行收付款管理

- 每日复核银行付款

- 每月汇总下载各银行流水

---

### 第三部分：代运营公司数据整理

- 定期整理合作代运营公司数据

- 需付款项目提交付款申请；需收款项目与相关人员核对确认（不定期）

---

### 第四部分：工资表编制

| 步骤 | 内容 |

|------|------|

| 考勤统计 | 导出全员考勤，逐一与员工确认 |

| 任务统计 | 统计月度任务完成情况，与负责人确认未完成项 |

| 日报/清仓对接 | 对接舒怡，汇总日报及清仓数据 |

| 扣费汇总 | 汇总社保扣费、奖罚情况 |

| 人事变动确认 | 确认绩效、新入职、离职、薪资调整等信息 |

| 工资表汇总 | 将上述数据汇总录入工资表 |

| 复核确认 | 发给阿祥复核后定稿 |

---

### 第五部分：个税申报、工资发放与工资条

1. 将工资表按四家公司拆分为独立报表

2. 汇总已发放未申报薪资、绩效等数据

3. 在个税系统逐一完成申报

4. 汇总最终发放数据，提交工资发放申请

5. 复核工资发放情况

6. 编制工资条，在发薪当日分发给全体员工

---

### 第六部分：凭证录入（金蝶系统）

> 涉及公司：祥书、球岭、分公司、迈慷（注销中）

> 工时参考：球岭/祥书各约 4–5 天；分公司/迈慷各约 1 天；每公司约 300 个凭证号

**原始凭证整理：**

- 打印银行回单（球岭回单需裁剪为凭证标准尺寸）

- 打印全部开具及接收发票，按成本/费用类型分类

- 打印工资表、社保表等需入账的凭证附件

- 打印线下收款回单对应的销售单

- 向开票方补充发票不详细项目的支撑材料（采购单、入库单等）

- 下载支付宝收付款回单，打印整理

- 下载并比对店铺销售数据与后台涉税数据，防止少报

- 向平台申请花费类发票

**凭证录入与核算：**

- 将销售数据汇总确认收入金额，按商品分类形成成本表

- 将所有凭证逐笔录入金蝶系统

- 计提员工工资、社保

- 计提固定资产折旧

- 完成收入确认、增值税核算、成本结转

- 核查库存商品余额与科目余额

- 查看当月利润情况，对需调整项目进行调整

- 暂估成本处理

- 对录入凭证进行审核核定

- 执行损益结转与结账处理

- 报税完成后打印凭证，装订成册归档留存

## 三、AI 可辅助的工作环节

以下工作环节，可借助 AI（如 Claude）直接配合完成，**节省时间、降低出错率**：

| 工作环节 | AI 可做什么 |

|----------|------------|

| **发票交接清单编制** | 提供发票数据后，自动生成分类汇总表格、交接单模板 |

| **工资表计算与核对** | 输入考勤、绩效、扣费数据后，自动汇总计算，复核公式逻辑 |

| **工资条生成** | 根据工资表批量生成个人工资条文本，逐人发送内容格式化 |

| **销售数据比对** | 提供两份数据后，自动比对金额差异，标记不一致项 |

| **个税比例预测** | 输入累计薪资数据，计算当月个税适用税率，预判全年走势 |

| **凭证整理清单** | 根据月度业务情况，生成凭证整理 checklist，逐项追踪完成状态 |

| **对账结算核对** | 输入双方数据后，自动比对，找出差异行并标注 |

| **税种申报提醒日历** | 根据各税种申报周期，生成月度/季度/年度申报提醒计划 |

| **利润表/运营报表** | 提供基础数据后，自动计算汇总，生成表格及简要分析 |

| **政策解读** | 收到新财税政策文件后，协助解读要点，评估对公司的影响 |

| **文件与邮件起草** | 起草对接函、交接说明、申请文件等各类公文 |

| **12315 投诉回复** | 提供投诉内容后，协助拟定规范的处理回复文本 |

> **不能替代的环节**：银行操作、系统登录（电子税务局/金蝶/个税系统）、原始凭证打印装订、面对面签字确认等需本人在系统内操作或具有法律效力的动作，AI 无法直接执行，但可以辅助准备好操作所需的数据和材料。

## 四、岗位价值说明与薪资调整建议

### 工作量客观评估

| 维度 | 说明 |

|------|------|

| 覆盖公司数 | 4 家公司（祥书、球岭、分公司、迈慷） |

| 账务类型 | 全盘账务，含凭证录入、报表编制、税务申报 |

| 薪资管理 | 全员工资核算、发放、工资条、个税申报全流程 |

| 电商数据 | 多平台销售数据下载、比对、归档 |

| 对外对接 | 财务公司、税务局、银行、各合作方 |

| 合规要求 | 多税种按期申报，容错率极低，零差错要求 |

| 月度工时估算 | 仅凭证录入一项：球岭+祥书约 8–10 天，分公司+迈慷约 2 天；加上其他工作，全月饱和 |

### 薪资调整建议

本岗位实际承担了**全盘财务负责人 + 薪酬专员 + 税务专员 + 电商财务对账专员**四个岗位的职能，属于**一人多岗、高度集中的关键财务岗位**。

任职以来：

- 账务、税务、薪资**全年零差错、零风险**

- 长期在满负荷状态下保质完成所有工作

- 主动识别并规避财务与税务风险

基于以上岗位职责的全面覆盖、持续饱和的工作量，以及长期稳定的工作成果，建议老板**综合评估岗位市场价值与个人实际付出，给予薪资合理调整**。

后续将继续踏实履职、严控财务风险，持续做好各项财务保障工作，与公司长期稳定共同发展。
