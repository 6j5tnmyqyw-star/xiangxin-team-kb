## 一、连接与配对

### 问题：App 搜不到 / 连不上手表，但手机蓝牙里显示「已连接」（最高频，先查这个）

**现象：** 客户说 Garmin Golf / Garmin Connect App 里搜不到、连不上手表，可是手机「设置 → 蓝牙」里 Approach S70 明明显示「已连接」。

**根因：** 佳明手表**不能**用手机系统蓝牙直接连，必须在 Garmin 的 App 里走配对流程。很多客户图方便，直接在手机蓝牙设置里点了连接，反而把蓝牙占住了，App 就识别不到手表。这是 S70 配对失败最常见的原因。

**客户自助步骤（可直接发给客户照做）：**
1. 打开手机「设置」→「蓝牙」
2. 找到「Approach S70」，点它右边那个蓝色圆圈里的 i（信息）按钮
3. 点「忽略此设备」并确认（安卓：长按该设备 →「取消配对 / 取消保存」）
4. 回到 **Garmin Golf / Garmin Connect App**，按 App 里的「添加设备 / 配对」引导重新连接
5. 配对成功后手表会自动连上，**不用**再去系统蓝牙里手动连

**一句话发客户：** 佳明手表别在手机蓝牙设置里连，要在 Garmin 的 App 里连。要是系统蓝牙里已经连上了，先点「忽略此设备」，再打开 App 配对就行。

---

### 重要提醒：实在连不上手机也别急 —— 不连手机照样能下场用

**适用：** 华为等部分安卓手机蓝牙波段不兼容，反复配不上 App，客户着急甚至想退货时，先用这个安抚。

**关键事实：** S70 是**独立 GPS 手表**，内置全球球场地图，**不连手机也能正常下场打球**：
- **照样能用**：GPS 定位、测距（前 / 中 / 后果岭、障碍区）、球场地图、记分、挥杆数据 —— 下场的核心功能全都有
- **连手机（App）只是用来**：同步和查看历史成绩、更新球场地图、接收手机通知、升级固件 —— 锦上添花，不影响打球

**客服话术：** 您手表连不上手机不影响下场用的，S70 自己就带 GPS 和球场地图，直接戴着到球场打开高尔夫模式，就能测距、看果岭、记分。连手机主要是把成绩同步到 App 看记录、更新球场，您有空再慢慢弄，不耽误打球。

### 问题：手表连不上手机 / Garmin Golf App 搜索不到

**解决步骤：**
1. 确保手机蓝牙已开启，手表和手机距离在 1 米内
2. 手表端：长按左上键 → 设置 → 连接 → 手机 → 配对手机
3. 如果之前配对过但连不上：
   - App 里删除已配对设备 → 手表恢复出厂蓝牙设置 → 重新配对
4. 检查 Garmin Golf App 是否有更新（App Store/应用商店更新到最新版）
5. 关闭手机蓝牙 → 重启手机 → 重新打开蓝牙 → 重试

**进阶排查：**
- 手表同时只能连一台手机，先断开其他设备的蓝牙连接
- 安卓手机检查是否授予 Garmin Golf App「位置权限」（部分安卓型号必须有位置权限才能发现蓝牙设备）

---

### 问题：频繁断连 / 蓝牙连接不稳定

**解决步骤：**
1. 清除 Garmin Golf App 缓存（设置 → 应用 → Garmin Golf → 清除缓存）
2. 确保手表固件是最新版本（App 内 → 设备 → 系统 → 软件更新）
3. 避免在有多个蓝牙设备的拥挤环境配对
4. 部分手机省电模式会杀后台 → 设置 Garmin Golf App 为「不限制后台活动」

## 二、GPS 与球场地图

### 问题：GPS 定位慢 / 搜不到信号 / 位置不准

**解决步骤：**
1. **首次使用或换了新球场**：走到室外开阔地带，静止等待 30 秒-2 分钟
2. 手表端：设置 → 系统 → GPS 模式，确保选择「GPS + GLONASS」或「GPS + Galileo」
3. 如果一直搜不到：连接手机 App → 同步数据（手表会通过手机下载星历数据加速定位）
4. 注意：室内、桥下、密林会遮挡 GPS 信号

---

### 问题：球场地图不完整 / 球场信息错误

**解决步骤：**
1. 连接手机 App → 进入「设备」→「管理球场」→ 检查该球场是否已下载
2. 如果已下载但信息不对：删除该球场 → 重新下载
3. 如果球场不在库里：通过 Garmin 官网提交球场更新请求
4. 建议每季度连接 App 做一次地图更新

---

### 问题：手表提示「未找到球场」但明明在球场

**解决步骤：**
1. 确认手表 GPS 已定位成功（表盘显示绿色 GPS 图标）
2. 启动「Golf」活动 → 手表会自动搜索最近球场
3. 如果还是找不到：手动选择 → 按菜单键 → 选择球场 → 搜索/输入球场名称

## 三、充电与电池

### 问题：S70 电池耗电快 / 用不到宣称的天数

**标准续航说明（Garmin 官方数据）：**
| 模式 | 续航 |
|------|------|
| 智能模式（手表模式） | 约 16 天 |
| GPS 模式（打球） | 约 20 小时 |
| 省电模式 | 约 32 天 |

**解决步骤：**
1. 关闭不必要的功能：心率监测、血氧、Always-On 屏幕常亮是最大耗电源
2. 缩短屏幕超时时间（设置 → 系统 → 背光超时→ 8秒）
3. 降低屏幕亮度（不要设自动亮度）
4. 如果睡觉不戴：开启「睡眠模式」或关机
5. 检查是否有后台同步 → App 内关闭自动同步

**如果掉电异常快（一天掉 30%+）：**
- 重启手表（长按左上键 15 秒强制重启）
- 恢复出厂设置（注意：会清除数据，先同步到 App）
- 如果以上都不行 → 硬件问题，联系售后换机

---

### 问题：充电充不进去 / 充电接触不良

**解决步骤：**
1. 检查充电触点（手表背部 4 个金属点）是否干净 → 用干布擦拭
2. 检查充电线接口是否有异物
3. 换一个充电头（5V/1A 即可，不要用快充头，可能不兼容）
4. 换一根充电线测试（S70 与 S62/S60 充电线通用）
5. 充电时确保手表放平，磁吸对准

## 四、App 与数据同步

### 问题：打球数据不同步到 App / 数据丢失

**解决步骤：**
1. 确保打完球后「保存并结束」了该轮活动（没保存 = 没记录）
2. 打开 Garmin Golf App → 下拉刷新 → 等待同步完成
3. 如果 App 没同步：强制关闭 App → 重新打开 → 手表靠近手机
4. 如果同步按钮灰色：检查手机网络（WiFi 或蜂窝数据）

---

### 问题：App 闪退 / 打不开 / 更新失败

**解决步骤：**
1. 卸载 Garmin Golf App → 重启手机 → 重新安装
2. 检查手机系统版本是否过旧（iOS 15+ / Android 10+）
3. 如果是更新固件失败：确保手机电量 > 50%，手表电量 > 20%，WiFi 网络稳定

---

## 五、手表功能

### 问题：触摸屏反应迟钝 / 卡顿

**解决步骤：**
1. 重启手表（长按左上键 15 秒）
2. 检查手表存储是否过满（设置 → 系统 → 关于 → 检查存储空间）
3. 如果屏幕有水渍或汗渍 → 擦干后再操作
4. 贴膜可能影响触控灵敏度 → 建议用 Garmin 官方推荐贴膜

---

### 问题：心率监测不准

**解决步骤：**
1. 确保手表贴合手腕，不要戴太松（光学心率传感器需要贴紧皮肤）
2. 手腕骨上方 1-2 指宽度是最佳佩戴位置
3. 冬天血管收缩会导致读数偏低 → 热身 5-10 分钟后读数会稳定
4. 深色皮肤、纹身、过于浓密的汗毛可能影响光学心率准确性
5. 如果持续不准 → 可能传感器故障，走售后

---

### 问题：挥杆节奏 / Tempo Training 无数据

**解决步骤：**
1. 确保开启了「挥杆节奏」功能（设置 → 高尔夫设置 → 挥杆节奏 → 开启）
2. 启动「Golf」活动 → 开始打球 → 每次挥杆后手表会自动记录
3. 如果仍然无数据：检查传感器是否被遮挡，手表佩戴是否正确
4. 注意：练习场挥杆可能不会被记录（需要实际球场模式）

## 六、售后与退换

### 常见售后场景快速判断

| 现象 | 判断 | 处理 |
|------|------|------|
| 无法连接手机 | 90% 是设置/App 问题 | 按第一章节排查 |
| 定位慢 | 首次使用正常 | 室外等待 + App 同步星历 |
| 电池一天掉光 | 先排查设置 | 关闭常亮/血氧 → 如无效走售后 |
| 屏幕花屏/黑屏 | 硬件故障 | 直接走售后 |
| 表带断裂 | 耗材，保修期内可申请 | 联系 Garmin 客服 |
| 进水/进水损坏 | 正常使用防水 5ATM | 非人为损坏走售后 |

## 七、其他常见问题（佳明问题汇总整合）

### GPS / 球场

**初次拿到手表显示英文球场？**
不是故障，是还没定位到当地球场。戴到户外开阔处，等 GPS 定位成功（约 30 秒-2 分钟），会自动加载当地球场。

**不显示球道图？**
进高尔夫设置 → 关闭「大数字」显示，球道图就出来了。

> S70 内置全球球场地图，开机定位后直接能打全球，无需先连手机下载。

### 功能与设置

**果岭坡度 / 高级功能要不要花钱？**
果岭坡度等高级功能需购买 Garmin Golf 会员。目前会员**仅支持苹果手机购买和使用**，安卓暂不支持；用苹果账号买了之后换安卓手机登录同样用不了。**下单前务必如实告知安卓用户这一限制，让客户知情后再决定**，避免售后纠纷。

**抬腕不亮屏？**
长按左中键 → 设置 → 系统 → 背光 → 活动期间 → 开启「抬手背光」，同时关闭勿扰模式（长按左上键切换勿扰）。

**微信运动读不到手表步数？**
在微信里关注并绑定「佳明爱运动」公众号，按引导授权后，手表数据就能同步进微信运动。

**睡眠质量检测？**
在 App 里设好就寝时间，第二天睡眠数据会自动同步到 App。

**换表带买多大尺寸？**
S70 白色 / 灰色是 20mm 快拆表带，黑色是 22mm（S62 是 22mm），买错装不上；拆卸方法见官方教学视频。

### 安卓连接补充

安卓手机若装了**最新版** App 反而连不上，可到佳明官网 garmin.com.cn/codelist 下载匹配版本重试；安卓配对等待时间可能较长，多试两次。

### 佳明官方客服

- 电话：**400-819-1899**（周一至周六 8:30 - 17:00）
- S70 中文说明书：https://download.garmin.com/cn/download/manuals/approachS70_OM_ZH-CN.pdf

## 快速话术模板

**客户说「连不上手机」：**
> 您先试试：App 里把设备删掉 → 手表重启 → 重新配对。如果还不行，检查一下手机蓝牙和 App 是不是最新版，我截图教您。

**客户说「电池不耐用」：**
> S70 标准续航是 16 天，如果您开了屏幕常亮和血氧监测，正常是 7-10 天。您可以在设置里关掉常亮显示和血氧，如果关了之后还是掉电很快，可能就是异常了。

**客户说「球场找不到」：**
> 您走到室外开阔地，打开高尔夫模式，手表会自动搜索附近的球场。如果还找不到，可能是球场没下载，连接 App 后到「管理球场」里下载一下就好。
