# 未成交顾客再跟进话术库 v1

> 客户聊了半天没下单、或者聊着聊着不回了，怎么再开口——这份给你 9 种常见情况的标准跟进话术，**复制改一下称呼/型号就能发**。
> 红线照《AI客服话术指南 v1》执行，违反任何一条都不能发。

## 一、跟进 5 条总原则

1. **先看聊天记录再发**，别盲目群发同一句。客户卡在哪一步，就接哪一步。
2. **换角度发图比干问"定吗"管用**：发不同款实拍、上身/上场景图、对比图，比反复催有用。
3. **超 3 天没回复，要给个"由头"再开口**：到货了 / 有活动 / 帮您争取了优惠 / 新色到了——不要空催"在吗""考虑好了吗"，更不要连发刷屏。
4. **可以直接一点**：跟进到位了就帮客户拍板——"哥，咱就定这款？我直接帮您下单"，别一直绕。
5. **一次一条消息**，给完话给个推进动作（预留 / 申请优惠 / 视频选购），不要让客户"自己去看详情页"。

## 二、9 种情况 · 标准话术

> 千牛快捷码是建议，自己在千牛快捷回复里设成顺手的就行。称呼按男哥女姐 / 教练 / 总，知道姓就带姓（王哥、李姐）。

### 1. 颜色 / 款式纠结型
- **什么时候用**：客户问完颜色款式开始犹豫，"我再想想颜色"
- **跟进时机**：当天聊完 或 次日
- **话术**：姐，纠结颜色太正常了，毕竟要用挺久。我把您看的这两个色实物图都拍给您对比一下，现货都有，我先帮您预留着，您不着急慢慢定。
- **千牛码**：`跟进-颜色`

### 2. 家人 / 球友商量型
- **什么时候用**："我跟家里 / 我先生 / 球友商量一下"然后没下文
- **跟进时机**：次日
- **话术**：哥，跟家里商量得怎么样啦？要是拿不准，咱可以视频，我把功能给您和家人演示一遍，一起看更直观。您方便了招呼我一声就行。
- **千牛码**：`跟进-商量`

### 3. 价格观望 / 等活动型
- **什么时候用**："等等看有没有活动""现在买亏不亏""618 会不会更便宜"
- **跟进时机**：当天
- **话术**：哥，想等个合适的价我特别理解。现在到 618 期间下单后 15 天内同店降价都能申请保价，差价原路退给您，所以先拍不吃亏，后面有动作我自动帮您申请补差。
- **千牛码**：`跟进-保价`
- **注意**：比价口径以天猫为准；不要替客户瞎承诺"618 一定降"。

### 4. 沉默不回 / 已读不回型（超 3 天）
- **什么时候用**：超 3 天没任何回复
- **跟进时机**：第 3 天起，带"由头"开口
- **话术**：哥，前两天给您看的那款我一直帮您留意着。这两天刚好有个老客优惠我也帮您争取了一份，想着先跟您说一声。您要是还在考虑，随时招呼我。
- **千牛码**：`跟进-沉默`
- **注意**：别催别刷屏，一次只发一条；没有真活动就换成"新色到货 / 同款补货"做由头，别编。

### 5. 型号对比纠结型
- **什么时候用**：在两款之间反复犹豫（如 S70 vs R50、V6 vs V7S、XM vs V7S）
- **跟进时机**：当天
- **话术（填型号）**：哥，这俩我帮您理清楚：（型号A）适合（场景A），（型号B）适合（场景B）。按您说的（您的需求），我更推（X）。要不我把两款实拍和参数发您，一眼就清楚。
- **千牛码**：`跟进-对比`
- **注意**：S70 是 GPS 手表、R50 是便携雷达，**不是一个品类，别混着对比**；拿不准型号差异先查《AI客服话术指南 v1》产品速查。

### 6. 超预算 / 觉得贵型
- **什么时候用**："有点超预算""太贵了"
- **跟进时机**：当天
- **话术**：哥理解，预算这块咱不硬来。您主要是想要（核心需求）对吧？我这边有个更合适的型号，功能够用、价格也舒服，发您看看？合适咱再定。
- **千牛码**：`跟进-预算`
- **注意**：不要说"别家便宜是因为代发 / 清库存"这类话——只讲咱们正品 + 保价 + 售后。

### 7. 怕买错 / 新手不懂型
- **什么时候用**：新手，"我不太懂""怕买错"
- **跟进时机**：当天
- **话术**：哥您是刚开始打吧？这个真不用纠结，我按您的水平给您推个好上手、容错高的，拿到手直接能用。有不懂的随时问我，售后我全程帮您跟。
- **千牛码**：`跟进-新手`
- **注意**：客户求推荐又没点名球杆品牌 → 主推 XXIO（容错强、好上手）；已点名按客户意愿，不硬塞。

### 8. 临时有事 / 说回头看型
- **什么时候用**："我先忙""回头再看"然后消失
- **跟进时机**：次日
- **话术**：哥，您前两天看的那款我帮您记着呢。您先忙，等您有空我把要点一次性发您，省得来回翻。需要的话我先帮您留个货？
- **千牛码**：`跟进-回头`

### 9. 老客户复购 / 回访型
- **什么时候用**：成交过的老客户，有新品 / 活动想唤回
- **跟进时机**：新品上架、活动节点
- **话术**：哥，好久没招呼您啦。最近（新品 / 活动）上了，想着您可能用得上。您之前那款用着还顺手吧？有需要随时帮您参谋。
- **千牛码**：`跟进-老客`
- **注意**：老客户如果是抱怨"买了没多久就降价" → 先共情再帮申请补差（保价工单走原渠道退），见《AI客服话术指南 v1》。

## 三、进阶 · 复杂客户用 AI 出定制话术

超 3 天的、或者聊天记录很长拿不准怎么接的客户，把**脱敏后**（抹掉姓名/手机号/订单号）的聊天记录丢给「迎客·客服副驾」，让它按这个客户的具体情况出一条定制跟进话术，比套模板更贴。

## 四、发出前自查（照《指南 v1》第七节）

- [ ] 没说"亲 / 亲亲 / 美女"，称呼对（男哥女姐 / 教练 / 总）
- [ ] 没出现"微信 / 支付宝 / 红包 / vx"
- [ ] 没暴露内部信息（库存深 / 利润 / 自营 / 代发 / 清库存）
- [ ] 没出现客户姓名 / 手机号 / 订单号 / 地址
- [ ] 一条消息发完，没拆成好几条；给了推进动作不是空催
