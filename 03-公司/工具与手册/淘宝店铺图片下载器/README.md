# 淘宝店铺图片下载器

下载**自家**淘宝/天猫店铺商品的全部图片（主图 / 3:4长主图 / SKU颜色图 / 详情长图 / 主图视频），
零反爬——走卖家后台、不碰买家详情页。

## 怎么用（最简单）

**双击 `淘宝店铺图片下载.command`**，弹出菜单：

1. 下载全店所有在售商品的图
2. 下载指定商品（粘贴商品ID或链接，可多个）
3. 设置定时：每天自动扫新上架商品下图
4. 取消定时
5. 退出

图片默认存到 `~/Downloads/淘宝店铺图片/`，按 `商品名_ID/{01-主图,02-3比4长主图,03-SKU颜色图,04-详情长图,05-主图视频}/` 归类，全是原图。

## 三个前提（重要）

1. **Chrome 开着 + 登录目标店铺的千牛**。脚本读你的登录态打开自己商品的后台发布页，不存账密。
   - 想下哪个店的图，就在 Chrome 里登那个店的千牛（换店不用改代码）。
2. **不要挂代理/VPN**。淘宝必须走国内网络，挂代理反而触发风控。
3. 第一次双击若提示"无法打开"，到 系统设置→隐私与安全性 点"仍要打开"。

## 定时自动跑

菜单选 3，输入每天几点跑（建议选白天电脑开着、Chrome 登录的时段，比如 9 点）。
之后每天自动**只下新出现的商品**（扫描全店、和上次记录对比，新增的才下）。

- 到点时如果 Chrome 没开或千牛掉登录，当次自动跳过（不会乱报错）。
- 日志看 `state/cron.log`，每次结果摘要在 `state/last_run.json`。
- 取消：菜单选 4。

## 命令行用法（进阶）

```bash
cd ~/work/taobao-shop-images
MODE=ids  ITEM_IDS=1046638400847,1045007898948  browser-harness < shop_images.py   # 指定商品
MODE=all  browser-harness < shop_images.py                                          # 全店
MODE=scan browser-harness < shop_images.py                                          # 只下新增
# 可选: OUT_DIR=自定义输出目录   MAX_PAGES=限制翻页数(默认80)
```

## 原理（为什么不会被反爬）

打开自己商品的发布页 `item.upload.taobao.com/sell/v2/publish.htm?itemId=<ID>`，
该页服务端把整份商品数据直出在 `window.Json`，里面分门别类带着所有图片 URL。
图片本体都在 `img.alicdn.com` 公共 CDN，直接 http 下载、CDN 不设防。
全程只点自己卖家后台，不打开买家详情页（baxia/滑块的高发区），不刷新、不裸打接口。
