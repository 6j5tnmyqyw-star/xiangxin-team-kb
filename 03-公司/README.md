## 不放什么

- 财务流水、利润表明细、拿货价、返点
- 客户姓名、手机、地址、订单号
- 供应商报价单、账期、对公账号
- 工资和人事评价

库存**数字**去吉客云查。本栏只保留流程说明（例如审单、发货、缺货下架）。待办以飞书任务为准，不在这里长期堆个人待办。
