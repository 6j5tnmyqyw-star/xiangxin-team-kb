# 祥新公司·团队知识库

> 给每一位同事(尤其新加入的)看的公司说明书。看完这里,你就懂我们公司怎么运转、你的岗位怎么干、遇到问题去哪查。

## 这是什么

这是祥新 / 倍视能 / 祥子爱马仕的**团队共享知识库**,用 Obsidian 打开阅读。里面有:

- 公司全景、团队、品牌、店铺(新人第一站)
- 各部门的规则和 SOP(你的岗位怎么干)
- 客服话术库(怎么跟客户说)
- 品牌产品知识(我们卖什么)
- 业务 AI 技能(AI 能帮你干哪些活)

> 这个库是**公司统一维护的权威源**,阿祥(邹祥书)管。内容会持续更新,你只要定期"拉最新"就行(见下面)。

## 新人怎么用(按顺序)

0. **先把这个库装到你电脑** —— 看 [[00-新人必读/00-怎么把这个库装到你电脑]](第一次约 15 分钟,之后更新只点一下)
1. **读 [[00-新人必读/01-公司全景]]** —— 5 分钟搞懂公司是干嘛的、有哪些品牌店铺、谁负责什么
2. **必读 [[00-新人必读/02-客户隐私红线]]** —— 🔴 上岗前必须看,违反要担责
3. **找到你的岗位规则** —— 进 [[01-部门规则]],按你的岗位看对应那份(运营/客服/采购/库房/财务/短视频)
4. **日常遇到问题** —— 客服话术去 [[02-客服话术]],产品问题去 [[03-品牌产品库]],AI 能帮什么去 [[04-业务技能]]

## 怎么保持最新(同步)

这个库通过 Git 同步。公司这边一更新,你拉一下就是最新:

```bash
cd <你电脑上这个库的路径>
git pull
```

> 不会用命令行也没关系,装好后会有人一次性教你"拉最新"这一个动作,平时就点一下。

## 发现问题 / 有更好的做法

看到规则写错了、或你有更好的话术/流程,**别自己默默改**——在工作群 @ 阿祥说一声,或登记到纠错日志,他审过后统一更新进来。这样大家看到的永远是同一个版本,不会各干各的。
