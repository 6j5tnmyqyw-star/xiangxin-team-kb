# 祥新团队知识库

> **给每一位同事的公司说明书。** 同事分属不同公司主体都可以读。读完后，按下面五步把共享内容落到**你自己的本地 Obsidian 库**。
> 这个 GitHub 仓库是**完整脱敏权威源**，已经公开：clone 即可，**不用 GitHub 邀请、不用把用户名发给阿祥**。
> 飞书「祥新团队知识库」是在线可读框架 + 核心规则。私人内容（日记 / 家人 / 财务流水 / 拿货价）**不进**。

仓库地址：https://github.com/6j5tnmyqyw-star/xiangxin-team-kb

```bash
git clone https://github.com/6j5tnmyqyw-star/xiangxin-team-kb.git
```

Clone 完成后，用 Obsidian **Open folder as vault**（打开文件夹作为仓库）打开这个文件夹。不要打开成里面的某一个子文件夹。

## 标准五步

> 目标：**读飞书知识库 → 配好工具 → 把公司共享内容写进各自的 Obsidian。**

| 步 | 做什么 | 说明 |
|---|---|---|
| **1** | **配置好飞书机器人** | 装 Node + `lark-cli`，用公司飞书账号登录（`--as user`）。这是全员底座。 |
| **2** | **安装好 Obsidian** | 用 **GitHub / 命令行**安装，**不要去官网点下载**。 |
| **3** | **工作目录定位到 Obsidian 库** | 打开本仓库（或你自己的 vault），把 AI 客户端的工作目录指到**该库根目录**。没有桌面客户端也可以先用飞书机器人 + Obsidian。 |
| **4** | **写好 Obsidian 的规则与参考** | 库根放规则文件（我是谁 / 岗位 / 落盘规则 / 飞书段 / 安全红线）。本仓库根上的 `CLAUDE.md` 就是团队规则。 |
| **5** | **把公司共享内容弄进去** | 直接把本仓库当 vault 打开；或把规则 / SOP / 话术 / 产品知识投影进你本地库的**同名栏目**。 |

## 怎么保持最新

```bash
cd xiangxin-team-kb
git pull
```

也可以用 GitHub Desktop 的 `Fetch origin` / `Pull`。看之前先拉一下。细节见 [[00-新人必读/05-公司库更新怎么到你电脑（同步节奏与个人笔记怎么放）]]。
