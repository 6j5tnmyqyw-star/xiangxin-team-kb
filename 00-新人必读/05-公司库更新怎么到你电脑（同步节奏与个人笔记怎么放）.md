# 公司库更新怎么到你电脑

> 一句话：公司库是「只读的教材」，你自己的东西放 `_我的笔记/`，两边永远不打架；更新自动流到你电脑，AI 下次对话就用上了。

## 一、谁改、谁收

- **改库的只有阿祥和 AI**。你们所有人都是「收」，不要直接改库里的文件（改了下次同步会被覆盖回去）。
- 发现规则错了 / 有更好的做法 → 去纠错日志 Base 选「规则建议修改」留一条。AI 每周收一次，采纳了改进库，全员自动拿到——这就是你参与改规则的方式。

## 二、更新多久到你电脑

| 你是哪种装法 | 怎么收更新 | 滞后 |
|---|---|---|
| Obsidian 装了 Git 插件（推荐） | 自动拉取，不用管 | ≤1 小时 |
| 只装了 GitHub Desktop | 每天上班第一件事点一下 `Fetch origin` → `Pull` | 你点了才有 |

- 设置方法：Obsidian → 设置 → 第三方插件 → 搜「Git」→ 启用 → 把 `Auto pull interval` 设 60（分钟）。装一次，以后永远不用管。
- **重要规则变更不靠你自己发现**：铁律 / SOP 级的改动，阿祥会在飞书群发通知。看到通知后手动拉一次（或等自动拉取）即可。日常小更新（补资料、修错字）静默到达，不另行通知。

## 三、更新下来跟你自己的东西怎么相处

- **你的笔记、草稿、个人记录 → 全部放 `_我的笔记/` 文件夹**。这个文件夹：①不会被同步覆盖 ②不会上传到公司库，放心写。
- 公司库其它文件夹 = 公司维护区，**只读**。AI 每次对话都是现读这些文件，所以拉取下来 = 立即生效，没有"安装/重启"这一步。技能（`.claude/skills/`）同理，拉取即更新。
- 你不改公司文件 → 同步永远不会有冲突。这是整个设计能傻瓜化的原因。

## 四、翻车自救（30 秒）

万一手滑改了公司文件、同步报错，跟你的 AI 说一句：

> 帮我把公司知识库恢复成官方最新版（git fetch + reset --hard origin/main），`_我的笔记/` 不要动。

恢复后你的个人笔记原样还在。

## 五、闭环全图

```
阿祥/AI 改库 → 推上 GitHub（每天 3:40 自动 / 随手动推）
      ↓
你的 Obsidian 自动拉取（≤1小时）
      ↓
Obsidian / 飞书机器人 / 指到本库的 AI 用上新规则
      ↓
你用出问题 / 有建议 → 纠错 Base「规则建议修改」
      ↓
AI 每周收口 → 阿祥拍板 → 改库 → 回到第一步
```
