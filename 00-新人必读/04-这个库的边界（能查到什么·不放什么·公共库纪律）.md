# 这个库的边界（能查到什么 · 不放什么 · 公共库纪律）

> 适用：全公司同事。1 分钟读完。让你知道这个库**能帮你查到什么**、**不要指望它有什么**，以及它装到你电脑后**该怎么对待**。

## 一、这个库里能查到什么

这是**规则、流程、产品知识、话术**的统一权威源——“怎么干、怎么说、卖的是什么”：

- 公司全景 / 团队花名册 / 客户隐私红线（[[00-新人必读/01-公司全景|公司全景]]）
- 各部门规则 + 各岗 SOP（运营 / 客服 / 采购 / 库房 / 财务流程 / 短视频）
- 客服话术库 + 售后知识库（含 Garmin、倍视能高频问答）
- 品牌产品知识（GPS / 测距仪 / 球杆选购）
- 内容创作（文案库 + 选题 / 口播方法论）
- AI 能帮你干哪些活（[[07-AI协作/业务技能/00-AI能帮你干哪些活|业务技能]]）

> 拿不准某个流程怎么走、某句话怎么跟客户说、某个型号什么参数——先来这里搜。

## 二、这个库里**不会有**什么（别找，也别问 AI 要）

下面这些**永远不进**这个库，是公司刻意的边界，不是漏传：

- 🔴 **客户隐私**：姓名 / 手机 / 地址 / 订单号（见 [[00-新人必读/02-客户隐私红线|客户隐私红线]]）
- 🔴 **具体钱数**：工资 / 提成 / 利润 / 销售额明细 / 拿货价 / 返点 / 银行流水
- 🔴 **供应商报价**：哪家多少钱、账期、返利
- 🔴 **个人内容**：阿祥的日记 / 家庭 / 健康 / 个人想法——跟你工作无关，也不该在这

> 所以你用飞书机器人或任何 AI 客户端配合这个库干活时，**别让它去这个库里翻财务数字或客户信息**——这里本来就没有。要这类数据，走飞书 / 找主管。

## 三、公共库纪律（这个库现在同步到你电脑了）

你 `git pull` 之后，这个库就在你电脑上了。三条纪律：

1. **以读为主，别自己默默改。** 看到规则写错、有更好的话术 / 流程——在工作群 @阿祥 说一声，或登记纠错日志，他审过后**统一更新进来**。这样大家看到的永远是同一个版本。（怎么提见 README「发现问题」一节）
2. **绝不把客户数据 / 个人隐私写进这个库的任何文件。** 这是 git 共享库，你加进去的东西全公司都会拉到。哪怕是临时笔记也别放——要记个人东西，记自己电脑别处。
3. **库里的东西属于公司内部资料，不外传。** 不发公司外的群 / 朋友圈 / 个人微信。

## 一句话

**这里是“怎么干 / 怎么说 / 卖什么”的统一答案；钱、客户、个人的事这里没有也别放。看到错的 @阿祥，别自己改。**
