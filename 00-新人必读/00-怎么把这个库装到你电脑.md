## 第 1 步：配置好飞书机器人

这是全员必配。换 AI 软件时，飞书这边尽量不动。

### 装 Node.js

Mac：

```bash
brew install node
node --version
```

Windows：打开 https://nodejs.org/zh-cn/download 安装 LTS，然后在命令提示符里执行 `node --version`。
提示「不是内部或外部命令」就先重启电脑，还不行找阿祥。

### 装并登录 lark-cli

```bash
npm install -g @larksuiteoapi/lark-cli
```

`npm` 卡住时：

```bash
npm config set registry https://registry.npmmirror.com
```

Windows 若权限不足，用管理员身份重开命令提示符再装。

```bash
lark-cli auth login
```

浏览器里用**你的公司飞书账号**授权。第一次若提示权限不够，跟阿祥说一声，他在飞书后台批 scope。

验证（能列出你的群，或能看到自己是谁，都算通了）：

```bash
lark-cli im chat list
lark-cli auth whoami --as user
```

## 第 2 步：安装好 Obsidian

**不要**打开 https://obsidian.md 点下载。统一从 GitHub 发布页或下面的命令安装：

https://github.com/obsidianmd/obsidian-releases/releases

装完后：左下角齿轮 → Language →「简体中文」。

Mac：

```bash
brew install --cask obsidian
```

Windows（PowerShell）：

```powershell
winget install --id Obsidian.Obsidian -e
```

Linux 用 AppImage，命令见 [[07-AI协作/团队AI装机手册]] §3.1。版本号以发布页最新为准。

## 第 3 步：工作目录定位到 Obsidian 库

### 先把公开库 clone 下来

需要本机有 Git。Mac 可 `brew install git`；Windows 可 `winget install Git.Git`。也可以用 GitHub Desktop 克隆，**公开库不用等邀请**。

```bash
git clone https://github.com/6j5tnmyqyw-star/xiangxin-team-kb.git
```

建议放在你记得住的位置（例如文档目录），不要放在一堆临时下载里。

### 用 Obsidian 打开这个文件夹

1. 打开 Obsidian
2. 选 **Open folder as vault**（打开文件夹作为仓库）
3. 选中刚才 clone 的 **`xiangxin-team-kb` 文件夹本身**
4. 从本页和仓库根的 [README](../README.md) 开始读

选错成里面的 `03-公司` 或 `05-知识`，链接和根规则都会对不上。

### 若你已经有 AI 客户端

把工作目录 / 项目目录指到 **vault 根**（这个 `xiangxin-team-kb` 文件夹，或你自己的库根）。不要指到桌面或整个用户目录。

没有桌面 AI 客户端不影响：飞书机器人 + Obsidian 就能用。

你已经有自己的 Obsidian 库、不想开两个库时：把本仓库 clone 进你的库，当作只读子文件夹 `xiangxin-team-kb`。这个子文件夹**只看、不改、不往里放自己的笔记**，尤其不要放带客户信息的文件。私人日记仍放在你自己的库里。

## 第 4 步：写好 Obsidian 的规则与参考

本仓库根目录的 `CLAUDE.md` 就是团队规则（身份边界、隐私红线、业务铁律、导航）。文件名先保持这个，已经在用的工具还能加载它。

你**自己的** vault 根上，另放一份规则，写清：

- 你是谁、岗位
- 新文件默认写到哪（建议 `_待整理/`）
- 飞书段：本机已装 `lark-cli`，登录的是你的公司飞书；外发、群发、@ 别人、改别人文档，先给你看草稿
- 安全红线：客户隐私不进 AI；工资和人事评价不进 AI；密钥不进库、不进群

示例飞书段见装机手册 §2.4。

## 第 5 步：把公司共享内容弄进去

本仓库打开之后，栏目已经是团队骨架，内容在对应文件夹里：

| 你要的 | 在这里 |
|---|---|
| 新人必读、隐私、花名册 | `00-新人必读/` |
| 部门规则 | `08-公司知识库/` |
| SOP、话术、会议、店铺说明、工具 | `03-公司/` |
| 公司号文案 / 选题 | `04-内容创作/` |
| 产品档案、选购知识 | `05-知识/高尔夫与产品/` |
| 装机手册、业务技能 | `07-AI协作/` |
| 通用模板 | `99-模板与附件/` |

若你用的是**自己的 vault**，而不是直接打开本仓库：在你的库里建**同名栏目**，把上面这些共享正文放进对应栏。缺口写「待补」，并注明应放什么。

**不要**在团队库或即将推回 GitHub 的目录里建：`01-每日`、`02-人物`、`06-读书`、`09-我的认知系统`。
**永远不要放进去**：财务流水、拿货价、供应商报价、客户隐私、工资数字。

之后日常：飞书看最新框架；本地 vault 给你（或你的 AI）读。公司更新后，在本仓库目录执行：

```bash
git pull
```

GitHub Desktop 用户：打开后点 `Fetch origin`，变成 `Pull` 再点一次。看之前先拉。

## 一条铁律：别自己在本地改公司文件

看到内容有错，或你有更好的话术，**不要改完就算了**。你改的别人看不到，下次 `git pull` 还会被盖掉。

正确做法：工作群 @ 阿祥，或登记纠错日志。好方法跟 AI 说「回传总库」。见 [[06-发现好方法怎么回传总库]]。

个人草稿放 `_我的笔记/`（已在 `.gitignore` 里，不会上传）。

## 翻车了看这里

| 情况 | 处理 |
|---|---|
| `git clone` 要登录 / 说没权限 | 确认地址是上面的公开仓库。公开库不需要邀请。还不行把报错发阿祥 |
| `lark-cli` 找不到命令 | `npm install -g @larksuiteoapi/lark-cli`（Windows 用管理员） |
| `auth login` 权限不够 | 找阿祥加飞书应用 scope |
| Obsidian 里链接是空的 | 用 **Open folder as vault** 打开的是仓库根，不是子文件夹 |
| 有人让你去官网下 Obsidian，或去下豆包电脑版 | 以本页和装机手册为准：Obsidian 走 GitHub / 命令行；豆包电脑版不必下 |

完成度对照装机手册 §8。飞书机器人配通、Obsidian 能打开本库，就可以跟阿祥报到。
