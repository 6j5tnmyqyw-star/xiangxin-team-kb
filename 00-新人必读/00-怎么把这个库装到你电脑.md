# 怎么把团队知识库装到你电脑上(新人第一件事)

> 这个库放在网上(GitHub),你要把它"下载"到自己电脑,用 Obsidian 打开来读。
> 全程不用敲命令,跟着图形界面点就行。**第一次装大概 15 分钟,装好之后每次更新只要点一下。**
> 实在搞不定,找同事帮你装一次,之后你自己只需要会"点更新"那一步。

---

## 第一步:开通访问权限(找阿祥)

这个库是**私有的**,得阿祥给你开权限你才看得到。

1. 去 github.com 注册一个账号(有就跳过),记住你的用户名
2. 把**你的 GitHub 用户名 / 注册邮箱**发给阿祥
3. 阿祥把你加进来后,你邮箱会收到一封邀请,点接受

> 阿祥侧操作见本文末「给同事开权限(阿祥看)」。

## 第二步:装 GitHub Desktop(图形工具)

1. 打开 desktop.github.com,下载安装
2. 打开后用你的 GitHub 账号登录

## 第三步:把库下载到电脑

1. GitHub Desktop 里点 **File → Clone repository**
2. 在列表里找到 **xiangxin-team-kb**,选它
3. Local path 选一个你记得住的文件夹(比如桌面),点 **Clone**
4. 等它下载完,这个文件夹里就是全部公司知识了

## 第四步:用 Obsidian 打开来读

1. 打开 obsidian.md,下载安装
2. 打开 Obsidian → **Open folder as vault** → 选你刚下载的那个文件夹
3. 从 **README** 开始读,再看 **00-新人必读**

---

## ⭐ 以后怎么拿到最新内容(最重要)

公司会不断更新这个库。你要定期"拉最新",不然看的是旧的:

**每次想看之前,打开 GitHub Desktop → 点最上面的 `Fetch origin`(或 `Pull`)→ 完成。**

就这一个动作。拉完回 Obsidian 看就是最新的了。

## 进阶:让它自动更新(可选,懂一点的可以开)

不想每次手动点,可以让 Obsidian 自己定时拉:

1. Obsidian → 设置 → 第三方插件 → 社区插件 → 关闭"安全模式"
2. 浏览 → 搜 **Obsidian Git** → 安装 → 启用
3. 插件设置里把 **Auto pull interval** 设成比如 10(分钟)

开了之后,打开 Obsidian 就自动是最新的,不用手动点。

---

## 🔴 一条铁律

看到内容有错、或你有更好的话术/做法,**别自己在本地改了完事**(你改的不会传给别人,下次更新还会被覆盖)。正确做法:在工作群 @ 阿祥说,或登记纠错日志,他统一改进来。这样全公司看到的永远是同一版。

---

## 给同事开权限(阿祥看)

每来一个新同事,在 GitHub 仓库 `xiangxin-team-kb` 里:
**Settings → Collaborators → Add people → 填对方 GitHub 用户名/邮箱 → 默认 Read 权限即可。**

> 人多了之后建议建一个 GitHub Organization,把仓库转进去,用 Team 统一管权限,比一个个加协作者省事。需要时让 AI 帮你弄。
