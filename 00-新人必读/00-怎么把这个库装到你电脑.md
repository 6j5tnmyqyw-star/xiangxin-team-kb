# 怎么把团队知识库装到你电脑上(新人第一件事)

> 这个库放在网上(一个叫 GitHub 的网站),你要把它"下载"到自己电脑,用 Obsidian 打开来读。
> 全程不用敲命令,跟着图形界面一步步点就行。**第一次装大概 15-20 分钟,装好之后每次更新只要点一下。**
> 实在搞不定,找同事或阿祥帮你装一次,之后你自己只需要会最后那个"点更新"的动作。

---

## 第一步:注册一个 GitHub 账号

> GitHub 是存放这个库的网站。你得有个账号,阿祥才能把你"拉进来"看。已经有账号的跳到第二步。

1. 用浏览器打开 **github.com**
2. 点右上角 **Sign up**(注册)
3. 按提示依次填:
   - **Email**:填你常用的邮箱(建议用能收到验证码的)
   - **Password**:设一个密码,记牢
   - **Username**:取一个用户名(英文字母/数字,比如 `jiaxin-golf`)——⭐ **这个用户名很重要,等下要发给阿祥**
4. 它会让你**做个小验证**(拼图/点图)证明你是真人,按提示完成
5. 邮箱会收到一个**验证码**,填进去
6. 后面问你"用途/团队规模"之类的可以随便选或跳过(Skip),不影响

注册完你就有账号了,记住**你的用户名和密码**。

## 第二步:把用户名发给阿祥,开通访问权限

这个库是**私有的**,只有被允许的人能看。

1. 把你的 **GitHub 用户名**(第一步取的那个)发给阿祥(飞书发他就行)
2. 阿祥把你加进来后,你的**注册邮箱会收到一封邀请邮件**
3. 打开那封邮件,点里面的 **绿色按钮(View invitation / Accept invitation)**接受邀请

> 接受之后你才看得到这个库。没收到邮件就再找阿祥确认一下。

## 第三步:装 GitHub Desktop(图形工具,不用敲命令)

1. 打开 **desktop.github.com**,下载并安装 GitHub Desktop
2. 打开它,选 **Sign in to GitHub.com**,用你第一步的账号登录

## 第四步:把库下载到你电脑(叫"clone")

1. GitHub Desktop 里点菜单 **File → Clone repository**
2. 在列表里找到 **xiangxin-team-kb**,点选它
   - (找不到?说明权限还没生效,回第二步确认邀请接受了)
3. **Local path** 选一个你记得住的位置(比如桌面)
4. 点 **Clone**,等它下载完
5. 下载好的那个文件夹里,就是公司全部知识了

## 第五步:用 Obsidian 打开来读

1. 打开 **obsidian.md**,下载安装 Obsidian
2. 打开 Obsidian → 点 **Open folder as vault** → 选你第四步下载的那个文件夹
3. 从 **README** 开始读,再看 **00-新人必读** 这个文件夹里的内容

---

## ⭐ 以后怎么拿到最新内容(跟公司这边同步)

公司会不断更新这个库(新规则、新话术等)。你电脑里的是"下载那一刻的版本",**要手动拉一下才会变成最新**:

> **每次想看之前,打开 GitHub Desktop → 点最上面那个 `Fetch origin` 按钮(变成 `Pull` 就再点一下)→ 完成。**

就这一个动作,拉完回 Obsidian 看就是最新的了。养成习惯:**看之前先拉一下。**

## 进阶:让它自动更新(可选,嫌每次手动点麻烦的开)

1. Obsidian → 设置(左下齿轮)→ 第三方插件 → 关闭"安全模式"
2. 点 **浏览**,搜 **Obsidian Git** → 安装 → 启用
3. 进这个插件的设置,把 **Auto pull interval (minutes)** 设成比如 `10`,并打开 **Pull updates on startup**
4. ⚠️ 把自动 commit / push / backup 相关的开关**全部关掉**——你是只读权限,开了会一直报错

开了之后,你打开 Obsidian 它就自动拉最新,不用再手动点。

## 进阶:已经有自己 Obsidian 库的人(比如日常在用 AI 干活的)

不想开两个库切来切去?可以把团队库**放进你现有库里当一个文件夹**,你的笔记和公司知识能一起搜:

1. 第四步 Clone 时,**Local path 选你现有库的文件夹**(在 Obsidian 里右键任意文件 →"在系统资源管理器中显示"就能找到位置),下载完你库里会多出一个 `xiangxin-team-kb` 文件夹
2. Git 插件设置里多配一项:**Custom base path**(仓库路径)填 `xiangxin-team-kb`,其余同上(Auto pull 10 分钟 + 启动拉取 + 关掉所有自动 commit/push)
3. 铁律不变:`xiangxin-team-kb` 文件夹**只看、不改、不往里放自己的文件**,尤其别把带客户信息的文件挪进去

## ⭐ 关键一步:让你的 Claude Code 真正"用上"这个库

库下载下来只是第一步——**Claude Code 不会自动知道它的存在**,要按你的装法接一根线:

**情况 A:你开 Claude Code 会话时,工作目录直接选的就是这个库的文件夹**
→ 啥都不用配。公司规则(CLAUDE.md)和全部公司技能(.claude/skills/)自动生效。

**情况 B:你走的是"放进自己库当子文件夹"路线(上面的进阶方案)**
→ Claude 看不见子文件夹里的规则,要在**你自己库的根目录**找到 `CLAUDE.md`(没有就新建一个,文件名必须全大写),在最顶上加这几行:

```markdown
## 公司知识库(必读)
@xiangxin-team-kb/CLAUDE.md

- 公司规则、话术、SOP、产品知识都在 `xiangxin-team-kb/` 文件夹里,回答公司业务问题前先去里面查,别凭记忆编
- 公司技能在 `xiangxin-team-kb/.claude/skills/` 里,要用某项技能时先读它的 SKILL.md,照着执行
```

第一行 `@xiangxin-team-kb/CLAUDE.md` 是 Claude Code 的"自动加载"写法——以后每次新开会话,公司规则自动进它脑子,**不用你每次再交代**。

**怎么验证接通了**:新开一个 Claude Code 会话,直接问它:"咱们公司的客户隐私红线是什么?"
- 答得出来 = 接通了 ✅
- 说不知道 = 回头检查:文件名是不是全大写的 `CLAUDE.md`、那行 `@` 是不是顶格单独一行、文件夹名是不是 `xiangxin-team-kb`。

## ⭐ 用 Claude 的同事:更新也交给 Claude,插件都不用装

日常在用 Claude 干活的人,上面"自动更新插件"那节可以整个跳过——让 Claude 负责拉最新:

1. **先验证一次能更新**,把这段原样发给你的 Claude:
   ```
   帮我更新公司团队知识库:进入 xiangxin-team-kb 文件夹运行 git pull。
   如果提示它不是 git 仓库、或者电脑没装 git,不要自己想办法绕,
   直接告诉我是哪种情况。
   ```
   它回"已是最新/更新了 N 个文件"就是通了;报错就把它的回复发群里问阿祥。
2. **通了之后让它记成习惯**:
   ```
   记一条规则到 CLAUDE.md:每天第一次开始干活时,先去 xiangxin-team-kb
   文件夹跑一次 git pull 更新公司知识库,更新完简单说一句结果再继续干活。
   ```

以后每天开 Claude 干活,公司知识自动就是最新的;Obsidian 里看到的也是同一份文件。

## 🔴 一条铁律:别自己在本地改

看到内容有错、或你有更好的话术/做法,**别自己在电脑上改了完事**——你改的别人看不到,而且下次更新还会被覆盖盖掉。

正确做法:在工作群 **@ 阿祥** 说一声,或登记到纠错日志,他统一改进来。这样全公司看到的永远是同一个版本,不会各干各的。

## 给同事开权限(阿祥看)

每来一个新同事,收到他的 GitHub 用户名后:

1. 打开仓库 **github.com/6j5tnmyqyw-star/xiangxin-team-kb**
2. **Settings → Collaborators → Add people**
3. 填对方的 **GitHub 用户名或邮箱**,权限选默认的 **Read**(只读)即可,点添加
4. 对方邮箱会收到邀请,让他去点接受

> 人多了之后建议建一个 GitHub Organization,把仓库转进去用 Team 统一管权限,比一个个加省事。需要时让 AI 帮你弄。
