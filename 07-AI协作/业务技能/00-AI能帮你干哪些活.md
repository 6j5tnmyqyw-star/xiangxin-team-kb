# AI 能帮你干哪些活(业务技能清单)

> 全员底座是飞书机器人（lark-cli）和这份知识库。你电脑上如果已经有 AI 客户端，装好之后可以直接用大白话叫它干下面这些活。没有桌面客户端，飞书侧能做的事先走机器人。
> 装机看 [[07-AI协作/团队AI装机手册]]，不要再按同目录的 Claude Code 旧手册装。
> 不用记命令，**说人话就行**。

## 客服 / 销售

| 能干啥 | 怎么叫它 |
|---|---|
| 起草询单 / 售后回复话术(自动避红线 + 脱敏) | "帮我回个询单""这个售后怎么回""客户问 XX 怎么答" |
| 导出千牛/旺旺聊天记录、复盘客服对话 | "拉一下千牛聊天""导出旺旺咨询明细" |
| 私域老客召回名单 + 话术 | "跑一下私域召回""给老客发召回" |

## 运营 / 选品

| 能干啥 | 怎么叫它 |
|---|---|
| 看竞品店上新了什么 | "看看 XX 店上新了啥""竞品上新" |
| 竞品比价、监控异常价 | "跑一下淘宝比价""监控竞品价格" |
| 高尔夫市场情报日报(京东/抖音热销榜) | "今日市场分析""跑一下市场行情" |
| 经营分析(成交额/客单价/渠道结构/环比) | "这个月卖得怎么样""做个经营分析" |

## 采购 / 库存

| 能干啥 | 怎么叫它 |
|---|---|
| 供应商速查(这个货找谁拿/账期/能否开票) | "XX 品牌找谁拿""这个货谁有" |
| 库存周报(资金占用/滞销/断货预警) | "跑一下库存分析""生成库存周报" |
| 补货建议(该补啥/补多少/找谁拿) | "该补什么货""生成补货清单" |
| 供应商挂账对账(三色标记) | "帮我对账""核对挂账" |

## 内容 / 短视频

| 能干啥 | 怎么叫它 |
|---|---|
| 写短视频口播文案 / 选题 | "搞个选题""写条文案""今天拍什么" |
| 文案去 AI 味、加钩子、改口吻 | "这条太 AI 了""帮我改成口语""加个钩子" |
| AI 作图(主图/海报/详情/社媒封面) | "做张图""做个海报""做详情图" |
| 把内容做成高级可视化网页 | "做个可视化页面""把这篇做成网页" |
| 短视频一键发抖音/视频号/小红书 | "把这条发出去""一键发布" |

## 飞书 / 日常

| 能干啥 | 怎么叫它 |
|---|---|
| 发消息、建任务、查日历、读文档、操作多维表格 | 直接说要干啥,比如"给 XX 发个任务""帮我建个表" |
| 设提醒(同步到手机) | "提醒我 X 点做 Y" |
