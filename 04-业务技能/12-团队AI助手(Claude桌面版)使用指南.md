# 📘 团队 AI 助手使用指南（Claude 桌面版）

> 装 Claude 桌面端到自己的 Windows 电脑上，加上几个关键插件，就能让 AI 帮你：写文案、查规则、读 Excel、操控浏览器（自动填表、抓数据、跨页操作）、跟飞书联动。

**最后修订**：2026-05-16　**修订人**：邹祥书

---

## 一、Claude 是什么 / 能帮你干啥

Claude 是 Anthropic 的 AI 助手（祥书一直在用的那个）。桌面端装到你 Windows 电脑上之后，对话+插件结合能干很多事。

**它能帮你做**：
- ✅ 写文案：「写一段双 11 直播预告，重点 Bushnell V6S」
- ✅ 查公司规则：贴 wiki 内容给它读
- ✅ 读本地 Excel/CSV：「这份销售数据找异常订单」（要装 Filesystem 插件，见下方）
- ✅ **操控 Chrome 浏览器**：自动登录后台、填表、抓商品页、跨标签页操作（要装 Claude for Chrome，见下方）
- ✅ 翻译 / 总结 / 改文章 / 写小脚本
- ✅ 跟飞书联动：发消息、查日历、读文档（要装飞书 MCP，看你需求）

**它做不了的事**（要找祥书 bot）：
- ❌ 跑祥书写的专用 skill（千牛聊天/吉客云/淘宝监控等）—— 先飞书私聊「祥子AI 推送」机器人，bot 在祥书电脑上跑

## 二、装之前你要准备

| 准备项 | 谁负责 |
|---|---|
| Windows 10 或 Windows 11（64 位） | 已有 |
| 4 GB 以上内存 | 已有 |
| 网络代理（TUN 模式，国内必需） | 祥书统一配 |

> 🛑 **第一次装强烈建议找祥书或 AI 远程帮跑通**，国内代理 + 登录这一步容易卡。

## 三、安装 Claude 桌面端（3 步）

### Step 1：下载安装包

打开浏览器（先确保代理已经开启，全局模式），访问：

**https://claude.com/download**

点 "Download for Windows" → 拿到 `Claude-Setup.exe`（约 120 MB）。

### Step 2：双击安装

双击下载好的 .exe，按提示下一步下一步即可。

### Step 3：登录

打开 Claude 桌面端 → 用祥书给你的账号登录（邮箱 + 密码或 Google 账号）→ 完成。

> ⚠️ 国内不开代理（TUN 模式）的话登录会失败 / 报错"无法连接"。开了代理还不行就找祥书。

## 四、必装插件（按你日常需求装）

Claude 桌面端本身只是对话，要让它"能做事"得装插件（Anthropic 叫 **Extensions** / **MCP** / **Connectors**）。

装法都一样：**Claude 桌面端 → 左下角设置 ⚙️ → Extensions（扩展）→ 点 "Browse extensions" → 找到 → 一键装**。不用碰 JSON，不用碰终端。

### 🔥 1. Filesystem（必装）—— 读你电脑上的文件

**干啥用**：让 Claude 能读你电脑上的 Excel/CSV/Word/PDF。不装这个连个 xlsx 都打不开。

**怎么装**：
- 设置 → Extensions → 搜 "Filesystem" → 一键装
- 装完它会问"允许 Claude 读哪些文件夹"，**只勾选你工作用的文件夹**（比如 `Desktop` 和 `Documents`），不要全盘允许

### 🔥 2. Claude for Chrome（必装，控浏览器神器）

**干啥用**：让 Claude 直接控制你的 Chrome，比如：
- "登录淘宝后台，把昨天没发货的订单导出来"
- "去生意参谋看下今天 UV"
- "把这个商品页的图片全下载到桌面"
- "帮我批量填这 50 条退款申请"

**怎么装**：
1. 用 Chrome 浏览器打开 → https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn
2. 点"添加至 Chrome"
3. 装完后浏览器右上角会有 Claude 图标，**用同一个 Claude 账号登录**
4. 在 Claude 桌面端发任务，扩展接管 Chrome 操作

> ⚠️ **只支持 Chrome**——Edge、Brave、夸克这些都不行。日常用 Edge 的同事先去装 Chrome。
> ⚠️ Claude 操作前会**弹确认窗**，让你看清要做啥再 yes，**不要无脑 yes**（特别是涉及钱的操作）。

### 🟡 3. 飞书 MCP（可选，跟飞书联动）

**干啥用**：让 Claude 能直接发飞书消息、查日历、读飞书文档。不需要切窗口，对话里就能搞定。

**怎么装**：
- 设置 → Extensions → 搜 "Lark" 或 "Feishu" → 一键装
- 装完后用你飞书账号扫码授权

> 💡 这个不是所有人都需要装。如果你日常重度跟飞书打交道（发任务、查日程），装；否则跳过。

### 🟢 4. Computer Use（可选，桌面级操控）

**干啥用**：让 Claude 像人一样控制你的电脑——开 app、点窗口、用 Word、跨软件操作。比 Chrome 扩展更强但更重。

**注意**：
- 仅 **Pro / Max** 订阅有；Team / Enterprise 反而**没有**这个功能
- 首次启动要下载约 2 GB 沙盒环境
- 适合**有特殊需求**的人，普通运营 Chrome 扩展够用

**怎么开**：设置 → Capabilities → 打开 "Computer Use" → 按提示完成沙盒下载。

## 五、5 个典型场景示范

### 场景 1：让 Claude 按公司规则做事

```
你贴一段规则给它：

> 公司「淘宝订单不得用京东快递」规则原文：
  [复制 wiki 规则内容]
  
  帮我写一段发货话术，告诉客户为啥不能选京东快递
```

### 场景 2：写抖音文案（避禁用词）

```
> 帮我写抖音视频脚本，30 秒以内，主题 Bushnell V6S 实测精度。
  公司禁用词："最、极致、第一、史上最低、绝对、国家级、唯一、顶级、独家、军用级、百分百精准"
  禁用词一个都不要用。
```

### 场景 3：读 Excel 找异常（要先装 Filesystem）

```
> 读我桌面上的 0515销售明细.xlsx
  找出 GMV 比前一天降 30% 以上的店铺，列成表格
```

### 场景 4：控浏览器自动化（要先装 Claude for Chrome）

```
> 帮我去淘宝卖家中心，把今天还没发货的订单导出 Excel 存到桌面
```

Claude 会弹确认窗一步步问你，你点 yes 它就做。

### 场景 5：批量翻译

```
> 这份英文产品手册帮我翻成中文，保留专业术语，按段分开
  [粘贴英文]
```

## 七、遇到问题怎么办

| 情况 | 怎么办 |
|---|---|
| 装不上、报错 | 截图发飞书群 @ 祥书 |
| 装完插件后没反应 / 软件不对劲 | 多半是没真正重启——光点窗口 ✕ 没用，软件还在右下角**托盘**里跑着。点托盘 `^` 小箭头展开 → 找到 Claude 图标 → 右键 → 退出，再重新打开就好 |
| 提示「无法连接 / network error」 | 代理掉了或不是 TUN 模式，找祥书 |
| 提示「会员到期 / 401」 | 找祥书续费 / 重新登录 |
| 插件装不上 / 找不到 | 截图发祥书 |
| Chrome 扩展不响应 | 确认 Chrome 扩展跟桌面端**登录同一个账号** |
| 用法不会 | 直接问 Claude「怎么 XXX」让它教你 |
| 想做的事它做不了 | 看上面「替代方案」表，或群里 @ 祥书 |

## 八、安全规则（⚠️ 重要）

1. **任何涉及钱、订单、删除文件的操作，弹确认窗时认真看清再点 yes**，AI 偶尔会理解错
2. **不要让 Claude 操作客户隐私信息**（手机号、地址、身份证）—— 这些不能进 AI 对话框
3. **不要让 Claude 操作公司的店铺密码 / 后台账号**改密码、转账之类的事；只能让它做"已登录态下的常规操作"
4. **Filesystem 只勾工作文件夹**，不要全盘授权
5. **聊天内容不要包含商业机密**（成本毛利、内部财报）—— 即便 Claude 承诺不用于训练，敏感数据也别上 AI

## 十一、跟「Claude Skills 共享」云盘的关系

云盘里那个「📦 正式发布」文件夹的 skill zip，**理论上**可以装进 Claude 桌面端用（jay 自家库里的 skill 有些会同步到 `~/.claude/skills/`）。但因为大部分 skill 依赖祥书的本地环境（lark-cli、特定账号、本地 Chrome），团队装上能不能跑**没实测过**。

**当前建议**：先把日常 Claude + Filesystem + Chrome 扩展用熟，skill 这事等祥书第二阶段统一推。
