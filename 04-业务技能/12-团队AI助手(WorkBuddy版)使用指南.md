# 团队 AI 助手使用指南（WorkBuddy）

> 面向：全体同事（运营 / 客服 / 财务 / 库房 / 内容）
> 最后修订：2026-11-20
> 原来那份「Claude 桌面版」指南已作废，团队统一用 WorkBuddy。

---

## 一、WorkBuddy 是什么

腾讯出的 AI 工作台。跟你平时用的聊天 AI 不一样的地方只有一个，但很关键：**它能真的动手干活**——读你电脑里的文件、改表格、做 PPT、发飞书消息、跑脚本，最后交给你一个能直接用的东西。

它比聊天 AI 强在：

- 一句话说清要什么，它自己拆步骤、自己执行，不用你一步步指挥
- 能读本地的 Excel / Word / PDF，也能批量处理文件夹
- 产出的是文件（docx / xlsx / pptx / 网页），不是一段话
- 可以同时开几个任务并行跑

---

## 二、装好它（10 分钟）

1. 到 **workbuddy.cn** 下载安装包，双击装上
2. 用你的企业账号登录（没有账号找阿祥开）
3. 第一次打开会让你选个目录，随便选，下一步才是关键

---

## 三、最关键的一步：工作空间选团队库（不选＝技能全不生效）

WorkBuddy 的技能是**跟着工作空间走**的。公司给你配的 30 多个技能都在团队知识库里，只有工作空间选对了才会被读到。

每建一个新任务，**左下角「选择工作空间」→ 选团队知识库的根目录**（就是你放「祥新团队知识库」那个文件夹，能看到 `00-新人必读`、`05-各岗SOP流程` 那一层）。

选对之后：
- 技能自动生效，不用装
- 说「帮我对账」「查一下售后单」，它知道该走哪套流程
- 每次同步拿到的新技能，下次开任务就有

> 技能实际放在库里的 `.workbuddy/skills/`（隐藏文件夹，不用管它）。WorkBuddy 只认这个路径，不认 `.claude/skills/`——2026-11-20 之前技能放错地方，等于全公司都没生效，现在改过来了。

## 四、怎么开口

一句话就够，说清**做什么 + 给谁 + 什么格式**：

| 想要什么 | 就这么说 |
|---|---|
| 回询单 / 售后 | 「帮我回这条询单，客户问 V6S 和 V6 有啥区别」+ 贴原话 |
| 查售后单 | 「列一下这个月 V6S 的售后单，按原因归类」 |
| 查供应商 | 「这个品牌的货找谁拿，账期多久」 |
| 对账 | 「帮我对账」+ 传两份 Excel，见 `05-各岗SOP流程/2026-11-20-供应商挂账对账-怎么让AI做.md` |
| 建任务 | 「建个任务：核对10月京东账单，派给我，11月25号18点截止」 |
| 写文案 | 「写条抖音口播，讲 V6S 的坡度补偿，别用违禁词」 |
| 做 PPT / 报告 | 「把这份销售数据做成一份周报 PPT，四段式」 |
| 整理文件 | 「把 Downloads 里的图片按日期分文件夹」 |

**说人话就行**，不用记命令、不用写提示词模板。

## 五、几个同事用得最多的场景

### 场景 1：让它按公司规则干活

先说「按公司规则来」，它会去读 `01-部门规则`、`05-各岗SOP流程` 里的现成做法。产出的东西如果跟 SOP 不一致，你可以直接问它「这条是按哪份规则来的」。

### 场景 2：对账（华华、海英）

传两份 Excel（销售明细 + 供应商挂账单），说「帮我对账」。它会先问你四个参数（金额列叫什么、运费阈值、按什么匹配、订单号格式），确认完出两份三色标记的表。

完整步骤和红色排查顺序见 `05-各岗SOP流程/2026-11-20-供应商挂账对账-怎么让AI做.md`。

### 场景 3：读 Excel 找问题

直接把文件拖进对话框，说「这份表里找一下异常订单：金额为 0、重复单号、退货没冲销的」。比手工翻快得多，但**结论你要自己复核**，它看错行你也看不出来。

### 场景 4：写对外文案

说清平台（抖音 / 小红书 / 朋友圈）、受众、想强调什么。它会自动过违禁词（见 `01-部门规则/09-内容创作规范.md`）。**发出去之前你自己读一遍**——AI 不承担对外承诺的责任。

### 场景 5：建任务

「建个任务：XXX，派给 YYY，周五 18:00 截止」。任务会自动挂到【祥新任务】清单里，主管在清单里能看见。如果它建完没告诉你「已挂清单」，你追问一句「挂清单了吗」，让它读回来确认。

## 六、它做不了的（别浪费时间）

| 想让它做 | 实际情况 | 怎么办 |
|---|---|---|
| 登录你的网银 / 税务 / 店铺后台抓数据 | 登不了，需要你自己登录的浏览器窗口 | 你自己导出，或让它读你导出的文件 |
| 帮你点发送、发群、发给客户 | 只给草稿 | **你自己点发送**，这条是红线 |
| 改公司公共库的规则文件 | 不允许 | 提「规则建议修改」，走纠错日志 |
| 判断某张发票能不能抵、税务口径对不对 | 不懂，也别让它猜 | 问海英 / 问阿祥 |
| 替你做人事、钱、对外承诺的决定 | 不做 | 找主管 / 阿祥 |

## 七、出问题怎么排查

| 现象 | 先查这个 |
|---|---|
| 说「帮我对账」，它没走对账流程 | 工作空间是不是没选团队库根目录 |
| 技能里提到的脚本跑不起来 | 本机有没有 python3；缺 pandas / openpyxl 就 `pip install pandas openpyxl` |
| 飞书相关的活干不了 | `lark-cli` 装了没、登录账号了没 |
| 浏览器类的活干不了 | Chrome 开着没、登录着没 |
| 它说找不到某个文件 | 路径说清楚，或者直接把文件拖进对话 |

还不行 → 群里问阿祥，把任务标题和报错截图发过去。

## 八、安全（自己心里要有数）

1. 客户姓名、手机号、地址、订单号——**不写进对外发的任何东西**，对话里也少贴
2. 店铺后台截图、订单数据——不外传
3. 密钥、密码——不写进任何文件，也别贴进对话
4. 金额、库存、对账、人事的结论——**以系统 / 阿祥为准**，AI 整理的结果你要回看
5. 对外发的东西——它只出草稿，**你自己点发送**

---

## 九、谁负责什么

| 事 | 找谁 |
|---|---|
| 账号、装不上、权限 | 阿祥 |
| 某个技能不好用、想要新技能 | 阿祥（或在纠错日志提「规则建议修改」） |
| 公司规则本身有问题 | 纠错日志 Base → 规则建议修改 |
| 岗位相关的做法 | 各自的部门规则 + 岗位 SOP |

## 十、进阶（用熟了再看）

- 想要一个市场里没有的能力 → 直接说「帮我做一个技能，用途是……」，WorkBuddy 能自己生成一个放进 `~/.workbuddy/skills/`
- 同一条流程天天做 → 让它固化成技能，下次一句话就能跑
- 你的个人习惯（称呼、口味、常用格式）→ 存进用户级记忆，所有项目都带着走
