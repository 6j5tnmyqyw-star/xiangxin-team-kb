# 14 · 团队知识库怎么拿到手（飞书云盘版 · 不用 GitHub）

> 给同事看的。没有 GitHub 账号也能用，飞书账号就行。
> 对应文件：GitHub 公开库 `xiangxin-team-kb` ＝ 飞书云盘「📚 团队知识库镜像（每日自动同步）」，两边内容一样，每天 03:40 / 03:55 自动更新。

## 一、只想看看（30 秒）

直接在飞书里打开镜像文件夹，按目录翻：

- `00-新人必读` 入职先看这
- `01-部门规则` 你岗位的规则
- `02-客服话术` / `03-品牌产品库` 接待客户直接查
- `05-各岗SOP流程` 具体怎么干
- `04-业务技能` AI 技能装法

链接找 @祥书 或群里的置顶消息要（文件夹已设为「获得链接的人可阅读」，跨租户账号也能打开）。

## 二、让 AI 能读到（推荐，做一次就行）

在终端跑一次，本地就有一份完整副本，之后每天增量更新：

```bash
lark-cli drive +pull \
  --folder-token H6r9fnWASlUgFXdju68csErLnXc \
  --local-dir ~/obsidian/团队知识库 \
  --if-exists smart \
  --as user
```

第一次会走飞书授权，之后自动。`--if-exists smart` 只下改过的，几百个文件也就十几秒。

拉完之后告诉你的 AI：

> 公司团队知识库在 `~/obsidian/团队知识库`，回答公司规则、话术、SOP、产品问题前先去这里检索。

## 三、发现库里的东西不对/过时了

不要自己改完就算，走回传：

> 「回传总库：XX 规则第 3 条应该改成……」

你的 AI 会登记到纠错日志 Base（分类＝知识回传），@祥书 侧审核采纳后合并进库、`CHANGELOG.md` 记一行并署你的名字，第二天全公司自动拿到新版。

## 四、几个别踩的坑

- **库是脱敏版**：拿货价、成本、客户手机号订单号、工资都不在里面，别在库里补这些。
- **别把客户聊天记录贴进来**：要沉淀就沉淀「结论和话术」，原文不进库。
- **飞书云盘只读**：想改内容走上面的回传流程，云盘里改了第二天会被镜像覆盖。
