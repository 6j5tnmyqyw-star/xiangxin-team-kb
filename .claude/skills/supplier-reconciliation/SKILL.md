# 供应商挂账对账技能

把销售订单明细（自家系统导出）和供应商挂账单（供应商发来）按订单逐条比对，金额对得上的标绿、差额在阈值内的标黄（视为运费差异）、对不上的或缺失的标红。

## 核心规则

| 颜色 | 含义 |
|---|---|
| 🟢 绿色 | 两边金额完全一致 |
| 🟡 黄色 | 差额 ≤ 阈值（默认 60 元，按运费差异处理） |
| 🔴 红色 | 差额超出阈值，或另一份里没有对应订单 |

两份文件**都标色**。每个订单编号单元格上加批注，说明对应的另一边订单号和差异原因。

## 关键概念：双路金额比对

供应商挂账上的"应收金额"通常等于销售明细里的**成本价**（不是售价）。所以：

- 销售明细同时有「应收合计」（售价）和「订单货品成本」（成本价）两列
- 挂账金额对销售明细的两列分别比对，**任一对得上就算对上**
- 这样能容纳两种情况：供应商按成本挂账、或按售价挂账

如果发现新供应商不是这个口径，要先问用户怎么对。

## 关键概念：从订单编号提日期

订单编号通常形如 `JY202604190024`，里面 `20260419` 就是下单日期。**两边都用这个规则提日期**，比用「下单时间」字段更可靠（因为挂账文件可能没有时间字段）。

如果遇到其他供应商订单号格式不一样，要识别新规则——先看几条订单号，找出日期段的位置。

## 匹配流程

1. **读两份 Excel**，识别表头位置（一般是第 1 行）
2. **从订单编号提日期**，建索引
3. **货品名称提关键词**：去掉品牌前缀和规格，提英文词（≥3字母）和中文词（≥2字符）
4. **同日期内贪心匹配**：综合"货品名称相似度 + 金额接近度"打分，分高的优先一对一配对
5. **判定颜色**：差额 < 0.01 绿，≤ 阈值 黄，否则红（且若货品相似度 < 0.2，视为完全没匹配上）
6. **写入颜色和批注**保存

## 操作步骤

### 第一步：先看两份文件结构

```bash
python3 << 'EOF'
import pandas as pd
from openpyxl import load_workbook

for fname in ['file1.xlsx', 'file2.xlsx']:
    wb = load_workbook(fname, data_only=True)
    for sn in wb.sheetnames:
        df = pd.read_excel(fname, sheet_name=sn, header=None)
        print(f"\n{fname} / {sn}: shape={df.shape}")
        print(df.head(5).to_string())
EOF
```

### 第二步：和用户确认四件事

务必先问清楚这四个问题，不要默认：

1. **两边的"金额"字段叫什么？**（例如优品叫"应收合计"和"订单货品成本"，供应商叫"应收金额"）
2. **运费阈值多少？**（默认 60 元，但可能不同供应商不一样）
3. **匹配键是什么？**（默认订单编号里的日期 + 货品名称关键词；如果用户提到物流单号也能用，就加进来）
4. **订单编号格式**（看前几条样例确认日期段位置）

### 第三步：运行对账脚本

调用 `scripts/reconcile.py`，传入参数：

```bash
python3 scripts/reconcile.py \
  --sales <销售明细.xlsx> --sales-sheet <Sheet名> \
  --sales-oid <订单编号列名> --sales-recv <售价列名> --sales-cost <成本价列名> \
  --sales-goods <货品名列名> \
  --supplier <挂账.xlsx> --supplier-sheet <Sheet名> \
  --supplier-oid <订单编号列名> --supplier-amt <金额列名> --supplier-goods <货品列名> \
  --threshold 60 \
  --date-regex 'JY(\d{4})(\d{2})(\d{2})' \
  --output-dir /mnt/user-data/outputs
```

脚本会输出：
- `<销售明细>_对账.xlsx`
- `<挂账>_对账.xlsx`
- 终端打印汇总（绿/黄/红各多少条）

### 第四步：呈现结果给用户

用 `present_files` 把两个文件给用户。然后**按类别列出红色订单**，分两组：

- **金额对不上但能匹配到**（写明差额，提示可能是售后/改价/部分退款）
- **完全找不到对应**（提示去群里查是不是漏发或归到别的单）

## 边界情况

- **成本价为 0**：视为缺失数据，只用售价比对
- **退货/负数金额**：保留负号比对，差额按绝对值算
- **挂账文件最后几行可能是手写汇总**（订单编号为空，金额是合计数）：标红并备注"无效行"
- **同一天有多笔金额相近的单**：按货品名称相似度区分，贪心匹配避免重复占用
- **如果金额完全对不上但用户坚持是同一单**：让用户手工调整颜色，不要硬匹配

## 常见误区

- ❌ 不要用「下单时间」字段做匹配（两边格式可能不一样，且挂账可能没这列）
- ❌ 不要只用售价或只用成本比对——要双路
- ❌ 不要把货品名称完全不像但金额接近的硬配对（设 0.2 的相似度门槛）
- ❌ 不要忘记给两份文件都标色（用户通常想两边对照看）

## 用户偏好

- 输出语言：中文
- 颜色用浅色（C6EFCE 浅绿、FFEB9C 浅黄、FFC7CE 浅红），方便看清字
- 在订单编号那一列加 Excel 批注，鼠标悬停就能看对应另一边的订单号
