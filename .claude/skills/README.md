# 公司技能包（随库自带）

这个文件夹里是公司给大家配的 AI 技能（放在仓库根，路径不要改）。工作目录指到本团队知识库、且当前客户端会读 `.claude/skills/` 时，这些技能可用，不用单独安装；每次 `git pull` 拿到最新版。没有桌面客户端也可以先用飞书机器人（`lark-cli`）和 Obsidian。

- 技能清单 / 版本 / 谁能用 → 飞书「📦 AI 技能更新台账」：https://xiangxingolf.feishu.cn/wiki/EAI1wrGl8izDAUkD9AtcMIADnMb
- 用法：直接对 AI 说人话，比如「帮我起草这条询单的回复」「查一下 V6S 的售后单」「把这篇文案去去 AI 味」「发个通知到群里」（自动用美观卡片，见 `lark-card`）
- ⚠️ 部分技能有前置条件：飞书类需要装 lark-cli 并登录（[[07-AI协作/团队AI装机手册]] §2，全员必配）；浏览器类（淘宝比价、店铺上新、千牛聊天抓取、短视频发布）按岗位需要，不是全员必装（同手册 §4）
