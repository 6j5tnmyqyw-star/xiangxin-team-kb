# 飞书美观卡片（团队统一格式）

> **一句话**：往飞书发**成段 / 结构化**的内容时，默认发**卡片**（不是纯文本）。卡片在手机上清晰、能高亮分级、能放一键复制的代码块、能放跳转按钮——这就是阿祥那个机器人发的「好看卡片」同款能力，现在你的 bot 也能发。

## 什么时候用（默认就用）

| 场景 | 用卡片 |
|---|---|
| 通知 / 公告 / 周报 / 日报 | ✅ |
| 催办 / 告警 / 提醒 | ✅ |
| SOP / 流程 / 清单 | ✅ |
| 话术 / prompt / 命令（要对方复制的）| ✅ 放 ``` 代码块，自带一键复制 |
| 带链接（文档 / 表格 / 任务）| ✅ 链接**内联进正文**或放底部按钮 |
| 就一两句话的口语回复 / 闲聊 | ❌ 纯文本即可 |

## 配色铁律（header 颜色 = 消息分级）

| 颜色 `template` | 用途 |
|---|---|
| `red` / `orange` | 🔴 催办、告警、出事了 |
| `yellow` | 🟡 温和提醒、注意事项 |
| `blue` | 🔵 常规通知、周报、日报（默认） |
| `green` | 🟢 完成、好消息、搞定了 |

正文里再配语义色高亮块分级（≤5 个，多了就糊），重点用 **加粗**，别通篇一个调。

## 怎么发（三步，照抄）

```bash
# 1. 正文写成 markdown（变量里）
MD='**本周滞销 TOP3 已盘点**，详情见下。

🔴 V6S：库存 320 件、近 30 天 0 动销
🟡 Garmin S70：周转放缓，建议关注

> 数据来源：吉客云库存快照 2026-06-23'

# 2. 用本技能的脚本把正文 + 标题 + 颜色 + 按钮 → 卡片 JSON
CARD=$(python3 .claude/skills/lark-card/lark_card.py \
  --title "📊 滞销周报 2026-06-23" \
  --template blue \
  --button "📄 打开完整周报=https://xiangxingolf.feishu.cn/wiki/xxxx" \
  <<< "$MD")

# 3. 用 lark-cli 把卡片发出去（--msg-type interactive）
#    发到群：--chat-id oc_xxx     发给个人：--user-id ou_xxx
lark-cli im +messages-send --as user \
  --chat-id oc_xxxxxxxx \
  --msg-type interactive \
  --content "$CARD"
```

- `--title` 省略=无标题栏；`--template` 默认 `blue`；`--button "文字=URL"` 可写多次。
- 发给个人把 `--chat-id oc_xxx` 换成 `--user-id ou_xxx`。
- 收件人 open_id / 群 chat_id 不确定：`lark-cli contact +search-user` 查人、`lark-cli im +chats-search` 查群。

## 几条统一规矩（跟阿祥的机器人对齐）

1. **要对方复制的内容**（话术 / prompt / 命令 / 链接文本）一律放 ` ``` ` 代码块，飞书卡片代码块自带「一键复制」。
2. **链接**：嵌进正文文字里或放底部按钮，别让对方手动拼 URL。
3. **需要对方选 / 拍板**：别甩一段文字问，发选项让对方点（进阶用法，见飞书 `lark-im` 交互卡片）。
4. **发之前先确认收件人对**（群发错地方很尴尬）；涉及客户隐私 / 后台数据的内容**不发**。
5. 用 `--dry-run` 可以先打印不真发，校准好再去掉。

## 前置

- 装好 `lark-cli` 并登录（装机手册第 4 节）。
- 本技能自带 `lark_card.py`，随团队库同步，不用单独装。
