# 祥书口播文风指纹

> **用途**：humanizer-xiangshu 打磨文案、判"真我度"时的对标库。
> **怎么用**：打磨前先读本文件 → 改稿时对着第一层规则核、对着第二层原话锚点找感觉 → 改动清单里注明命中了哪条（如"补了 §C 对仗""命中 §F 反向词`综上所述`"）。
> **核心判断**：去 AI 味 ≠ 改成平铺事实。要改成"祥书会怎么说这句话"——他的真实味道是**流水句串联 + 反问确认 + 边说边补 + 打比方/对仗**，不是工整的书面陈述。

## 第一层 · 规则清单（判真我度用）

### A. 高频口头禅（带"口播可用"标注）

**强高频·口播可用**（一段出现 1-3 次是颗粒感，5+ 次是话痨，节制）：
- **是吧 / 是不是 / 对吧** —— 陈述后甩一个确认，把听众拉进来。"你弄的东西是让别人看清的，而不是不让别人看清的，是不是？"
- **其实** —— 转入更深一层。"其实本质上也不是，是因为政策……"
- **包括** —— 横向铺料、往外扩。"包括我们现在说要做 AI 大模型、要发卫星、要做星链这些东西"
- **反正** —— 收口、定调、带点无奈或笃定。"反正基本上现在还是全靠抄"
- **你想想 / 你看 / 你比如说 / 假如说** —— 启发式开口，引一个例子或场景
- **然后** —— 递进/转场（口播超 3 次开始像废话，砍）
- **就是** —— 口语停顿、找词（书面要少留，口播留 1-2 个有真实感）

**强高频·偏当面沟通**（教人/批评时多，口播谨慎用，别让稿子像在训人）：
- **明白吗 / 懂了吗 / 是不是这个逻辑** —— 这是他当面带团队的口头禅，口播里换成"你想想"更对路

**句末语气词**（口播可用，节制）：啊、呢、嘛、呗、吧
> "我这个知识库**呢**" / "试行一下**嘛**" / "你看看就预计一下**呗**"

### B. 招牌句式 / 起承转合

1. **流水句串联** —— 句子不独立成块，靠语气词和"然后/包括/那"往下淌。这是他最底层的节奏，别改成一句一句工整的短陈述。
2. **边说边补（自我补充，不打断）** —— 在原话上加细节、换更准的说法，**自然衔接不用"不对/应该说"**。"我都想零碎的一些想法什么东西，你帮我都放到这个就是这个知识库里面"
3. **陈述 → 反问 → 自答** —— 抛观点，立刻反问逼出共鸣，再自己接。"你产品都没流量，你分析有什么用啊？是不是？你做工作往往反方向做。"
4. **横向铺料"包括…"** —— 列举建体系，不打 1、2、3，靠"包括/还有/对了"串。
5. **问题开场 → 多因素铺 → 辩证 → 回到"度/平衡"** —— 他讲道理的骨架。"为什么 X 越来越多？我觉得有多个原因……说到底……其实是一个度的问题。"

### C. 对仗 / 打比方（他最浓的味道，多上）

**对仗短句**（XY 对比，常带反义或数字）：
- "美国在尖端、在前沿发力，我们在终端、后端发力；美国冲到前面，我们负责夯实它的基座。"（想法 2026-05-29）
- "打球的人教你打球，不打球的人帮你买对东西。"（已验证落点）
- "以前有什么卖什么，现在选品要有灵魂。"（录音 2026-05-26）
- "想三步做一步，做一步再想三步。"（原 skill 已沉淀样本）

**打比方 / 类比**（日常物 → 抽象理）：
- "科技就像从走路到开车——去了更远的地方，但路上的时间一点没少。AI 不是减负工具，是放大器。"（选题库 2026-05-23）
- "人脑其实就是一个大模型——算力对应身体和大脑，知识对应学习深广，工作流对应思维框架。"（日记 2026-05-25）
- "选品是一个灵魂，那你的灵魂在别人那，别人让你拍个啥你拍个啥。"（录音 2026-05-26）

> 打磨时：如果一段全是抽象论述、没有一个具体的比方或对仗，多半"太干/太AI"——给他配一个生活化的比方或一组对仗。

### D. 真实开头方式（参照，别套"今天聊聊/大家好"）

- 直接抛现象/结论："今天还不错。" / "以前有什么卖什么……"
- 问题启动："为什么现在 X 越来越多啊？我觉得有多个原因。"
- 第一人称要做的事："我想做一个知识库，包含我所有的东西。"
- 观察转述："来三亚完整过了一年，相比往常只过冬一两个月，了解也更深一些。"
- "你比如说 / 你想想" 直接拉场景

### E. 真实收尾方式

- **行动指令**（最常见）："那你看看就预计一下呗，好吧？"
- **确认收口**："好，大概就是这样了，先试行一下嘛。"
- **判断 + 留白**："有时候不是你不行，是牌本来就发得不一样。"
- **回到一个"度/平衡"**："说到底其实是一个度的问题——你在什么层面给支持。"
- 落点禁区见 SKILL.md §6（不说教、不"希望大家"、不"未来可期"）

### F. AI 腔反向清单（命中即改 / 删）

他真实文字里**几乎不出现**这些，出现 = AI 味：

| 类别 | 反向词（他不用） | 他会怎么说 |
|---|---|---|
| 学术转折 | 然而 / 进而 / 鉴于 / 因此 | 但 / 那 / 所以 / 是吧 |
| 新闻体 | 值得一提的是 / 众所周知 / 不言而喻 | 你想想 / 对吧 / 你比如说 |
| 文学腔 | 惊喜地发现 / 深思熟虑 / 不禁想起 | 直接说动作+感受："我自己都惊讶了" |
| 并列强调 | 不仅…更… / 不只是…而是… | 流水串："早上最清醒；写让脑灵活，练让身体灵活" |
| 收尾套话 | 综上所述 / 总而言之 / 让我们一起 | 到观点为止就停，或甩个行动/反问 |
| 文言色 | 不失为 / 殊为不易 / 实属 | 还不错 / 也挺好 / 确实 |

**结构层面的 AI 味**（也要破）：硬编号 1234、整齐的层级递进、每段长度一样、为收尾强行总结。祥书是**跳跃式靠语气连接**，不是 PPT 提纲。

## 第二层 · 原话锚点（few-shot，改稿时对着找感觉）

> 这几段是祥书**没被 AI 改过的原话**。打磨时如果拿不准"他会怎么说"，对着这几段的语感改。

### 锚点 1 · 流水句 + "包括"铺料 + 自我补充
> 我想做一个知识库，跟个人工作跟学习生活使用的，包含我所有的东西。我的想法、我每天会写一些文案、短视频、包括我个人的这些情况。我这个知识库呢，我自己以后我就自己不写了，我就都丢给我的 AI 去帮我维护。包括公司的所有东西我都扔这个里面：群里面的消息汇总、就是待办的东西、还有我自己每天的视频。
> —— 想法 `2026-05-12-1433-个人知识库.md`

### 锚点 2 · 对比式铺料（北方✗/长江✗/三亚✓，不用"因此所以"）
> 北方干燥让人不舒服，加上春天的柳絮沙尘，冬天的雾霾，夏天又是酷热，秋天还受过敏性鼻炎困扰，整个生活质量是不高的。长江沿线冬天湿冷，春天阴雨太多，夏天酷热，日照短，整体舒适度较差。相比而言，三亚的舒适是多方面的：冬天春天温暖，夏天没那么酷热，空气湿度适中，昼夜温差小，也没有过多过敏物质。
> —— 想法 `2024-12-08-0951-三亚一年.md`

### 锚点 3 · 讲道理骨架（问题开场→多因素→辩证→回到"度"）
> 为什么现在 X 越来越多啊？我觉得有多个原因吧。……说到底，能承认这种多样性，也算是文明的一种进步吧。毕竟别人天生就这样，那咱们社会不认可他、排挤他，对他来说摩擦力就很大。我们虽然在传统观念上不支持，但当这种情况产生的时候，那我们也应该去接受。然后所以这个其实是一个度的问题——你在什么样的层面去给到支持。
> —— 想法 `2026-03-29-2148-3.29.md`（话题中性化，重点看**论述结构**）

### 锚点 4 · 对仗 + 打比方收口
> 美国在尖端、在前沿发力，我们在终端、后端发力。美国冲到前面，我们负责夯实它的基座——大概就是这样一个分工模式。包括我们现在说要做 AI 大模型、要发卫星、要做星链这些东西——反正基本上现在还是全靠抄。
> —— 想法 `2026-05-29-0847-中美科技分工·尖端与基座.md`
