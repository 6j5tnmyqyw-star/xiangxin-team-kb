# 高尔夫电商作图 · ChatGPT prompt 模板库

> 用法：按"作什么图"选模板，把 `[方括号]` 里的占位符换成你的商品 / 主题 / 比例，整段发给 ChatGPT。
> 商品：Bushnell 测距仪（V6/V6S/V7S/PRO XM）、Garmin GPS 手表（S70/R50/G82）、Ping/Callaway 球杆。
> 公司视觉调性：**高尔夫球场、清晨光线、专业、克制**（不浮夸不花哨）。分辨率≥1080×720。
>
> ⚠️ 图上**少放中文字**（GPT 中文字常出错），文案留到后期 Canva/PS 加。

---

## 模板 1 · 商品场景 / 氛围图

**用途**：商品放进球场氛围里，做详情页头图、营销底图、推文配图。
**比例**：16:9（横）或 3:4（竖）

```
一张高质量电商产品场景图：把 [Bushnell V6S 高尔夫激光测距仪] 放在 [清晨高尔夫球场果岭边的木质台面上]，
背景是 [虚化的草地和淡淡晨雾]，清晨柔和的侧光，专业产品摄影风格，干净克制、有高级感，
浅景深虚化突出产品，色调清新自然，画面右侧留白用于后期加文案，16:9 比例，高清。
```

> 提醒：AI 画的"商品"外观不会和实物一模一样。这类图当**氛围 / 背景**用；要精确商品外观，就让 AI 只画场景背景、产品用实拍后期合成。

## 模板 2 · 大促 / 节日海报底图

**用途**：618、双11、节日促销海报的背景底图（文字后期加）。
**比例**：3:4（竖版海报）或 1:1

```
一张高尔夫主题的电商大促海报背景：主题 [618 年中大促]，画面里有 [高尔夫球场、果岭、球杆剪影] 等元素，
色调 [暖金 + 草地绿]，喜庆但克制，大面积留白和明确的文字区留给后期加促销文案，
现代简洁设计风，有高级感，3:4 竖版，画面里不要出现任何文字。
```

> 提醒：**不要让 AI 写促销文字**——中文易错，还可能蹦出违禁词。只要底图，文案后期排版加。

## 模板 3 · 详情页卖点示意图

**用途**：把"长续航 / 高精度 / 快速读数"等卖点画成图解。
**比例**：1:1 或 3:4

```
一张简洁的产品卖点示意图：表现 [Garmin S70 长续航]，极简信息图 / 扁平设计风格，
干净的白底配品牌色点缀，用 [电池图标、简单线条、英文短标签] 表达，专业、清晰，
中间或下方留出中文标注的位置（中文后期加），1:1 比例。
```

> 提醒：图里的数字、参数 AI 容易写错，**关键数据一律后期核对补上**；别写专业到没人懂的术语，也别碰违禁词。

## 模板 4 · 社媒封面（小红书 / 抖音 / 公众号）

**用途**：内容封面图，标题文字后期加。
**比例**：小红书/公众号正文 3:4，抖音 9:16，公众号封面 16:9

```
一张 [小红书] 风格的高尔夫内容封面：主题 [新手怎么挑测距仪]，
风格 [年轻、清新、有生活感]，主体是 [高尔夫元素 + 大块标题留白区]，明亮通透、吸引点击，
3:4 比例，顶部留白给后期加标题，画面里不要文字。
```

> 风格按平台调：小红书清新生活感、抖音强对比抓眼、公众号克制专业。

## 模板 5 · 白底 / 纯色衬托背景

**用途**：纯背景，商品实拍后期合成上去；电商列表图、主图衬底。
**比例**：1:1

```
极简产品衬托背景：[浅灰到白的柔和渐变]，带柔和阴影，专业电商白底风格，
非常干净、中央留出产品位（产品后期放上去），有高级质感，1:1 比例，无任何文字和logo。
```

## 模板 6 · 节日 / 季节氛围图

**用途**：节气、节日推文的氛围配图。
**比例**：16:9

```
一张高尔夫主题的 [春季] 氛围配图：画面有 [球场、季节特征如新绿草地/樱花] 等元素，
[清晨或黄昏] 柔光，专业摄影风，克制有高级感，色调自然，16:9，留白给文案，画面里不要文字。
```

## 通用收尾（可拼在任意 prompt 末尾，提质量）

```
要求：专业商业摄影 / 设计水准，构图干净，主体突出，光线自然柔和，色调统一，
避免廉价感、避免堆砌元素、避免乱码文字，输出高清。
```

## 生成后怎么让 ChatGPT 改（迭代话术）

图出来不满意，直接接着说（不用重开对话）：

| 想改什么 | 这么说 |
|---|---|
| 太暗 / 太亮 | "整体再亮一点 / 暗一点，光线更柔和" |
| 换角度 | "换个俯视角度 / 平视角度" |
| 去掉文字 | "把图里所有文字去掉，只留画面" |
| 换比例 | "改成 3:4 竖版 / 16:9 横版" |
| 换背景 | "背景换成 [清晨果岭 / 纯白]" |
| 多要几版 | "基于这个风格，再生成 3 个不同构图的版本" |
| 留白不够 | "右侧 / 顶部多留一块空白给我加文字" |

## 红线速记（作图前默念，详见 SKILL.md 第五节）

1. AI 图只做氛围 / 背景 / 海报底图，**不当真实商品主图**（虚假宣传会被罚）
2. 违禁词不上图：极致 / 史上最低 / 第一 / 绝对 / 最 / 唯一 / 顶级 / 独家 / 军用级 / 百分百精准
3. 品牌名拼对：Bushnell / Garmin / Ping / Callaway
4. 不放客户隐私、不喂后台截图
