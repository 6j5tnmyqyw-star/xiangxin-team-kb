# chatgpt-image-maker · 运营上手指南

> 给运营组（小琴 / 娜娜 / 洪洪 / 嘉欣 / 庆弘）。三分钟看完就能用。
> 这个工具帮你**用 ChatGPT 又快又好地作电商图**（商品场景图、大促海报、详情卖点图、社媒/公众号配图）。比原来用豆包生图质量高。

---

## 你走哪条路？——默认路径 C，最简单

> **不用装任何浏览器插件**。Claude 帮你把作图的 prompt 写好、把违禁词红线都检查掉，**你只要复制到 ChatGPT 网页生图、下载**就行。

（如果你电脑特意装过 Claude in Chrome 扩展，可以让 Claude 直接帮你点 ChatGPT 生图——那是进阶路径 B，没装就走 C，不影响。）

---

## 一、装这个 skill（一次性，装好以后一直能用）

**前提**：你已经按团队装机手册装好了 Claude.app 桌面端（能打开左侧 `</> Code` 标签）。没装好先看团队飞书云盘里的《Claude Skills 安装与使用指南》。

**装 skill 三步**：

1. 从飞书云盘下载 `chatgpt-image-maker-v1.zip`，**解压**，得到一个 `chatgpt-image-maker` 文件夹
2. 把这个文件夹**整个**放到你电脑的 skills 目录：
   - **Windows**：`C:\Users\你的用户名\.claude\skills\`
   - **Mac**：`~/.claude/skills/`
   - （`.claude` 文件夹如果看不到，是被隐藏了——Windows 在文件夹"查看"里勾"隐藏的项目"；找不到就问阿祥）
3. 放好后长这样：`...\.claude\skills\chatgpt-image-maker\SKILL.md`

装完**重开一下 Claude.app** 就生效。

> 安装这步如果卡住，别硬试，直接找阿祥，他帮你放好。

---

## 二、怎么用（路径 C 实操）

1. 打开 **Claude.app** → 左侧 **`</> Code`** 标签 → **New session**
   - working directory 选一个你方便存图的文件夹就行（比如桌面新建个"AI配图"文件夹），作图不用读公司知识库
2. 直接说人话，例如：
   - "给 Bushnell V6S 做一张清晨球场的场景图，公众号封面用，16:9"
   - "做个 618 大促的海报底图，竖版"
   - "Garmin S70 续航卖点，做张详情页示意图"
   - "做张小红书封面，主题是新手怎么挑测距仪"
3. Claude 会**给你一段填好的作图 prompt**（已经套好公司风格、检查过违禁词）
4. 你**复制这段 prompt** → 打开 [chatgpt.com](https://chatgpt.com) → 粘贴进对话框 → 发送
5. 等 ChatGPT 生图（约 10-40 秒），图出来后**鼠标移到图上 → 点下载**
6. 不满意就接着在 ChatGPT 里说"再亮一点 / 换个角度 / 去掉文字 / 再来 3 版"（改图话术 Claude 也会给你）

## 三、图存哪 · 怎么上飞书

**命名规范**（跟公司素材命名一致）：
```
日期_产品_场景_版本.png
例：20260521_BushnellV6S_球场场景图_v1.png
```

- 存到你那个"AI配图"文件夹
- 要给团队用 / 上架用的，传到飞书对应素材夹
- ⚠️ **发给同事或上飞书时记得给查看权限**，别让人来找你申请

---

## 四、四条红线（每次作图都记着）

1. **AI 图不能当真实商品主图**！它画的商品和实物对不上 = 虚假宣传，平台要罚。AI 图只做**背景、氛围、海报底图、配图**；商品本身要用**实拍**。
2. **违禁词不能上图**：极致 / 史上最低 / 第一 / 绝对 / 最 / 唯一 / 顶级 / 独家 / 军用级 / 百分百精准。图上 AI 自己写了这些字，删掉重做。
3. **品牌名别写错**：Bushnell、Garmin、Ping、Callaway。图上有品牌名 / 型号，生成后逐字看一遍。
4. **不放客户信息**（姓名 / 手机 / 地址 / 订单号），不拿后台截图喂 ChatGPT。
