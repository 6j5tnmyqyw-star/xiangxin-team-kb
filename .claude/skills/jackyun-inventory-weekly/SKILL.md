# 吉客云库存周报

> **用途：** 自动登录吉客云 → 导出公司总库存 → 跟上一份快照对比 → 写 markdown 周报到 vault。

## 一、什么时候用

祥书说出以下意图之一就触发：
- 「跑一下库存分析 / 生成库存周报 / 库存对比」
- 「导出吉客云库存 / 把库存导一份」
- 「看看这周库存变化 / 这周哪些卖得快」
- 「吉客云库存有什么异常」

不适用：
- 单 SKU 的查询 → 直接在吉客云后台查
- 分仓库存对比 → 那是另一个查询表（分仓库存查询），本 skill 只跑「总库存查询」

⚠️ **安全规则**：密码字段原则上应该让祥书自己输入。如果他明确说「你直接登」就替他填，否则只填账号字段并请他自己敲密码。

填完点登录 → 会跳到 **短信二次验证**：

### 第 2 步：打开「总库存查询」

顶部标签栏点【总库存查询】（用 `find` 工具按文本匹配，元素名形如 `[200]总库存查询`）。

页面打开后右侧会显示「请选择条件进行筛选」。**点左下角蓝色【筛选】按钮**（不填任何条件 = 全部库存），等待数据加载（约 2 秒）。

### 第 3 步：检查并隐藏「图片」列（一次性配置）

> 含图片列时导出上限 2000 条，所以**必须**先把图片列移出。

如果第一列还显示图片缩略图：
1. 右键点列表第一行（图片缩略图位置）→ 弹出菜单
2. 点【配置列】→ 弹出「配置列」对话框
3. 在右侧「已选列」勾选【图片】这一行
4. 点中间的【<】按钮 → 把图片列移到左侧「待选列」
5. 点【保存】→ 提示「更新配置信息成功!」

**这是账号级持久设置**，做过一次后下次登录还是隐藏状态，跳过即可。

### 第 4 步：触发导出

1. 右键点列表任意行（不要点列头）→ 弹出菜单
2. 鼠标移到【导出】→ 展开子菜单
3. 点【导出所有页（限制50000行）】
4. 右下角会出现 toast: `【导出任务】总库存查询 开始执行...`

### 第 5 步：等任务完成 + 下载

- 等 5–15 秒（数据量越大越久），右下角变成 `【导出任务】总库存查询 任务执行完成`
- 点右下角状态栏的【导出任务】文字 → 弹出「下载记录和系统任务」面板
- 在最上面那条 `【导出任务-图文】总库存查询(N条)` 上点【下载】
- 文件会自动落到 `~/Downloads/总库存查询.xlsx`

### 第 6 步：归档 + 分析


完整报告链接发给他自己点。

## 三、对比分析做了什么

`analyze.py` 自动跟「快照目录里日期最近的上一份 xlsx」对比：

| 维度 | 周报会写 |
|---|---|
| **总览** | SKU 数、库存金额、件数 vs 上周 |
| **品牌** | 各品牌库存金额变化（Bushnell / Ping / Garmin / Honma / Titleist / Callaway / 其他） |
| **Top 资金占用 SKU** | Top 20，标注本周金额涨跌、新晋/掉出 |
| **跑得最快** | 库存下降最多的 SKU Top 10（实际卖出） |
| **新进货** | 库存上升最多的 SKU Top 10 |
| **红灯·超卖** | 可用库存为负的 SKU 数及最严重的 5 条 |
| **红灯·断货** | 7 天内可能断货的 SKU |
| **红灯·滞销** | 支撑天数 > 365 天且金额 > 1 万的 SKU |
| **新增滞销品** | 上周还在动 / 本周变为 0 销售的 SKU |

首次跑（没有上周快照）会跳过对比，只出本周分析。

## 五、注意事项 / 故障排查

- **2FA 拿不到验证码**：检查祥书手机号 18031674627 是否在身边；让他在吉客云后台「我的资料」改绑定手机
- **找不到「总库存查询」标签**：可能他的工号没有这个权限——这是 [200] 功能号，需要库存模块权限
- **导出按钮灰掉**：可能列表还没加载完，等加载完再右键
- **下载链接打不开**：吉客云导出文件 15 天有效期，过期重新跑一次
- **超过 50000 行**：要分两次导（按品牌或货品分类筛选），并改脚本接受多个 xlsx
- **跑分析报错 "未找到 xlsx"**：检查 `~/Downloads/总库存查询.xlsx` 是否真的下载下来了
