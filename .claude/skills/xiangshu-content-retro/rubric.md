# 祥书口播稿评分 rubric — v0（起步占位版）

> 这是**起步版**，权重凭直觉设、bucket 边界是占位。攒够 ≥5 篇真实复盘后跑「升级公式」，让数据重新拟合——那一版才是你账号真生效的公式。
> 评分对象：60-90 秒四段式口播稿（钩子/铺事/拐点/落点）。个人号 + 公司号共用，权重按号微调（见末尾）。

---

## v0 综合分公式

```
composite = (GO×1.5 + GD×1.5 + ZS×1.2 + CY×1.2 + GM + JJ) / 7.4 × 2.0
```

每维 0-5 整数分，composite 范围 0-10。

权重逻辑：**钩子 GO + 独特观点 GD** 是你 pipeline 反复强调的两个生死点（前3秒留不住人 / 拐点不独特等于没拐），给 ×1.5。**真实质感 ZS + 传播冲动 CY** 次之 ×1.2。这是凭直觉设的，要被你自己的数据验证——别当真理。

---

## 6 个维度（对齐四段式）

### GO — 钩子强度（权重 ×1.5）｜对应「钩子」段
*前 3 秒能不能逼人停下来看完 30 秒？*
- **0** — 自我介绍 / 讲背景 / 「今天我们来聊聊」式开场
- **3** — 一个具体承诺或反直觉断言
- **5** — 一个具体到能脑补画面的场景或断言，刷到的人手指停住

5/5 锚点：「上周一个客户半夜两点给我发消息说要退货」这种带时间、带动作、带悬念的具体开场。
0 分对照：「大家好我是做高尔夫的」。

### GD — 观点独特度（权重 ×1.5）｜对应「拐点」段
*那句「但我后来才发现……」是不是别人讲不出来的？*
- **0** — 拐点是常识，任何人都能说（等于没拐）
- **3** — 有个人视角，但不算稀缺
- **5** — 只有干了这行/这个阅历的人才能说出的反直觉观察

5/5 锚点：老板视角看一件大家以为理所当然的事，翻出底层逻辑。
0 分对照：「所以选装备一定要选适合自己的」这种谁都能讲的废话拐点。

### ZS — 真实质感（权重 ×1.2）｜对应「铺事」段
*铺的事是不是祥书真经历/真客户故事，有具体场景、具体对话、具体数字？*
- **0** — 抽象概括（「客户经常有售后问题」）
- **3** — 有个事但细节模糊
- **5** — 具体到时间/对话/数字/那个人（隐去身份），观众信这是真的

> 这是你的护城河——你的料别人编不出来。具体度直接拉这一维。

### CY — 传播冲动（权重 ×1.2）｜跨段
*看完想不想转发 / 评论接话 / @某个人？转发会不会暴露 ta 不想暴露的处境？*
- **0** — 看完就划走，转发等于自曝（如「我也被坑过」类痛点，转了显得自己蠢）
- **3** — 中性，转发无压力但也无冲动
- **5** — 转发/评论本身是一种表达（站队、自嘲、@该看的人、行业黑话共鸣）

> ⚠️ 关键陷阱：「受众广」≠「愿意传播」。一个小众但转发安全的话题，跑得过一个普世但社交暴露的话题。别被「这题受众大」骗。

### GM — 共鸣面（权重 ×1.0）｜跨段
*目标观众能不能在前几秒认出「这说的就是我/我关心的」？*
- **0** — 跟观众没关系
- **3** — 一类人会有感
- **5** — 戳中目标人群一个没被说破的痛点/爽点

> 公司号：目标是高尔夫人群（买装备的、新手、想升级的）。个人号：中年创业者/想深一层的人。别用大盘共鸣骗自己——要的是**目标号的目标人群**共鸣。

### JJ — 金句落点（权重 ×1.0）｜对应「落点」段
*落点能被截图/转发/评论区接话吗，还是变成了说教？*
- **0** — 说教（「希望大家都能……」「我们要……」）
- **3** — 一句还算记得住的收尾
- **5** — 一句独立拎出来还能在评论区/截图里活的话

0 分对照：任何「希望/我们要/一定要」开头的总结。

## bucket 预测（⚠️ 占位，必须按你账号体量重设）

> 下面是**占位边界**，不是你的真实分布。`/cheat-init` 等价的初始化里，先让祥书报两个号各自近 20 条的播放中位数 + 最高，按 percentile 设你自己的桶。
> 照搬下表 → 所有预测永远偏高或偏低。

| Bucket | 占位范围（播放）| 占位先验 |
|---|---|---|
| 沉底 | < 中位数 ×0.3 | 15% |
| 基础盘 | 中位数 ×0.3 ~ ×1.5 | 45% |
| 小爆 | 中位数 ×1.5 ~ ×5 | 30% |
| 爆款 | 中位数 ×5 ~ ×15 | 8% |
| 现象级 | > 中位数 ×15 | 2% |

每次预测给：**最可能 bucket** + **中枢**（桶内点估计）+ **全 bucket 概率分布（加起来 100%）**。
样本少时概率分布应该**更平**（如 25/30/25/15/5），别假装很确定。

## 两个号的权重微调

| | 公司号（高尔夫装备）| 个人号（老板思考）|
|---|---|---|
| 最看重 | GO 钩子 + ZS 真实质感（产品类信任是命）| GO 钩子 + GD 独特观点（老板视角是命）|
| 额外注意 | 转化暗示——但**不计入 composite**，单独在复盘记「这条带没带货感」| 真诚不端着——ZS 低于 3 直接警告 |
| 禁用词 | 必过 [[07-AI协作/规则/03-内容创作规范]]（测距仪专属：军用级/百分百精准…）| 同 |

> 公司号的「转化力」故意不进 composite——因为**能不能火**和**能不能带货**是两件事，混进一个分会污染流量预测。带货感单独在复盘段记一笔，将来够样本了可以拆成独立看板。

## 已知盲区（这套 rubric 注定打不准的地方）

1. **时长/完播**：6 个维度都不抓完播率。90 秒 vs 60 秒的完播差异单独追踪。
2. **平台情绪/时效**：算法这个月推什么会变，上月的爆款角度这月可能被压。
3. **拍摄/出镜质量**：rubric 只评稿子，你的表情、节奏、剪辑不在内——但它们真实影响流量。复盘时如果稿子分高却扑了，先排查是不是出镜/剪辑问题，别冤枉 rubric。
4. **运气**：单条噪声很大。别因为一条打脸就改公式——看 ≥3 条同向偏差再动。
