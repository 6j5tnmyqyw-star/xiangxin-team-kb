## 项目用途
祥书自己做的延展讨论项目（内置自己写的提示词），用来对一个话题做深度展开，给口播稿提供素材密度。

## 默认延展 prompt 模板
项目内已有提示词，直接发话题即可。本 skill 默认 prompt（项目特殊要求时可覆盖）：

```
帮我延展这个话题：[祥书的话题]

我要做一条 60-90 秒口播。请给：
1. 这话题最反常识的 3 个点
2. 已经被人说烂的 3 个角度（我要避开）
3. 可能的具体场景/案例素材 5-8 个（数字、对话、人物都欢迎）
4. 一句话总结这话题最该传达的核心观点
```
