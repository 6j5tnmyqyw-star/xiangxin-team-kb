# 迎客·客服副驾（xiangxin-yingke-kefu）

祥新 AI 组织里「客服」员工的副驾：把客服从「想话术」里解放出来——AI 起草，客服点确认就发。**只起草、不自动发**（隐私 + 控制）。

## 跑法

```bash
cd 07-AI协作/skills/xiangxin-yingke-kefu
python3 kefu_draft.py --type 询单 "Bushnell V6 和 V7 有啥区别，能便宜点不"
python3 kefu_draft.py --type 售后 --file q.txt --product "倍视能 V6 测距仪"
echo "客户消息" | python3 kefu_draft.py --type 询单
```

type：`询单`（售前咨询/比价/推进成交）｜`售后`（已购问题/退换/补发）｜`跟进`（沉默顾客/老顾客回访）

## 直接查库 kb_query.py（不起草、秒返现成答案）

销售/客服自己查「这个怎么答」用——纯检索、不调 AI、毫秒级，避免一个个私下重复问采购/助理：

```bash
python3 kb_query.py "GFORE的球包有没有送罩子"
echo "客户问的问题" | python3 kb_query.py
```

返回库里最相关的几条 QA 原文（含 [配图] 标记）；搜不到会老实说没搜到、建议补进知识库，不硬凑。

## 输出

【红线提醒】→【回复草稿】→【备选语气】→【需先核实】。客服核对后发出；重要的可再过一道「校官」复核。

## 关键设计

- 引擎 `claude -p` 起草；自动注入**客服红线**（平台订单严禁私下退款/退差价、大额卡单转私域话术、违禁词、天猫基准、圈t不优先香港、隐私不入正文）。
- **知识库检索**：库在 `03-公司/SOP与流程/销售客服/`（180+ 篇，从飞书「高尔夫知识库」镜像）。**核心文件 = `004-1-48` 客服销售问答（190 条标准 QA，同源「客服销售问答」wiki + 速查库 Base `VpcEbXEFta8rFZsjcevc03B5nNg`）**，检索时温和加权（`CORE_BOOST`）优先——势均力敌时标准 QA 胜出，但不碾压真正更相关的专门文档（实测售后/佳明/红线类专门问题仍正确命中专门文件）。检索 = 全库切成内容块、按客户问题做中文 n-gram + 型号词打分取最相关 top-k 注入（不再是旧的「文件名匹配 + 硬编码白名单 + 只读 1500 字」——那样 190 条问答基本调不出）。产品/政策据实回答不编。
- **隐私脱敏**：自动把手机号、长数字串(订单号)脱敏后再喂给 AI（守"客户隐私不进 AI"铁律）。
- 按需工具，不挂 launchd；别和别的重 AI 任务(claude -p 批量/codex)并发跑（会抢资源超时）。
- **售后问题先查历史**：起草售后话术前，用 [[xiangxin-shouhou-query]] 查该商品/品牌近一个月售后情况（多少单、主因是质量还是尺码/不想要），让话术有数据依据。
- 配套：发布前复核走 [[project_jiaoguan_review]]（校官）；客服问题沉淀走 [[xiangxin-jiucuo-daily]]。
