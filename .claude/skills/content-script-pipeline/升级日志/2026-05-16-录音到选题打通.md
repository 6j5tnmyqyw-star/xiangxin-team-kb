## 六、还差最后一公里

**飞书妙记 → `_待整理/` → 自动跑录音 pipeline + 摘选题** 这条链路还是手工的。

祥书原话："录音我都是每天的飞书妙记让 AI 放待整理里面的，需要每天及时整理，早上六点之前都整理好。"

现在状态：
- ✅ 妙记 → `_待整理/`：靠人喊或半自动
- ❌ `_待整理/` → 录音整理跑通 → 选题素材进库：**没有定时**

下次干这块时要做的：
1. 凌晨 5:00 新增一个 cron（比如 `com.xiangshu.recording-night-process`）
2. 扫 `_待整理/` 里昨天进来的妙记/录音类文件
3. 逐个跑录音 pipeline（含新规则的选题素材摘取）
4. 6:00 前完成，8:57 daily-golf 就能直接吃到当天的录音料

这才是真正的"录音→选题"全闭环。

## 七、踩过的坑（给未来的 AI 看）

1. **launchd + iCloud 中文路径 = 必崩**。看到日志里 `祥�\M--\M-^P AI` 这种乱码，立刻把 sh 搬到 `~/.claude/scripts/`。
2. **claude -p 在 launchd 下要自己 export 代理**。已写进 sh 模板。
3. **`_待整理/` 没有自动归档进程**（[[project_inbox_auto_archiver]] 记过）。文件不会自己走。
4. **个人号选题库 `_每日候选/` 目录默认不存在**。sh 指令里已写"目录不存在就建"。
