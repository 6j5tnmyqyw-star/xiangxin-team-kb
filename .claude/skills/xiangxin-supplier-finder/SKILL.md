# 采购·供应商速查（supplier-finder）

> 采购员工的「活字典」：把 72 家供应商按品牌/开票/联系方式结构化，问什么答什么；要登记新供应商或改报价时写回飞书 Base。

## 一、什么时候用

祥书或采购同事（阳阳等）说出以下意图就触发：
- **找货**：「Garmin 找谁拿」「这个 PING 的杆谁有货」「圈t 调货找谁」「TaylorMade 哪几家可以比价」
- **查联系/条件**：「XX 供应商电话多少」「账期是先款后货还是月结」「在哪个工作群」「地址/收货信息」
- **开票**：「XX 能开专票吗」「加几个点」「哪些供应商能开 13% 专票」
- **对公打款**：「给 XX 打公账，银行账号税号发我」
- **登记/更新**：「加个新供应商 XX」「XX 现在报价变了，记一下」

**不适用（走别的 skill）**：
- 供应商对账、挂账核对 → [[supplier-reconciliation]]（库管，传两张表对金额标颜色）
- 吉客云里查某 SKU 的采购单/采购记录 → [[jackyun-api]]
- 给采购同事派任务 → 飞书任务（注意：带金额的供应商往来**不挂【祥新任务】公共清单**，见铁律 4）

## 三、查询怎么答（标准动作）

1. **先读本地副本** `03-公司/供应商/00-供应商信息汇总.md` 的对应章节，grep 关键词定位。
2. **找货类**：列出该品牌**所有可选供应商**（不是只给一家），方便祥书比价；每家标地区。
   - ⚠️ 圈t（杆身/握把/工坊调货）问题：看 `## 二` 的「圈t/工坊·杆身握把」分组，**优先推大陆供应商，不优先香港**（铁律 1）。
3. **联系方式/账期/地址/工作群**：读 `## 四、明细表`，把该供应商整行字段答全。
4. **开票**：先看 `## 三、开票速查` 判断能否开专票、税点、是否额外加点。
5. **对公打款**：读 `## 五`，把银行/账号/税号原样给出（这是公账信息不是隐私，可用，但别外传无关方）。
6. 答完如果信息可能过期（本地副本更新日期见文件 frontmatter），提示「以飞书 Base 为准，需要我去 Base 核最新的吗」。

## 四、登记新供应商 / 更新报价（写操作）

**飞书 Base 是权威源**，先写 Base 再同步本地副本。

1. 用 [[lark-base]] 先查表结构（字段名/类型），别凭空猜字段：
   - base token `JuuHbtMBGatW4HsfTwIc0dsRnnb`，table `tblZozjwKRtj0Mab`
2. 写记录（新供应商）或更新字段（报价/账期变更）。
3. 同步更新本地副本 `00-供应商信息汇总.md` 对应章节 + frontmatter 的「更新日期」「供应商数」。
4. 写操作前把要写的内容念给祥书确认一次（金额/账期这类敏感字段尤其）。

## 五、铁律

1. **圈t 优先大陆**：调货（询货/工坊/杆身握把）不优先找香港，香港时效不可靠 → 推荐顺序大陆在前。
2. **本地是副本、飞书是权威**：两边不一致以飞书 Base 为准；改了一定两边同步。
3. **多家可比价**：找货默认给出同品牌的多家供应商，不要只丢一家。
4. **带金额的供应商往来不进公共任务清单**：返利/挂账/打款金额只走本地或私聊祥书，不发【祥新任务】（那是团队公共面板）。
5. **对外不外传**：供应商联系方式、报价、对公信息只在内部用，不出现在对外文案/给客户的内容里。
