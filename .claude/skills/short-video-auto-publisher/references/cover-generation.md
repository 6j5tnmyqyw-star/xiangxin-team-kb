# 封面生成：ChatGPT 出无字底图 + 本地叠中文标题

**为什么分两步**：祥书要 AI 生成封面，但 [[chatgpt-image-maker]] 红线明确——**GPT 生成的中文字常缺笔画/乱码**。所以封面 = ChatGPT 出**干净竖版视觉底图（绝不放中文字）** + 本地 `make_cover.py` 把**正确的中文标题大字**叠上去。既要 AI 的好画面，又要文字不出错。

---

## 第 1 步：ChatGPT 出底图（走 chatgpt-image-maker 路径 A）

照 [[chatgpt-image-maker]] 的 browser-harness 路径 A（开 chatgpt.com → 发 prompt → 等停止按钮消失 → 从 estuary 抓图 fetch 转 base64 下载）。

**底图 prompt 骨架**（按视频主题填，竖版，强制留白给叠字，禁文字）：

```
高尔夫主题竖版封面背景图，9:16 竖构图。画面：<按视频内容填，如"清晨高尔夫球场果岭，一只手持测距仪测距，背景虚化球道，专业克制氛围">。
光线：清晨柔光、专业、克制，不浮夸。
构图要求：主体偏下或偏侧，**顶部留出大片相对干净的区域**用于后期叠加标题文字。
重要：画面里**不要出现任何文字、字母、数字、水印、logo**。高质量，电商级质感，分辨率不低于 1080×1920。
```

- 风格沿用公司视觉规范：高尔夫球场 / 清晨光线 / 专业 / 克制。
- **再三确认 prompt 里写了"不要任何文字"**——底图带字会和后期叠字打架。
- 生成后看截图：若 AI 仍自作主张加了字，删掉重生成。

底图存 `/tmp/svap_bg.png` 备用（或 `99-附件/AI生成图/` 临时）。

---

## 第 2 步：本地叠标题大字（make_cover.py）

```bash
python3 scripts/make_cover.py \
  --bg /tmp/svap_bg.png \
  --title "测距仪功能太多 记住一个词:无感化" \
  --out "99-附件/AI生成图/20260524_测距仪_封面_v1.png" \
  [--subtitle "老板视角｜怎么选不踩坑"] \
  [--size 1080x1440]   # 默认 1080x1920(9:16)；小红书友好可用 1080x1440(3:4)
```

脚本做的事：
- 把底图等比缩放/居中裁切到目标尺寸（默认 1080×1920）。
- 顶部叠**标题大字**（中文，PingFang 粗体，自动换行，描边/半透明底条保证任何背景都看得清）。
- 可选副标题小字。
- 用 macOS 自带 PingFang 字体，中文不会缺字。

**标题文字也要过违禁词红线**（见 [copywriting.md](copywriting.md)）——叠到封面上的字同样不许出现极限词。

---

## 尺寸与多平台

- 起步**一张通用竖版封面**（1080×1920）三平台通用，平台会自适应。
- 若要分平台精细化：抖音 9:16（1080×1920）、小红书 3:4（1080×1440）各出一版，`--size` 切换，`--out` 加平台后缀。
- 视频号封面用竖版那张即可。

---

## 命名归档

```
YYYYMMDD_产品/主题_封面_[平台]_vN.png   →  存 99-附件/AI生成图/
例：20260524_测距仪_封面_v1.png
```

底图（无字版）可一并留 `_底图` 后缀，方便改标题重叠不用重新生成。
