# 普利司通

# 高尔夫

# 球

# 

高端高尔夫球通常考虑了球手对操控或者距离的需求，根据不同的材质去打造适合求受需求的产品。通常来讲 操控更好的球 打杆更加软一点而追求距离的高尔夫球会在击倒的时候 反馈更加硬。

比如我们常知道的泰勒梅的tp5跟tp5x，还有titleist的Pro v1还有Pro v1x。两款明星产品供不同需求的球手选择。 

我们知道击球软硬 其实反馈到每个人的感觉上是有差别的 而这种差别主要来自于不同球员的挥杆速度。这样就会造成可能有的人打同样一款球会觉得是软的 但是另外一个人可能打他就是硬 那有没有什么办法去解决这样一个不同挥杆速度 球员选择球的问题呢？

普利司通的高尔夫球为我们带来了解决方案。我们都知道普利司通是做橡胶轮胎非常出名，因为高尔夫球也是橡胶制作 所以普利司通母公司就进军了高尔夫球行业 并且在行业内也有几十年的研发。

他们通过对不同球员恢复的差异 总共设计了四款不同类型的高尔夫球。tour b x 跟tour b rx 这两款球适合追求距离的球友他们分别适用于挥速高于105或者低于105的球员。

xs跟rxs两款适合注重操控的球员 果岭停球更好，也是分别适用于挥杆速度高于105或者低于105的球员。

这样我们不同追赶速度的球手都有适合自己需求的高尔夫球，有点类似于高尔夫球的量身定制，不知道根据您的情况会选择哪一款 我觉得完全可以来试一试 或许能找到自己最合适的甜蜜球款！
