# 公司号 · 定位

## 核心人设（一句话）

一个真实的高尔夫电商老板，带你看这个生意里真实的样子——装备背后的门道、客户的真实故事、做这门生意的酸甜苦辣。

## 三个支柱（6:3:1）

### 支柱 A · 老板视角的行业内幕（60%）
公司号的主菜。
可拍角度：装备真实成本 / 行业潜规则 / 采购故事 / 老板视角讲价格逻辑 / 同行做的蠢事聪明事。
**关键差异：不打球反而是优势——不陷在技术细节里，站在生意人的高度看行业。**

### 支柱 B · 客户故事与陪伴（30%）
转化最直接的内容。
可拍角度：客户真实故事（隐去身份）/ 客户奇葩问题 / 买完反馈 / 帮客户避坑的真诚建议。

### 支柱 C · 基础高尔夫科普（10%）
只做最基础的（礼仪、黑话、新手扫盲），不跟深耕的账号比专业。
作用：让账号有「高尔夫属性」，方便算法推荐和新观众看懂前两个支柱。

## 不拍清单

- 不拍硬广
- 不拍同行八卦
- 不蹭无关热点
- 不装专业（不打球就别假装教练）
- 不拍纯产品参数（交给同行做）

## 关键约束

**必须真人出镜。** 公司号的核心差异化是「真实的老板」，没有真人出镜，这个差异化不成立。

## 与个人号的关系

公司号是辅，承接「你做什么」（信任 → 生意）。
公司号简介挂个人号链接，展示的是个人号里那个爱思考的人在做生意的状态。
**内容绝不重叠**：公司号永远不发纯个人思考，个人号永远不发纯装备 / 技术内容。
