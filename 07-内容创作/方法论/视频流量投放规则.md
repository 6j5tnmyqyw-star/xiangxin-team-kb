# 视频流量投放规则

## 一、适用对象

挂载商品或参与竞拍的重点视频。

## 二、投放标准

| 条件                  | 动作     |
| ------------------- | ------ |
| 播放量 > 10% 且完播率 > 8% | 少量增加流量 |
| 播放量 > 12%（隐含完播率达标）  | 大幅增加流量 |

## 备注

- "播放量 %" 与 "完播率 %" 的具体口径（基数是曝光？粉丝量？）需补充确认
- 适用平台未指定，默认抖音/视频号体系
