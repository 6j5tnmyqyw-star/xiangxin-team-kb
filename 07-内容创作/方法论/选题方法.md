# 选题方法

> 能拍的话题不是坐着空想出来的，是从固定的几个「口子」里捞出来的。
> 这份文档定义祥书的**四个话题来源** + 一条选题进库的最低标准。公司号 / 个人号共用这套方法，只是各源的配比不同。
> 配套：[[选题来源]] 速查（如有）、流水线 skill `content-script-pipeline`（定义"怎么把料变成脚本"）。

## 一、四个话题来源（按优先级从上到下）

可拍话题固定从这四个口子捞，**越靠上越真实、越不容易撞车**：

### 1. ⭐ 我的录音（最高优先级）
我日常的口述、思考、会议、跟家人/同事的对话，经录音 pipeline 转写后落在 `01-每日/录音原文/`（全天录音整理）和 `01-每日/录音原文/妙记原始逐字稿/`（会议逐字稿）。
- **为什么排第一**：是我**亲口说过**的，最真实、最有我的味道、最不可能跟别人撞题。
- **怎么用**：选题日扫最近 5-7 天录音整理，挖"具体的事 + 我的独特观点"，按四栏写进待开发库，标 `来源：[[录音原文/...]]`。
- 公司号 → 装备门道 / 采购故事 / 客户故事 / 价格逻辑；个人号 → 老板思考 / 中年生活 / 学习新知。

### 2. 日常工作中的问题（问题日志 Base）
公司每天暴露的真实问题——客服踩的坑、采购的教训、运营的卡点——沉淀在飞书【Claude纠错日志】Base 和日报里。
- **为什么能拍**：真实问题 = 真实内容。一个客户的奇葩问题、一次采购的后悔、一个被规则堵住的漏洞，都是公司号支柱 A/B 的好料。
- **怎么用**：扫近期问题日志，挑"有普遍性、能讲成故事、脱敏后不敏感"的。
- 主要供公司号；个人号可从中提炼"老板怎么看管理 / 团队"的思考。
- ⚠️ **隐私铁律**：客户姓名 / 手机 / 地址 / 订单号绝不出镜，问题脱敏后再用。

### 3. 最新新闻资讯
跟我领域交叉的新闻——高尔夫行业新品 / 赛事 / 政策（公司号），经济 / AI / 创业 / 中年话题（个人号）。
- **为什么能拍**：蹭"新"带流量，但**只做引子不做搬运**——用老板视角 / 我的真实观点切入，新闻只是由头。
- **怎么用**：WebSearch + 我平时刷到的；必须配一句"我对这条的独特看法"才算合格，纯转述不算。
- 不蹭无关热点（公司号定位铁律）。

### 4. 抖音热榜（去话题热榜里搜）
去抖音的话题热榜 / 搜索里找正在被搜的关键词，看哪些跟我的品类 / 人设搭得上。
- **为什么能拍**：这是**需求验证**——大家正在搜的，就是平台正在给流量的。
- **怎么用**：搜高尔夫相关关键词（公司号）、老板 / 中年 / AI 相关（个人号），结合热度 + 库存缺口立选题。公司号待开发库里已沉淀过一批抖音热榜数据，可复用。

> **四源优先级铁律**：录音 > 工作问题 > 新闻资讯 > 抖音热榜。录音是我自己的话，先挖干净；前两个口子料足时，新闻和抖音只作补充。

## 二、四个源 → 两个账号（配比不同）

| 来源 | 公司号（高尔夫电商） | 个人号（邹祥书） |
|---|---|---|
| ⭐ 录音 | 装备 / 采购 / 客户 / 价格故事 | 老板思考 / 中年生活 / 学习新知 |
| 工作问题 | **主力**（客服 / 采购 / 运营真实坑） | 提炼成"管理 / 团队"思考 |

| 抖音热榜 | 高尔夫品类关键词 | 老板 / 中年 / AI 关键词 |

支柱配比：公司号 A 行业内幕 60% / B 客户故事 30% / C 科普 10%；个人号 A 老板思考 50% / B 中年生活 30% / C 学习新知 20%。

## 三、一条选题进库的最低标准

**四栏填满才算合格，填不满说明还没想清楚：**
- **钩子一句话**（前 3 秒说什么，要让人停下来）
- **核心观点一句话**（整条视频要传达的那一个点）
- **归属支柱**（A / B / C）
- **来源标签**：`【录音】` / `【工作问题】` / `【新闻】` / `【抖音热榜】`——录音来源的排最前

## 四、节奏建议

- **周一（1-2 小时）选题日**：按四个源捞料 → 写进「待开发」→ 挑本周要拍的剪切到「已选定」→ 各自建脚本草稿。
- **周二、周三 写文案**：打开草稿按四段式写，定稿移到「待拍」。
- **周四、周五 拍 + 剪 + 发**：发完脚本移到「03-已发布」，改名加日期。
- **周日（20 分钟）周复盘**。
- **任何时候**：看到、想到、聊到、踩坑的，立刻记进 `04-内容创作/素材库/灵感速记.md`——这是录音之外的第二条源头活水。

## 五、跟流水线 skill 的关系

本文定义"**料从哪来**"（四个源）；`content-script-pipeline` skill 定义"**怎么把料变成脚本**"（搜话题 → 采访 → 写文案 → 归档）。选题日 AI 自动跑第一段时，就是按这四个源捞料、出 5-8 条候选选题。

## 六、筛选台 + 不拍/要拍回写流程（固定流程）

> 待开发库选题攒多了要筛。祥书在**妙搭选题库筛选台**（手机可开）上点 要拍 / 不拍，把清单发给 AI，AI 回写库 + 刷新筛选台。这是固定流程。

- **筛选台**：妙搭 app `app_4k7hr12xxjvgt`（公司域名 `xiangxingolf.aiforce.cloud`，手机直接开），镜像两个账号的「待开发库」全部选题，三维筛（账号 / 支柱 / 来源）+ 三态标记（要拍 / 不拍 / 不动）。
- **祥书操作**：在筛选台点 要拍✅ / 不拍✖，把**不拍清单**发给 AI（`[账号][支柱] 标题` 一行一条即可）。
- **AI 收到不拍清单的固定动作**：
  1. 在对应账号 `01-选题库/待开发.md` 找到该选题块 → 剪切到同目录 `已废弃.md`（`###` 格式，加 `废弃日期`）。
  2. 从筛选台数据里删掉这几条（按 `账号|标题`）。
  3. 重新内联 + 发布妙搭，**同 app_id 链接不变**，祥书重开即新版（不拍的卡片消失）。
  4. 跑完推送祥书一条飞书确认。
- **要拍**：对应块剪切到 `已选定.md` → 走 `content-script-pipeline` 写脚本。
- **执行工具**（AI 用，可复用）：`~/.claude/scripts/topic-triage/republish.py`
  - `--remove remove.txt`（每行 `账号|标题`）删不拍；`--publish` 才真发布，不加只本地构建验证。
  - 自动：删 TOPICS → esbuild 编译 JSX → 内联 tailwind/react/lucide 成零依赖单文件 → `lark-cli apps +html-publish` 发布。
  - 权威源 `99-附件/AI生成/选题库筛选台.html`（CDN 可双击版，脚本会把删改写回）；部署产物 `~/work/miaoda-deploy/topic-triage/index.html`。
- **新增选题如何进筛选台**：直接编辑 `选题库筛选台.html` 顶部 `const TOPICS = [...]` 追加条目（`account/pillar/title/hook/point/sources/date`）→ 不带 `--remove` 跑一次 `republish.py --publish` 即可。
