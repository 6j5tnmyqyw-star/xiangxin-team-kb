## 2. 店铺数据核算与利润（季度权重 10%）

- 每月数据汇总并核算利润率，参见 [2025/26年数据汇总、比对](https://xiangxingolf.feishu.cn/sheets/W6vdsLAZHhMZVEtBFv6cJGVWnjO?sheet=mNHita)

**流程规则**（从 2024–2025 历史错误沉淀）：

### 2.1 单订单成本核对清单（每单逐项过，防漏）

每条订单核算时，下列费用都要逐一确认，缺一项就视为未核对完：

- ☐ 主商品成本
- ☐ 运费（陆运 / 空运 / 代发 / 到付）
- ☐ 赠品（送球、tee、袖套、球包配件、礼盒、清仓奖励品）
- ☐ 定制费 / 印刷费 / 安装费
- ☐ 平台服务费 / 支付服务费 / 平台扣点
- ☐ 分期付款订单的额外服务费
- ☐ 进项税点（注意小规模税率和符号）
- ☐ 售后退款 / 换货差价（**最高频出错项，重点过**）

### 2.2 系统成本不可全信——下列来源必须二次核对

以下供应商 / 品类系统价格不准，**不能直接照抄系统**：

- 韩国代购系列
- 廖篇家衣服
- 喜力克斯球包
- 昕晖鞋子
- 魔镜系列（早期对账）
- 第三方代发整体
- 22 年及更早入库、找不到成本的（不要默认填 0）

**核对方式**：① 供应商微信群翻聊天记录（按客户姓名/地址/订单号）→ ② 问采购二次确认 → ③ 群里直接问供应商。三选一，不能拍脑袋。

### 2.3 运费补录窗口

- 部分供应商运费 **T+3 天**才显示，对账单生成前要回头扫最近 3 天有无新到账运费
- 「**到付**」订单尤其警惕：系统显示无运费 ≠ 真的无运费，要事后再查一次账单
- 第三方自扫码下单、代发等系统查不到运费的，标注「待核」，不默认 0

### 2.4 「三看」核对：价格 / 型号 / 数字

历史反复错点："看茬了""少写一位""看错型号""日期看混"

- 价格看准小数点和位数
- 鞋子 / 球包 / 球杆 / 服装等多型号品类，必须二次确认型号
- 群里报价单看 **最新一份**，旧报价单作废后不再使用
- 数字录入完逐位回读一遍

### 2.5 折扣 / 清仓单独标记

折扣相关错误高频：多算折扣、清仓未达条件、清仓产品按正价、同一款误按 9 折……

- 任何带「折」「清仓」「奖励价」字眼的订单 → **单独标色或拉到单独 sheet**
- 最后单独复核这一组，不和正价单一起过

### 2.6 业绩归属 / 订单筛选

- **未发货订单**不计入当月业绩
- 业绩归属筛选完，**临时辅助列必须删除**（曾因没删导致订单重复）
- 同一订单不允许分给两个人（客服转化、服务费调整等情况要确认归属）
- **跨店铺引流订单**：业绩归引流店铺，以订单备注的「来源·X 店铺」为归属依据（客服-013，2026-06-12 起；销售成交时负责备注）

### 2.7 公式自检

- 公式拉到最后一行（订单多时容易漏）
- 提交前按供应商筛选复核成本，按业务员筛选复核归属

**流程规则**（从历史错误整理）：

## 7. 订单复核与售后

- 订单复核
- 售后退款处理
- 欠款计应收订单的收款工作（ERP 操作收款；2026-06-12 起按客服-011 升级为**每周**过欠款应收单：监督对应销售追尾款、核对回款改状态，超期与对应销售协调，详见 [[08-公司知识库/06-销售客服规则]] 客服-011）

**流程规则**（售后是历史错误第二高频项，重点防）：

### 7.1 售后退款「双系统比对」

每月对账时，售后单必须从两边查：

- **ERP 系统** + **网店后台**（淘宝 / 抖音 / 京东 / 拼多多 / 视频号等）
- 以二者**并集**为准
- 抖音特别注意：抖音系统订单核对的售后单可能不显示，但 ERP 上有 → 漏过

### 7.2 退款 / 换货必查项

- **退款差价**：曾多次漏写（8月-2024、9月-2025 等）
- **换货订单**：原订单其他货物的成本不要漏加，要与采购 / 业务员核对换出 vs 换入
- **审核状态**：售后退款必须确认是否已审核，避免"没审核但实际已退款"
- **售后清仓**：清仓奖励、清仓差价等单独走

### 7.3 核算提交后的售后窗口

- 月度对账提交后 **3 天内** 仍可能新增退款单（如核算完提交才生成的退款单）
- 规则：① 提交前再扫一遍当月售后单 ② 提交后 3 天内若有新增退款，下月对账时补上
- 这类延迟退款**不算入当月错误率**（参照原表 5月-2025 处理）

# 二、常见错误类型（乐捐对照）

如未按时反馈以下错误，一次乐捐 20 元：

1. **结算错误**：供应商结算金额错误、重复付款、付款信息错误
2. **数据统计错误**：收入、成本、利润数据不准确（每月容错 2 次）
3. **税务申报错误**：漏报、错报、逾期申报
4. **账务处理错误**：科目归类错误、凭证缺失
