# 一、内容制作

## 1.1 定位

- 主：Bushnell 测距仪（V6 / V6S / V7S / PRO XM）
- 辅：Garmin（S70 / R50 / G82）、Ping / Callaway
- 风格：实测 + 真实场景，不浮夸

## 1.2 脚本

- 短视频 ≤ 30 秒，长视频 ≤ 3 分钟
- 结构：钩子（3 秒）→ 对比/演示 → 结论 → CTA
- 数据真实，引用标来源
- 大众语言，不堆术语
- 发布前自查违禁词

## 1.3 拍摄

- 横屏 16:9（公众号/长视频）/ 竖屏 9:16（短视频）
- ≥ 1080P，重要素材 4K
- 关键镜头上稳定器，每场景拍 2-3 条备份
- 现场录原声
- 视角平视前方，不仰拍/俯拍

### 合集/多品必检（重要）

- 多产品同框前**逐项点名主推品清单**，缺一不开拍
- 主推品：Bushnell 全系 + Garmin 测距仪/GPS
- 标准动作：清单打勾 → 全景预览图群内确认 → 拍完当场回看 → 成片复核
- 漏拍立即同步并补拍，事故进 Base 复盘

## 1.4 剪辑

- 前 3 秒出钩子，无 LOGO 长开场
- 单镜头 ≤ 3 秒
- 关键数据点上字幕
- 输出：1080P / H.264 / 8-12 Mbps
- 自查：声音、字幕、违禁词

## 1.5 违禁词

- 绝对禁用：极致、史上最低、第一、绝对、国家级、最、唯一、顶级、独家
- 测距仪禁说：军用级、百分百精准、零误差
- 价格只说"店铺活动价"，不说"最低价"

## 1.6 配图

- 豆包 AI，≥ 1080×720
- 关键词：高尔夫球场 / 清晨 / 专业 / 克制
- 比例：16:9（封面）或 3:4（正文）

## 1.7 直播

- 开播前：设备、商品、脚本、链接/券逐项检查
- 直播中：违禁词、价格库存口误零容忍；演示必须真做
- 下播后：数据回填运营组表，问题进 Base

## 1.8 素材命名
```plaintext
YYYYMMDD_产品_场景_版本.mp4
例：20260510_BushnellV6S_球场实测_v2.mp4

```

- 原片/工程/成片/封面分目录
- 重要素材双备份（本地 + 云盘）
- 工程文件保留 ≥ 3 个月

## 1.9 发布挂链接（重要）

- 商品类内容，所有平台**必须挂全链接再发**，禁止"先发回头补"
- 平台清单：小红书、抖音、视频号、公众号、天猫/京东内容场
- 标准动作：逐平台确认 → 核对店铺与 SKU → 文案提到"链接在 X"必须真在 → 发布后游客身份点一遍验证跳转/价格/库存
- 漏挂/挂错立即补挂或下架重发，群内同步，引发投诉进 Base

# 二、日常运营

## 2.1 组装球杆

- 核对杆头/杆身/握把/配件，缺件群里报，不替换
- 按出厂扭矩组装
- 组完当场测试：握把牢固、杆头无松动、长度对
- 拍照留底（杆头/握把/全杆/SN）
- 客户单双人复核或自核两遍
- 出库登记：日期 / 订单号 / 组装人 / 复核人

## 2.2 整理公司物品

- 每周五下班前整理一次
- 分区：测距仪 / GPS / 球杆 / 配件 / 包装耗材
- 样品区与库存区严格分开，样品贴标签
- 上架贴标签：品名 / 型号 / 入库日期 / 负责人
- 公用工具用完归位
- 易耗品低于阈值立即群里报
- 破损/丢失：拍照 + 进 Base，不私自处理

## 2.3 样品拍摄

- 拍前清洁去指纹
- 背景：白底或球场，按用途选
- 必拍：正面 / 侧面 / 细节 / 配件全家福
- 命名：`YYYYMMDD_型号_角度.jpg`
- 归档到对应商品文件夹

## 2.4 样品发货

- 客户信息严格按公司规则，不外传
- 包装：测距仪/GPS 双层气泡膜；球杆专用袋 + 硬纸管
- 附件按清单装齐（说明书/保修卡/赠品）
- 发货前拍照留底（商品 + 附件 + 面单）
- 录单：单号 / 时间 / 收件人 / 商品，回填运营组表
- 单号及时告知对接人/客户

### 样品回收

- 借出登记：日期 / 借出人 / 预计归还日
- 超期主动催收
- 回收时检查完整度，破损/缺件走报损
