## 【祥新公司规则】客服-004 客户称呼规范

- **生效日期**：2026-05-15
- **发布人**：邹祥书
- **适用范围**：全公司线上接待 / 私域聊天 / 售后跟进所有客服接待场景

**一、规则**
1. 男性客户统一称"**哥**"。已知姓氏 → "姓 + 哥"（如"王哥""李哥"）；未知姓氏 → 直接"哥"。
2. 女性客户统一称"**姐**"。已知姓氏 → "姓 + 姐"（如"王姐""李姐"）；未知姓氏 → 直接"姐"。
3. **禁用称呼**：
   - "**美女**"——不论年龄外貌一律不用。
   - "**亲**" / "**亲亲**" / "**亲爱的**"——一律不用。
4. 客户主动报姓氏 → 立即切换为"姓 + 哥/姐"。
5. 客户已有更正式身份称谓（如"张总""李教练""陈队"）→ 按客户原有称谓走，不回退到"哥/姐"。

**二、原因**

"美女""亲"显得轻浮、不专业，与高尔夫客群（成熟、商务、中高净值）调性不符。统一"哥/姐"自然、亲切、有边界感。

**三、执行职责**
1. **凌晨**：抽检所有窗口称呼用语；连续 2 次违反 → 报阿祥。
2. **月阳 / 珊珊 / 月月 + 各店客服**：执行本条规则。
3. **运营专员（嘉欣 / 荔枝 / 娜娜 / 鹤子 / 老孙）**：本店客服日常监督，发现违反当场纠正。
4. **老孙 + 凌晨**：一周内排查并更新现有话术库 / 自动回复 / 千牛机器人话术中包含"亲""美女"的条目。

**四、来源**

## 【祥新公司规则】客服-006 平台订单严禁私下退款 / 退差价

- **生效日期**：2026-05-17
- **发布人**：邹祥书
- **适用范围**：全公司线上客服窗口，处理 天猫 / 京东 / 淘宝 等平台订单时

**一、规则**
1. 不得答应客户通过 **微信 / 支付宝 / 个人转账** 等任何线下私人渠道退款。
2. 不得答应客户通过私下渠道 **退差价 / 返利 / 补偿** 等任何形式的金额返还。
3. 即便客户主动提出"走微信更方便、能多退一点"，也一律拒绝。
4. 客户的"返利 / 多优惠"诉求 → 走**平台优惠券 / 改价 / 补发**，不走个人账户。
5. 平台规则无法满足的特殊补偿诉求 → **先汇报凌晨主管 / 阿祥**，不得自行答应客户。
6. 红线：所有退款 / 退差价 / 补偿，必须**原平台原路退回**（淘宝单走淘宝、京东单走京东）。

**二、原因**

已发生案例：淘宝订单中，客服私下答应客户通过微信退差价（实质返利）。

私下退款 / 退差价的风险：
- **平台风控**：私退绕过平台资金流，账号有扣分 / 降权 / 封店风险。
- **财务对账**：体外循环对不上账，税务不可控。
- **客户二次索赔**：客户既走平台退款保护、又拿了私下补偿，公司双重损失。

**三、执行职责**
1. **凌晨**：抽检聊天 / 售后记录，发现私退立即纠正；连续 2 次违反 → 报阿祥。
2. **月阳 / 珊珊 / 月月**：执行本条规则；客户提出"走私下"必须拒绝。
3. **各店运营专员（嘉欣 / 荔枝 / 娜娜 / 鹤子 / 老孙）**：本店客服私退监督。
4. 异常补偿诉求（平台无法满足）→ 客服报 **凌晨 + 阿祥** 决策，不得自行答应。

**四、来源**

## 【祥新公司规则】客服-007 禁用「今天下单」高压逼单话术（红线）

- **生效日期**：2026-05-24
- **发布人**：邹祥书
- **适用范围**：全公司线上客服窗口（天猫 / 京东 / 淘宝 / 私域）

**一、规则**

🔴 **红线（零容忍）**：禁止使用以下一切「今天限定」高压催单话术：
- 「今天下单才有这个价」
- 「今天专属优惠，明天就没了」
- 「今天不下单就没有这个优惠了」
- 其他以「今天」为时间边界、制造紧迫感逼客户当天成交的表述

**正向替代话术**：
1. 有真实活动截止日期 → 给明确日期范围，如「618 活动期间（6月1日-6月18日）下单都能享受这个优惠」。
2. 无真实截止日期 → 不造截止，用软语气引导，如「这款最近很多人在拍，您有需要的话我帮您留意一下库存」。
3. 客户还在犹豫 → 聚焦产品价值和适合理由，不施压。

**二、原因**

5月4日—5月10日聊天复盘发现，客服多次使用「今天不下单就没有这个优惠」等话术，导致客户连续反问、情绪反弹，直接拉低成交率。高尔夫客群（成熟、商务、中高净值）对高压逼单高度反感，此类话术不符合品牌调性，且因无法兑现而损伤客户信任。纠错日志 `recvjWYzKmFOrn`，出现 6 次。

**三、执行职责**

1. **凌晨**：抽检聊天记录，发现一次违规即通报；连续 2 次 → 报阿祥。
2. **月阳 / 珊珊 / 月月 + 各店客服**：立即停用上述话术；修改已有话术库 / 千牛快捷短语中涉及「今天」限时表述的条目。
3. **各店运营专员（嘉欣 / 荔枝 / 娜娜 / 鹤子 / 老孙）**：本店客服话术检查，本周内完成自查。
4. **老孙 + 凌晨**：本周内排查并更新话术库 / 自动回复 / 千牛机器人话术，清除所有「今天」限时逼单表述。

**四、违反处理**

违反本红线，责任客服当次扣绩效，情节严重报阿祥处理。

**五、来源**

纠错日志 `recvjWYzKmFOrn`；邹祥书 2026-05-24 批准并发布。

## 【祥新公司规则】客服-008 抖音平台严禁主动加客户微信（红线）

- **生效日期**：2026-05-27
- **发布人**：邹祥书
- **适用范围**：抖音 / 抖店所有客服窗口（抖音祥新高尔夫店，珊珊 / 月阳等）

**一、规则**

🔴 **红线（零容忍）**：

1. 在抖音平台（私信 / 评论 / 直播）**严禁主动加客户微信、严禁引导客户加微信、严禁发微信号 / 二维码 / "加我微信"等任何站外引流表述**。
2. 客户**主动**要微信，也**不在抖音对话框给**——用平台话术婉拒，引导走平台内沟通或留电话。
3. 抖音订单的方案、优惠、产品图，统一在抖音平台内沟通，不导流到站外。
4. 退款 / 退差价同客服-006，原平台原路退回，不走私下。

**二、与「卡单加微信转私域」规则的边界（重要）**

2026-05-21《大额订单卡单加微信转私域》规则**仅适用于天猫 / 淘宝 / 京东**等非抖音平台；**抖音平台不适用该规则——抖音上一律不主动加微信**。

**三、原因**

抖音对站外引流（加微信）查得极严，违规直接罚款。已有同事因在抖音加客户微信被平台**罚款 2000 元**。一次违规成本（罚款 + 账号风险）远高于私域转化收益。

**四、执行职责**

1. **凌晨**：抽检抖音窗口聊天记录，发现主动加微信 / 发微信号即纠正、通报；连续 2 次违反 → 报阿祥。
2. **珊珊 / 月阳 + 抖音店客服**：严格执行本规则。
3. **各店运营专员**：本店抖音窗口的日常监督。

**五、违反处理**

违反本红线导致平台处罚的，由责任客服承担相应损失，并**按平台罚款金额扣减对应绩效**；情节严重报阿祥处理。

**六、来源**

抖音店客服反馈（已发生同事被罚 2000 案例）；邹祥书 2026-05-27 批准并发布。

## 【祥新公司规则】客服-009 千牛手动添加闪送物流必须选同城/商家配送

- **生效日期**：2026-06-10
- **发布人**：邹祥书
- **适用范围**：全公司在千牛后台手动添加物流单号的场景（闪送等同城配送订单），含客服销售 + 采购/发货对接岗（阳阳 / 鹤子 / 舒怡）

**一、规则**

1. 千牛后台手动添加闪送等同城物流时，物流方式**必须选择「同城配送」或「商家配送」**。
2. 选「同城配送」时，选择对应的配送平台（如闪送），填入对应订单号即可。
3. ❌ **禁止选择「其他物流」**——会导致物流信息不同步，24 小时内揽收超时，平台直接认定**虚假发货**。

**二、原因**

选错物流类型后，闪送的轨迹无法同步到平台，系统判定 24 小时未揽收 → 触发**虚假发货**认定。虚假发货是平台重处罚项（扣分 / 罚款 / 商品降权），一次操作失误的代价远高于多看一眼选项。

**三、执行职责**

1. **凌晨**：监督执行，发现选错物流当场纠正；造成虚假发货认定的报阿祥。
2. **月阳 / 珊珊 / 月月 + 各店客服**：手动添加闪送物流时严格按本规则操作。
3. **阳阳 / 鹤子 / 舒怡（三方发货手动接单顺位）**：三方发货 / 同城单手动录单时同样按本规则操作。
4. **各店运营专员**：本店手动发货操作的日常监督。

**四、来源**

2026-06-10 内部群 @所有人 通知，阿祥转发并要求入规则、知会销售。

## 【祥新公司规则】客服-012 商品成本自查：总仓库存查询，卖过就能查

- **生效日期**：2026-06-12
- **发布人**：邹祥书
- **适用范围**：全体销售客服 + 全体运营专员

**一、规则**

1. 吉客云「总仓库存查询」里，**只要卖过的商品都能查到成本**——当前没有库存（库存为 0）的也能查到。卖过的商品基本覆盖了常用商品。
2. 需要商品成本（核价、报价底线、调价、活动核算）时，**先自己去总仓库存查询里查**，不用先问采购/财务。
3. 查不到的（从未卖过的全新商品）再找采购/供应商确认。
4. **同一商品有多个报价/成本时，对客报价尽量参考贵的那个做基准**——便宜的可能是活动价、套餐价，不能保证随时都有；按低价报出去，到时拿不到货价就兑现不了，甚至亏钱。
5. 成本是内部数据，仅供内部参考，**禁止以任何形式透露给客户**（口径同客服-003：对客不讲利润、不讲库存）。

**二、原因**

成本数据系统里现成可查，遇到就问采购/财务是重复沟通，自查更快、不卡单。很多人误以为"没库存就查不到"，实际只要卖过就有成本记录。多报价取贵是为了报价稳：活动/套餐低价是临时的，按它报价等于把临时优惠当成了长期底价。

**三、执行职责**

1. **凌晨 / 珊珊 / 月阳 / 月月 + 各店客服**：需要成本时先自查总仓库存查询。
2. **运营专员（嘉欣 / 荔枝 / 娜娜 / 鹤子 / 洪洪 / 老孙）**：调价、活动核价同样先自查。
3. **凌晨**：销售侧落地监督，发现还在"先问采购"的当场提醒自查。

**四、来源**

## 【祥新公司规则】客服-013 跨店铺引流订单业绩归属：归引流店铺，成交必须备注来源

- **生效日期**：2026-06-12
- **发布人**：邹祥书

# 第三部分 · 销售实战方法

> 沉淀公司销售实战中已验证有效的话术与方法，作为客服销售日常聊天的对照标准。持续补充，效果好的新方法随时往里加。
> 适用：客服销售团队（凌晨、珊珊、月阳、月月）｜负责：销售主管 凌晨｜来源：月阳聊天案例复盘 + 销售主管总结

## 一、销售方法

### 方法一：先拒绝 + 马上哄

**触发场景**：顾客持续砍价、提无理要求，把客服聊烦。

1. **先拒绝**：直接否定，立场说清楚，不要含糊。
2. **马上哄**：拒绝后几秒内，下一句立刻反过来哄顾客开心。

借"拒绝 → 哄"的转折表达立场，同时让顾客共情，不至于把客户聊跑。

### 方法二：拉扯（第三方证据）

**触发场景**：顾客质疑真伪、授权、货源。

避免口头自证（"我们就是正品""您放心"这类没用），改用第三方证据"拉扯"：
- 老板本人 / 老板朋友圈截图
- 供应商聊天截图、品牌授权书
- 海关、物流、报关凭证

让证据替自己说话，比客服自己嘴硬有效得多。销售主管凌晨用这套打法效果较好，可作为参考。

### 方法三：促单（战报制造紧迫感）

**触发场景**：顾客已心动但成交犹豫，卡在最后一步。

发以下素材制造紧迫感：
- 同款近期成交截图
- 全店当日 / 本周销售战报
- 库存紧张提示

用真实成交数据触发"再不下手就没了"的冲动，促成下单。

### 方法四：给肯定答案，不用模糊词

**触发场景**：顾客咨询产品适配、效果、正品、售后等问题。

回答必须明确、肯定，不要用"似乎""也许""应该可以""大概"这类模糊词。模糊的表达会让顾客犹豫，最后放弃下单。把话说死、给确定结论，顾客才有安全感、敢买。

## 二、使用规范

1. 三个方法**根据顾客状态选用**，不要单点硬上。
2. 战报、截图等素材**必须真实**，不得编造或拼接。
3. 客户隐私（姓名、手机号、地址、订单号）发战报前**必须打码**。
4. 效果好的话术、聊天案例**回贴到销售群**，团队复用。
5. 拿不准的场景，先问销售主管凌晨；凌晨也定不了的，直接找阿祥。遇事不决就往上找，问题必须有人接，不能卡住、不了了之。

## 【祥新公司规则】客服-017 成品杆折算杆头价（整杆价−200）

- **生效日期**：2026-10-30
- **发布人**：邹祥书
- **适用范围**：销售 / 客服销售报价、谈价、拆价说明（成品杆场景）

**一、规则**
1. 成品杆算「杆头价」时：`杆头价 = 整杆价 − 200`（杆身 150 + 握把 50，固定合计）。
2. 不按实际杆身/握把进货价逐笔变动（除非阿祥另行修订标准）。
3. 单独卖杆头 / 杆身 / 握把不适用本折算。

**二、权威文档**

- 成品杆折算标准（2026-10-30）：杆头价 = 整杆价 − 200（杆身 150 + 握把 50）
