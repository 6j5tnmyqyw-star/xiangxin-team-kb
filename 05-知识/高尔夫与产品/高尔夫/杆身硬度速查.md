# 杆身硬度速查

## 一句话定义

按**下场杆数**（反映挥杆速度）匹配杆身硬度 + 材质——这是球杆配置最基础的对照表。

## 关键信息

### 杆数 → 杆身对照

| 下场杆数 | 推荐杆身 |
|---|---|
| 110 杆以上 | 碳素 R |
| 110 - 100 杆 | 碳素 SR |
| 100 - 90 杆 | 碳素 S |
| 90 - 80 杆 | 钢杆身 R |
| 80 - 70 杆 | 钢杆身 S |

### 怎么用

- **新手 / 慢挥杆速度** → 碳素 R/SR：轻、好挥、容错高
- **稳定球友** → 碳素 S 是个甜区
- **打稳到 90 内** → 可以考虑换钢身追求操控性
- **职业水平（70 杆）** → 钢 S，纯靠力量出距离

### 注意
- 杆数只是**代理指标**——真正决定的是挥杆速度
- 不确定就用挥杆速度仪测一次，比看杆数准
- 钢杆身重、振动反馈强，不适合手腕/肩有伤的球友
