# 高尔夫与产品

原 `03-品牌产品库` 整树放在这里：商品档案和选购知识不好拆开，按团队骨架先放进知识栏。档案之间的链接已改到本路径。

## 放什么

| 位置 | 内容 |
|---|---|
| `产品档案/` | 按品牌的商品档案（属性、SKU、卖点、客服可怎么说） |
| `产品档案/00-产品档案总览.md` | 总索引 |
| `产品档案/00-品类导购/` | 跨品牌怎么选（球、铁杆、测距仪、手表等） |
| `高尔夫/` | 测距仪、GPS、球杆等短文 |
| `VESSEL/` | 球包笔记 |

## 不放什么

- 拿货价、成本、批发折扣档
- 客户姓名和订单号
- 只属于某一家店后台、且含隐私的导出表

比价以天猫为准。页面标价不是成交价。
