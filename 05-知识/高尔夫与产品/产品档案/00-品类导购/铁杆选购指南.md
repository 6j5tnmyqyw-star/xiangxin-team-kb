# 铁杆选购指南

> [!tip] 一句话怎么选
> 铁杆的核心决策逻辑是**差点 × 风格**：高差点（>18）选容错大杆头（空腔背/中空结构）；中差点（9-18）选容错与手感兼顾的进阶款；低差点（<9）选刀背或半刀背锻造；送礼/颜值型则优先一刀雕/MAJESTY/ZODIA高端定制系。女士首选轻量碳杆版，左手需单独确认库存。

## 客服答疑要点

1. **杆身硬度怎么选**：挥速<85mph建议R；85-95mph建议R或SR；>95mph建议S。女士统一L。无法判断时问：平时7号铁能打多远？100码以下选R，110-130选SR，130+选S。

2. **钢杆身 vs 碳杆身**：钢杆更重（90-105g），手感直接稳定，适合有一定力量的球手；碳杆更轻（40-65g），出球更高，适合挥速慢或女士球手。两种材质同款型存在同价位选择的要主动提醒客户。

3. **刀背 vs 凹背（容错型）**：刀背（MB）杆头小、操控精准，适合差点<8的球手；凹背（CB/Cavity）甜蜜区大、容错高，差点>12优选。中间态是半刀背（Muscleback / Progressive）。⚠️ 切勿把"刀背外形"卖给高差点客户。

4. **定制产品不可退换**：MIURA / ZODIA / ITOBORI / Roddio / FOURTEEN 等需注明"定制球杆下订后不支持退换货"，下单前必须确认颜色、杆号范围、杆身硬度。

5. **BOLUX T05 铁杆与其他BOLUX商品混淆**：T05铁杆是单独铁杆组（TSV内4条）；BOLUX CB套杆（itemId 867983911514）是包含木杆的整套套杆，两者价差大，客服需区分。
