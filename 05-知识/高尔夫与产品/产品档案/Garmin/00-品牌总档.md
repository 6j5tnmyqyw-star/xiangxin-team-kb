## 导购要点

### 按预算与应用场景分类

**¥3000~10000 级：刚入门 / 小白升级**

| 推荐 | 场景 | 核心卖点 |
|---|---|---|
| **S70 手表**（¥8880） | 初学者要全能 | 43000+ 球场 + 小屏便携 + 健康监测 + 性价比最优 |
| **Z30 激光**（¥8800） | 不想带手表、要精准 | 激光秒锁旗杆 + 坡度补偿 + 果岭视图 |
| **G82 GPS 雷达**（¥8800） | 练习场常客 | 球道图完整 + 推杆训练 + 续航翔实 |
| **Venu X1**（¥9980） | 跨运动玩家 | 大屏 AMOLED + 100+ 运动模式 + 高尔夫模块 |

**¥15000+ 级：职业 / 高端玩家 / 装备投资**

| 推荐 | 场景 | 核心卖点 |
|---|---|---|
| **S50 旗舰**（¥19880） | 对标专业球手 | 全功能最完整 + 库存充足 + 稳定性最好 |

### 核心产品线分水

**① GPS 高尔夫手表分线**

- **Approach 系列**（S70/S50）：高尔夫专用 → 球场导航、坡度补偿、进阶功能完整  
- **Venu/Fenix 系列**：多运动+高尔夫 → 健身、户外、生活全覆盖，高尔夫只是附加模块  
- **MARQ2 Golfer**：时尚高端表 → 品质感+社交展示，高尔夫是内核功能

**② 手表尺寸差异**

- **S70 双尺寸**（47mm/42mm）：男女通用，库存最充足（5700+ 支）→ **主销售线**  
- **S50 单尺寸**（43mm）：库存 715，相对保守  
- **Venu X1**（大屏）：196 库存，小众但专业

**③ 测距工具分层**

- **激光 Z30**：精准±1yard → 职业优选，库存 288 稳定  
- **GPS 雷达 G82**：球道图 + 推杆训练 → 练习场主力，库存 707 最充足  
- **R50 模拟器**：终极数据分析 → 高端投资品，库存 398 保持定量

### 库存热度排序

1. **S70 手表**（库存 5702）→ **绝对主销售，月销量最高**  
2. **G82 雷达**（库存 707）→ **练习场爆款**  
3. **S50 旗舰**（库存 715）→ **高端客群稳定供应**  
4. **Z30 激光**（库存 288）→ **精准需求，中等热度**  
5. **Venu X1**（库存 196）→ **小众多运动客群**  
6. **R50 模拟器**（库存 398）→ **高端定制客户**  
7. **MARQ2 Golfer**（库存 30）→ **礼品/收藏，库存紧张**  
8. **Fenix 8**（库存 33）→ **户外爱好者，库存紧张**  
9. **CT10 传感器**（库存 38）→ **配件级，低流量**

### 客户心理洞察

- **初学者**：看"43000+ 球场"就心动 → S70 性价比无敌，¥8880 一次搞定  
- **练习场常客**：要"球道图完整+续航长" → G82 比激光更实用（不用每球瞄准）  
- **职业/高端**：要"最全功能+稳定性" → S50 库存最充足，是安心之选  
- **社交优先**：看"绿水鬼钛合金" → MARQ2 是装备秀、礼物首选

## 客服注意

**SKU 易拍错汇总**

- **S70 四个不同链接**：  
  - 标准版 ¥8880（商品 ID: 720453767104）  
  - 标准版 ¥9980（商品 ID: 1020578100073 / 969267907165）  
  - 礼盒版（含 CT1 球标+表带）特价版  
  **价格差 ¥1100，需确认客户是否送礼 / 需要 CT1**  
  → 库存最充足的 ¥8880 版本为主销售

- **Venu 2 Series 清仓**：  
  标价 ¥2980，**库存已为 0**（停产清仓品）  
  → 虽标价便宜，但**无货，勿推**

**产品线分水协议**

在推荐前，一定确认客户的**核心需求**：

| 如果客户说 | 推荐 |
|---|---|
| "我要用来计分和导航" | S70（¥8880），最均衡 |
| "我还要运动手环功能" | Venu X1（¥9980），多运动模块 |
| "我要最精准的数据" | Z30 激光（¥8800）或 G82 雷达（¥8800） |
| "我是职业/高手，要全功能" | S50（¥19880），最完整 |
| "我要大屏，怕看不清" | Venu X1（¥9980）或 Fenix 8（¥19499） |
| "送人、要高档感" | MARQ2 Golfer（¥32550），唯一选择 |
| "室内练习+数据追踪" | R50（¥88000），终极投资 |

**库存不足预警**

- **MARQ2 Golfer**（库存 30）→ 高价高端，建议 VIP 预约制  
- **Fenix 8**（库存 33）→ 小众户外，可能缺货  
- **CT10 传感器**（库存 38）→ 配件线，常被 S70 客户追问，库存偏低

**限量/特殊协议**

- **MARQ2 绿水鬼**："绿水鬼"是限定配色，¥32550 属于品牌顶阶 → 告知库存真实，避免后期缺货纠纷  
- **Fenix 8**：户外多功能定位相对小众 → 不要盲推，确认客户户外需求再销售

**价格异常预警**

- 所有商品标价看起来正常，无明显错标  
- 唯一例外：Venu 2 清仓版 ¥2980（已无货）→ 建议隐藏链接

**待人工补充**

- **S70 四链接统一**：建议在飞书任务建立"S70 商品链接对照表"，标注 CT1 赠送差异  
- **CT10 传感器**：档案仅有一条，缺少"16 支全套配置说明"  
- **各手表尺寸（47/42）差异**：S70/S50 均有双/单尺寸，需补充"男女推荐尺寸指南"  
- **与店铺其他品牌（Bushnell 测距仪）的对标说明**：待补充"Bushnell vs Garmin 精准度对比"
