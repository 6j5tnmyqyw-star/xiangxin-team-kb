## 产品知识

**一句话定位**：FastDeer 激光彩屏测距仪，触控屏操作、紫外线提醒、雨雾天模式、内外双彩屏，球场望远镜级性能。

**核心卖点**
- 触摸彩屏操作，支持自动亮度调节（内屏可根据球场光线自动调节）
- 紫外线提醒创新功能，实时显示 UV 强度等级（0-10 分级，分为弱/较弱/中等/强/极强）
- 雨雾天模式解决传统测距仪在大雾天和大雨天不能正常测量的问题
- 高精度 ADC 方案，透光率高达 92%，消除杂光、测量更精准反应更灵敏
- 小巧精致，头层小牛皮机身 + 航空铝 CNC 工艺，仅重 155g
- 坡度补偿精准测距，例：直线 158Y 补偿后 130Y
- 扫描模式便于远距离小旗杆抓取
- 伙伴（球童）模式无需走近可远距离协助测量
- 定制皮包可定制，卡扣设计 + 磁吸盖头

**关键参数**
- 测距精度：±1 码
- 放大倍数：6 倍
- 体积：10.01×6.38×3.85cm
- 目标锁定：振动反馈 + 绿色旗杆图标 + 绿色圆圈图标
- 测量距离：800 码
- 持续工作时间：10,000 次测量（满电）
- 触摸屏：LCD
- 测距单位：米数 / 码数可切换
- 电池类型：锂电池，DC5V 0.5A Type-C 接口

**使用与注意**
- 光线传感器和紫外线传感器自动感应环境
- 红绿双显功能配合自动亮度调节，晴天和阴天均可自动调整屏幕亮度
- 先测量自己到旗杆距离（A），再测到伙伴距离（B），系统自动显示伙伴到旗杆距离（C）
