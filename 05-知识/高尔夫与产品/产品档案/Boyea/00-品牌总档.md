## 导购要点

**1. 产品线分层清晰**

- **¥2100~3300 级**：轻便/二轮/实用款  
  → B-009（二轮）、B-936（时尚双拼）、伸缩球包通用款  
  → 适合初学 + 追求经济实惠的客户

- **¥4500~6000 级**：防水+防护+伸缩全套  
  → B-946（硬壳）、B-951（磨砂透明）、升级航空包、支架包  
  → 适合职业玩家 + 追求耐用防护的客户

- **¥3980 级**：手推车专线  
  → 360 度灵活转向，配座椅 + GPS/雨伞插位  
  → 适合常驻练习场的中高端客户

**2. 核心卖点与差异**

- **免费刺绣**：绝大多数款都支持，是低价差异化手段  
- **万向四轮**：几乎所有伸缩款标配，强调"灵活转向+前轮刹车"  
- **防水等级**：从"防泼水"→"皮膜防水"→"高透 TPU"→"防水硬壳"递进  
- **伸缩/收纳**：新款都是"一体式头框+伸缩"，对标专业航空托运

**3. 库存热销排序**

1. **标准航空伸缩款**（¥5980，库存 990+）→ **主销售线**  
2. **骷髅支架包**（¥5980，库存 597）→ **潮款、新客首选**  
3. **硬壳 B-946**（¥3280，库存 300）→ **防护首选、高容量**  
4. **手推车**（¥3980，库存 147）→ **配件生意、场地客户**  
5. **时尚双拼 B-936**（¥3180，库存 250）→ **性价比款**

**4. 客户心理洞察**

- 买球包的客户多是已有基础、要投资大装备的人 → 会关注防水、耐用、样子  
- 看到"免费刺绣"会加分 → 体现个性化、送礼感  
- 看到"含外套+密码锁"会觉得值 → 完整套装感  
- 手推车是"一次投资，多年使用"的长尾产品 → 不用经常补

## 客服注意

**SKU 易拍错汇总**

- **航空伸缩球包链接过多**：同价 ¥5980，库存 990 和 197、891 的有三个不同链接  
  → 库存 990 的是**主推链接**，其他可能是历史版本  
  → 确认前拉商品 ID（975563574528 vs 932974915915 vs 975555866487）

- **多色可选但图片易混**：  
  - 冰紫/蒂芙尼/孔雀绿 ¥2076  
  - 多色磨砂透明款 ¥4499~5980  
  → 客户常要求看全色，需提醒天猫详情页有色卡

**价格异常**  
- 所有商品标价看起来正常，无明显错标

**库存不足预警**

- B-946 硬壳款：库存 300（相对紧张）  
- B-009 二轮款：库存仅 100 → 缺货风险中等  
- B-951 磨砂款：库存 43 → 建议保留作为展品/小批货源

**免费刺绣细则**

- 绝大多数球包支持刺绣名字/队名 → **但要确认客户是否想要**（有人觉得影响卖相）  
- 刺绣一般 7~10 个工作日 → 告知交期
