## 导购要点

**1. 品牌定位：专业轻量 + 美学设计**

- **轻量化专线**：支架包/枪包全系强调"可拆解专利+轻量便携"  
  → 适合注重便携、常去练习场的进阶玩家

- **幻彩透明美学**：白幻彩 2.0 版透明 TPU 是 OMNIX 的设计签名  
  → 适合追求视觉个性化、年轻客户群

- **配件完整线**：从杆套（¥550）→ 枪包（¥5980）→ 标准包（¥9980）→ 航空包（¥1980）  
  → 适合渐进式消费、分次补齐装备的客户

**2. 价位梯度**

- **¥550~1980 级**：高性价比配件线  
  → 杆套（保护基础配件）、航空包（功能性强）、轻量练习包  
  → 新手 + 补齐配件的热销线

- **¥5980~10000 级**：专业支架包主线  
  → 磨砂系列（¥9980）、轻量支架包（¥5980）、幻彩 9 寸包（¥9980）  
  → 中高端客户主销售

**3. 库存与销售热度**

- **轻便枪包**：库存 791（**最充足**，是主销售线）  
- **幻彩透明 9 寸包**：库存 87（中热度，美学优先）  
- **航空包 2.0**：库存 198（功能性强，航旅客户基础）  
- **磨砂支架包**：库存 40~39（库存紧张，高端客群）  
- **杆套系列**：库存 20（配件线，常年稳定）

**4. 产品线与竞品对标**

| 对标维度 | OMNIX 优势 | 适用客群 |
|---|---|---|
| 轻量化 | 可拆解专利 + 8.5 寸超轻 | 练习场常客、追求便携 |
| 美学设计 | 幻彩透明 TPU，年轻时尚 | 社交媒体客户、年轻玩家 |
| 价格 | ¥5980~6000 中段有竞争力 | 实用主义消费者 |
| 配件齐全 | 杆套、伞、航空包一条龙 | 整体装备升级客户 |

## 客服注意

**SKU 易拍错汇总**

- **4 款铁杆套看似一样**：  
  ACIHCSBS / ACIHCSMW / ACIHCSPW / ACIHCSWB，都是 ¥550，都是"10 支通用套装"  
  **差异仅在配色**（黑/银、黑/多色、粉/白、黑/白）  
  → 前置确认客户偏好的配色，拉商品 ID 对照区分

- **磨砂支架包 B 和 C 版本**：  
  都是 ¥9980、都说"8 种配色"、库存分别 40 和 39  
  → 可能是同一款分批次入库 → 确认前可合并销售

**设计卖点说明**

- **可拆解专利**：强调"4 件式可拆组装"，便于收纳和运输  
- **幻彩透明 2.0**：是 OMNIX 独家设计，拍照效果好，适合红书/抖音展示  
- **磨砂质感**：对标高端支架包，触感升级

**库存不足预警**

- 轻量 8.5 寸支架包：库存仅 27 → **建议保留给展示/VIP**  
- 磨砂支架包两款：库存 40~39，中端球包中较稀缺 → 排队制货
