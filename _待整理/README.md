# _待整理

团队待审 Inbox。还没定稿、还没归栏的草稿先放这里，审过再挪到正式栏目。

飞书同栏：https://xiangxingolf.feishu.cn/wiki/LH8xwShseivgVRk6XAecMHQonso

## 放什么

- 待阿祥或主管看过的规则草稿、话术草稿
- 暂时不知道该进哪个栏目的团队材料

## 不放什么

- 已经定稿的正式规则（定稿进 `08-公司知识库/` 或 `03-公司/`）
- 你自己的私人草稿（放本地 `_我的笔记/`，该文件夹不会上传）
- 客户隐私、报价、工资

个人电脑上的 AI 若要默认落盘，优先写你**自己的** vault 里的 `_待整理/`，不要直接往这个公开仓库提交未审文件。
