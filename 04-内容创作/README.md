## 放什么

| 子目录 | 内容 |
|---|---|
| `选题库/` | 公司号选题和每日候选 |
| `文案-短视频/` | 口播 / 短视频稿 |
| `文案-成品/` | 定过稿的文案 |
| `方法论/` | 选题、口播写法 |
| `提示词/` | 内容向提示词 |
| `球杆选购/` | 已随内容树迁来的选购稿；产品参数以 `05-知识/高尔夫与产品/` 为准 |
| `读书改写/` | 改写成公司号内容的材料，不是私人读书笔记 |

规范：[[08-公司知识库/09-内容创作规范]]。

## 不放什么

- 个人号采访逐字稿、未公开的私人影评
- 违禁词稿直接当成品（最高级、第一、国家级、最便宜等）
- 客户隐私、成交价底账
