# 采购·供应商速查（supplier-finder）

> 采购员工的「活字典」：以飞书电子表格《供应商信息汇总》（阳阳维护、随时更新，含主表 + 9 个品牌排名/工坊表 + 固定折扣/网店链接/新同事群聊）为唯一权威源；查谁拿货、按哪家优先、开票税点、联系方式一问即答。

## 一、什么时候用

祥书或采购同事（阳阳、舒怡等）说出以下意图就触发：
- **找货/比价/看优先顺序**：「Garmin 找谁拿」「这个 PING 的杆谁有货」「圈t 调货找谁」「TaylorMade 哪几家优先问」
- **查联系/条件**：「XX 供应商电话多少」「账期是先款后货还是月结」「在哪个工作群」「地址/收货信息」
- **开票**：「XX 能开专票吗」「加几个点」「哪些供应商能开 13% 专票」
- **对公打款**：「给 XX 打公账，银行账号税号发我」
- **巡检/纠错/更新**：「查一下供应商表有没有问题」「同步一下本地供应商表」

**不适用（走别的 skill）**：
- 供应商对账、挂账核对 → `supplier-reconciliation`（库管，传两张表对金额标颜色）
- 吉客云里查某 SKU 的采购单/采购记录 → `jackyun-api`
- 给采购同事派任务 → 飞书任务（注意：带金额的供应商往来**不挂【祥新任务】公共清单**，见铁律 4）

## 三、查询怎么答（标准动作）

1. **优先实时读飞书权威表**（因为阳阳会随时更新）：
   ```bash
   LARK_CLI_NO_PROXY=1 lark-cli sheets +cells-get \
     --spreadsheet-token AxVxsJToYhtDcAtXMEycKiAenFg \
     --sheet-id 0HmTyU --range A1:T266 --as user
   ```
   若查某主流品牌的拿货优先顺序，同步读对应品牌排名表（如 `DPu6Lt` / `hLwRDY` 等）。仅在网络不可用或粗查时退回读本地副本 `03-公司/供应商/00-供应商信息汇总.md` 并注明副本日期。
2. **找货类**：优先按品牌排名表的顺序给出**多家可选供应商**（方便比价），并补齐主表中的**地区、工作群名、税点、发票性质**。
   - ⚠️ 圈t（杆身/握把/工坊调货）问题：看 `KweToB`（工坊类）和主表，**优先推大陆供应商，不优先香港**（铁律 1）。
3. **联系方式/账期/地址/工作群**：读主表 `0HmTyU` 对应整行字段答全。
4. **开票与税点**：核对主表「开票税点」「企业性质」「发票性质」「结算方式(公/私)」。**若发现主表与品牌排名表口径矛盾、对私开专票、缺失税点或重复行，按祥书要求及时汇报异常**！
5. **对公打款**：给出银行/账号/税号（公账信息不是个人隐私，内部可用，严禁外传）。

## 四、更新与维护

- **权威源在飞书电子表格**：新增/修改供应商原则上由阳阳在飞书表 `AxVxsJToYhtDcAtXMEycKiAenFg` 维护；如祥书要求 AI 直接改表，用 `lark-cli sheets +cells-set` 写回前把改动项给祥书确认一次（涉及税点/账期/打款信息尤其要确认）。

- **同步本地副本**：每次大更新后，从 `AxVxsJToYhtDcAtXMEycKiAenFg` 重新导出覆盖 `03-公司/供应商/00-供应商信息汇总.md`（保留其中的「渠道竞品调研记录」和「子目录参考」）。

## 五、铁律

1. **圈t 优先大陆**：调货（询货/工坊/杆身握把）不优先找香港，香港时效不可靠 → 推荐顺序大陆在前。
2. **飞书表是唯一权威、本地只是副本**：随时会更新，重要决策前以实时读取飞书表为准。
3. **多家可比价**：找货默认给出同品牌的多家供应商，不要只丢一家。
4. **带金额的供应商往来不进公共任务清单**：返利/挂账/打款金额只走本地或私聊祥书，不发【祥新任务】（那是团队公共面板）。
5. **对外不外传**：供应商联系方式、报价、对公信息只在内部用，不出现在对外文案/给客户的内容里。
6. **异常必报**：读表发现口径冲突、缺漏或财务风险（如对私开专票），主动报祥书。
