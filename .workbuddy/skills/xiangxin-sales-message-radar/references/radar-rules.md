# 销售每日微信 + 飞书消息雷达 · 判断口径与红线库

> 本文件供 `xiangxin-sales-message-radar` 技能在分析脱敏聊天与飞书消息时加载使用。

---

## 一、两路消息的高权重「防遗漏」信号

### 1. 飞书端（重点盯内部协作卡点，必附跳转链接）
判断「你回没回」的标准：看同一会话/话题链里，该消息之后有没有你本人发言、表情确认或任务闭环；**已经被其他人接走闭环的跳过，别刷屏**。

- 🔴 **必须马上处理**：
  - 在「三方发货群」「售后群」「客服销售工作沟通」或私聊里明确 `@你`、或点你名问货号/单号/客户地址/改价/退换货原因、你还没回；
  - 运营发通知让你核对主图/活动价/下架某款/联系某位已下单客户（如定制确认、延迟发货告知）；
  - 采购在三方群报了你之前问的报价/到货时间，你还没接或还没转告客户；
  - 售后/库房催你确认退货单号、拆包原因、是否同意仅退款；
  - 你自己名下的飞书待办已经干完忘了点「完成」，或今天 18:00/20:00 到期。
- 🟡 **留意**：
  - 群里刚发布的新口径/新规则/新品到货通知（例如某款现货到了、某款涨价/断货了，直接影响你今天报价）；
  - 同事提了跟你店铺或客户有关的事，虽然没 `@你`，但涉及你正在跟的大单。

### 2. 微信端（重点盯「别丢单」和「别忘承诺」）
- 🔴 **漏回 / 失联风险（24–48 小时内）**：
  - 客户最后一条发了问句（问价格、问现货、问尺码/参数、问物流/售后、要你发对比图/链接），而你超过半天没接话；
  - 客户说「等会拍 / 发个收款码 / 帮我查下有没有货」，你答应「我帮你问下」「回头发你」但聊天里后面没有下文；
  - 客户反馈商品瑕疵、发错货、投诉或质疑真伪（高危客诉，优先稳定情绪，必要时立刻同步阿祥/凌晨）。
- 🟡 **今天最值得跟进的商机（近 3–14 天窗口，每天挑 3–5 个最准的）**：
  1. **准成交冷却客**：近 3–14 天明确问过价、问过某款现货、说「考虑一下 / 问问球友 / 等发工资 / 等新款到货」还没下单；
  2. **新客破冰**：刚加微信 3–25 天、只聊了 1–2 句还没成交过第一单（对齐《新客破冰 30 天 SOP》）；
  3. **承诺回访到期**：之前约好「下周联系」「到货通知我」「打完这场球再定」，现在刚好到时间；
  4. **新品/现货精准匹配**：今天公司群里刚到的热销现货（如 S72 新配色、V6S 特价），刚好撞上他之前问过的需求。

## 二、降噪清单（这些一律跳过，不要凑数）

- 纯应答：`收到`、`好的`、`OK`、`嗯嗯`、`谢谢`、`辛苦了`、`1`、`[表情]`、`[动画表情]`、`[语音]`（无文字且非客户刚发未回）
- 群里无关的纯业绩播报流水、纯打卡截图、与自己无关店铺的上下架通知
- 已经由你自己或同事回复闭环的对话
- 早安/晚安/节日群发拜年贴

## 三、销售回复草稿必须遵守的 7 条红线

1. **称呼规范（客服-004）**：一律称呼「**X哥 / X姐 / X总**」或「**球友**」，**严禁出现「亲」「亲亲」「亲爱的」「美女」**。
2. **禁止高压逼单（客服-007）**：**严禁写「今天下单才这个价」「今天不拍就没了」「最后一天错过没了」**；改为客观说明活动截止日、现货数量或温柔提醒。
3. **跨平台红线（客服-006 / 008）**：
   - **抖音**平台绝对禁止主动加微信、发微信号或二维码；
   - 天猫/淘宝/京东/抖音平台订单**严禁私下微信退款或退差价**，必须原平台原路处理。
4. **砍价收口先走「发票台阶」（2026-11-26 新口径）**：
   - 遇到客户砍价或临门收口，草稿里先自然问一句要不要发票；不要票和要票报价一样，对客可顺势给台阶「您不要票，我按这个价给您定」，**绝不说拿货成本、绝不提税点、绝不报含票/不含票两套价**。
5. **不编参数与库存**：不知道的型号参数先查 `团队知识库/03-品牌产品库/产品档案/`；不知道现货先查采购/三方群；草稿里价格/赠品/发货日用 `【核实后填入】` 占位，不替销售乱拍底价。
6. **真人文风**：微信草稿每次 1–2 句短话即可，不要写 200 字长篇大论。
7. **人名状态核对**：
   - 销售组在职 4 人：**凌晨**（朱凌晨）、**珊珊**（王珊）、**月阳**（王月阳）、**月月**（兰月）。
   - **已离职（绝不抄送/绝不派活）**：**洪洪**（洪丽华）、**邹国瑜**、**阿娟**（李秀娟）。

## 四、数据防呆与零连接器兜底

- **空值不是零**：
  - 微信导出文件夹为空，或最新消息日期早于昨天 → **必须提示「未同步，数据停在 YYYY-MM-DD」**，绝不能汇报「微信零遗漏」。
  - 飞书拉到 0 条消息 → 先查 `lark-cli auth status` 是否掉登录或时间窗不对，绝不直接说「飞书今天没消息」。
- **零连接器兜底**：
  - 没配好 `lark-cli` 时，脚本加 `--no-feishu` 照样跑完微信端；销售也可以直接把飞书截图或脱敏文字粘进对话框一起扫描。
  - 手机微信还没来得及整库导出时，销售可以把近期几个重点客户聊天**打码真名/手机号后**粘贴或截图进来，AI 一样按🔴/🟡/🟢输出待跟进清单和草稿。
