# 销售每日微信 + 飞书消息雷达（同步前置 · 防遗漏 · 抓跟进）

> **为什么先同步再扫**：销售平时常用手机回微信，还有的同事有两个微信号。如果手机微信没导到电脑、或者 `lark-cli` 没登录，AI 扫出来的就是旧记录，不仅会漏掉刚问价的大单，还会把“你手机上已经回过的客户”误报成漏回。
>
> **定位**：每天花 1–2 分钟，帮销售把**微信 + 飞书**两边的漏回消息和成交机会捞出来，**只出草稿、只放本机、不查岗、不自动外发**。

---

## 一、开工 5 条铁律（违反一条都不许继续）

1. **没同步不硬扫、不编「零遗漏」**：
   - 运行预处理脚本检查微信最近一条消息日期。如果目录为空或最新消息早于昨天，必须把状态标成 `⚠️ 微信未同步（最新停在 YYYY-MM-DD）`，先给同步步骤，**严禁报“微信没有漏回”**。
2. **🔴 客户隐私先在本地脚本洗干净再喂 AI**：
   - **绝对禁止**直接把含客户真实姓名、11 位手机号、微信号、精确收货地址、长订单号的微信原件拖进对话或上传云盘。
   - **绝对禁止**读取 `_私密-客户档案/本人自查原版-勿喂AI/` 目录。
   - 必须先跑本地脚本 `scripts/prepare_radar.py`，由 Python 正则剥离敏感字段、替换成 `SS-XXXX / LC-XXXX / YY-XXXX / MY-XXXX / WX-XXX` 代号，AI 只读脱敏结果。
3. **只出草稿，绝不代发**：
   - 所有微信开场白、飞书回复都是**可复制草稿**，由销售本人确认价格、库存和平台规则后再发。
4. **飞书条目必须带跳转链接**：
   - 飞书群聊/私聊扫出的每一条遗漏，必须附原消息 `message_app_link`（点一下直接跳回那条聊天），不让销售满世界翻群。
5. **结果只留本机，不进团队库**：
   - 扫描报告只存本机 `_私密-客户档案/每日消息雷达/YYYY-MM-DD.md`（或 `_我的笔记/`），严禁放进 `团队知识库/`、共享云盘或 GitHub。

## 二、标准执行流程（4 步跑通）

### 第 1 步：同步团队库 & 检查双端聊天同步状态

1. 若工作区有 `./团队知识库/`，先同步最新规则和话术（二选一）：
   ```bash
   lark-cli drive +pull --folder-token H6r9fnWASlUgFXdju68csErLnXc --local-dir ./团队知识库 --if-exists smart --as user
   # 或 GitHub 路线：cd ./团队知识库 && git pull --ff-only
   ```
2. 运行本技能预处理脚本（Windows / macOS 通用，纯标准库 Python）：
   ```bash
   python3 "<本技能目录>/scripts/prepare_radar.py" --workspace . --days 2 --followup-days 14
   ```
   - 默认参数：`--days 2`（查昨天 + 今天防漏回），`--followup-days 14`（捞近 14 天问价/考虑中的跟进商机）。
   - 如果销售把微信记录放在指定文件夹，追加 `--wechat-dir "<路径>"`。
   - 脚本会自动完成：
     - 检测 `团队知识库/` 与本地 `_私密-客户档案/` 路径；
     - 探测并解析微信导出文件，检查最新消息时间戳（输出 `ok` / `stale` / `missing`）；
     - 本地正则脱敏 + 降噪，自检 `0 手机号 / 0 长单号`，写入 `_私密-客户档案/微信聊天脱敏版/daily_scan_YYYY-MM-DD.md`；
     - 用 `lark-cli auth status` 确认登录态，拉取昨天 00:00 至今全部可见飞书群聊 + 私聊（含 `message_app_link`）及本人未完待办，脱敏后写入 `_私密-客户档案/飞书消息缓存/feishu_scan_YYYY-MM-DD.md`。

> **零连接器 / 未导出兜底（绝不卡死）**：
> - 如果 `lark-cli` 未登录：提示运行 `lark-cli auth login`（需用本人飞书账号扫码），同时先用 `--no-feishu` 跑完微信部分；
> - 如果微信尚未从手机导出到电脑：按第 2.5 节引导同步；若销售手头只有几段急着看的聊天，也可让她**把真名/手机号打码后**直接粘进对话或截图，AI 按同款规则直接出判断和草稿。

### 第 2 步：若微信/飞书任一端未同步，先暂停提醒（卡点说明）

查看脚本输出的 JSON/摘要状态：
- **微信状态 = `missing` 或 `stale`（最新记录早于昨天）**：
  - 报告顶部标红提示：「⚠️ **微信记录未同步到最新（最新停在 YYYY-MM-DD），以下仅覆盖已同步部分 / 暂缺微信**」。
  - 附上 30 秒同步步骤（不讲废话）：
    1. 打开**手机微信 → 我 → 设置 → 通用 → 聊天记录管理 → 导入与导出 → 导出到电脑**（或使用电脑端微信备份/导出功能）；
    2. 导出期间**手机保持亮屏在前台，不要锁屏、不要切出微信**（防止中断）；若有工作/个人两个微信号，两个都导；
    3. 导完把记录放到本地目录（默认 `_私密-客户档案/微信聊天原件-勿直接喂AI/` 或个人 Obsidian 微信目录），再对我说「**重新扫一遍**」。

### 第 3 步：读取规则 + 脱敏数据，做双路分析

按顺序读取（**严禁读取 `本人自查原版-勿喂AI/`**）：
1. 本技能 `references/radar-rules.md`（高权重信号、降噪清单、销售红线、离职人黑名单、称呼与「发票台阶」）；
2. 脚本生成的 `_私密-客户档案/微信聊天脱敏版/daily_scan_YYYY-MM-DD.md`（若微信有数据）；
3. 脚本生成的 `_私密-客户档案/飞书消息缓存/feishu_scan_YYYY-MM-DD.md`（若飞书有数据）；
4. 若存在 `_私密-客户档案/AI可读脱敏版/00-索引.md`，对照已知客户分层（高价值/沉睡/历史买过什么）提升跟进精准度；
5. 若存在 `团队知识库/01-部门规则/06-销售客服规则.md` 或 `.workbuddy/skills/lingchen-sales-coach/`，对齐话术口径（男哥女姐、禁「亲」「今天下单」、砍价先走「发票台阶」、不编型号参数）。

### 第 4 步：输出「每日消息雷达清单」并存本机

严格按以下 4 块输出（手机/电脑 1 分钟扫完，宁缺毋滥），并保存到 `_私密-客户档案/每日消息雷达/YYYY-MM-DD.md`（若无 `_私密-客户档案/` 则存 `_我的笔记/每日消息雷达-YYYY-MM-DD.md`）：

```markdown
# 📡 每日微信 + 飞书消息雷达（YYYY-MM-DD · 早/晚班）

## 同步体检（先看这里）
- **微信聊天**：✅ 已同步至 YYYY-MM-DD HH:MM（扫了 N 位客户会话）/ ⚠️ 未同步（停在 ...）
- **飞书聊天**：✅ 已拉取近 X 天（群 M 条 / 私聊 K 条，@我 J 条）/ ⚠️ 未登录
- **团队知识库**：✅ 已同步 / ⚠️ 建议先 pull

---

## 🔴 一、必须马上处理（漏回 / 急单 / 售后）
> 飞书：点链接直达原消息；微信：按客户代号去微信/自查表一秒找人。

1. **【飞书·群名或私聊·发件人】** 一句话说清什么事、对方在等什么 — [打开原消息](message_app_link)
   - 👉 建议动作 / 回复草稿：「...」
2. **【微信·代号（如 SS-0123 / WX-005）】** 上次聊到哪 + 还没回的点（时间）
   - 👉 短句回复草稿（1–2 句，真人打字口吻）：「...」
3. **【飞书待办】** 已做完但忘了点完成 / 今天到期的任务名

*(没有就写「无」；🔴 档控制精炼，只放真会丢单/出事的)*

---

## 🟡 二、今天最值得跟进的 3–5 个成交机会
> 从近 14 天微信对话捞出：问价未拍 / 等补货 / 说考虑一下 / 新客未破冰 / 承诺回访到期。

1. **【代号】** 意向商品与卡点（1 句话）｜距上次沟通 X 天
   - 👉 自然开场白草稿（不用「亲」，不逼单）：「...」

---

## 🟢 三、顺手沉淀（最多 1–2 条，不加负）
- **好话术候选**：昨晚/今天某段回复效果不错，可记进进化本或说「回传总库」
- **需求/问题反馈**：客户反复问但缺货的款，或系统口径冲突（需要登记纠错日志说一声「登记这个问题」）
```

## 三、建议日常节奏（跟公司排班对齐）

- **每天跑 2 次**（阿祥与珊珊定的销售日常节拍）：
  - **早班**：午饭前 1 次 + 下班前 1 次；
  - **晚班**：按自己排班时间跑 2 次。
- **每周五顺手做 1 次脱敏需求汇总**：
  - 让 AI 基于本周 `_私密-客户档案/微信聊天脱敏版/` 生成**绝对不含客户代号/姓名/手机号**的《本周一线需求与难题汇总.md》（缺货款 + 同行价 + 难答专业题），传到自己的私有云盘 `01-<花名>上传` 给阿祥补子弹。
- **关于自动定时**：
  - 本技能本身是手动触发/WorkBuddy 内配置定时；**如果当前电脑没有真正配置系统定时调度，绝不嘴上说“已经每天自动跑了”**，只说明每天点开说一句「扫一下今天的微信和飞书消息」即可，或引导在 WorkBuddy 设置每日两次定时任务。
