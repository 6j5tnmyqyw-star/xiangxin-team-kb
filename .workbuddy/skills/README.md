# 公司技能包（随库自带 · WorkBuddy）

这个文件夹里是公司给大家配的 AI 技能。**只要用 WorkBuddy 打开本团队知识库（工作区选库的根目录），技能自动生效**，不用单独安装；每次同步自动拿到最新版。

## 技能怎么被读到

WorkBuddy 认两个目录，**同名时项目级优先**：

| 级别 | 路径 | 什么时候用 |
|---|---|---|
| 项目级 | `{工作区}/.workbuddy/skills/` | 本库用的就是这个，跟着库走，同事同步就带上 |
| 用户级 | `~/.workbuddy/skills/` | 所有项目通用，你想在别的文件夹也能用时放这里 |

目录名必须和 `SKILL.md` 里的 `name:` 一致，`name` 只能用小写字母、数字、连字符。

## 怎么用

不用记命令，直接说人话：

- 「帮我起草这条询单的回复」「这个售后怎么回」
- 「查一下 V6S 的售后单」「这个货找谁拿」
- 「把这篇文案去去 AI 味」「做个选题」
- 「帮我对账」「核对挂账」
- 「建个任务：XXX，派给 YYY，周五 18:00 截止」

技能描述对得上就会自动加载。

## 前置条件

- **飞书类**（发消息、建任务、查文档）→ 需要 `lark-cli` 并登录自己的飞书账号
- **浏览器类**（淘宝比价、店铺上新、千牛聊天抓取、短视频发布）→ 需要 `browser-harness` + 一个登录着的 Chrome
- **对账、库存周报这类要跑脚本的** → 需要本机有 `python3`，按技能里写的依赖装（一般是 `pandas`、`openpyxl`）
