# PPT（.pptx）成品精工手册

> 提炼自 Anthropic 官方 `pptx` 技能。核心原则：**每页只讲一件事，有视觉锚点，去 AI 模板味，跑完 XSD 校验和转图 QA 再交付。**

## 一、路线选择

- **新建演示文稿**：首选 `pptxgenjs`（Node，若缺再 `npm install pptxgenjs`），或 `python-pptx`。
- **套公司/品牌现有模板修改**：解包 ZIP → 先用 `scripts/slide_text.py` 读全文 → 按结构改 `ppt/slides/slideN.xml` → 重新打包 → 跑 `scripts/office/validate.py out.pptx --original src.pptx`。
  - ⚠️ **结构改动（增/删/调序）必须在改文字前做完**；XML 编辑用 `defusedxml.minidom`，不要用 `xml.etree.ElementTree`（会改写命名空间前缀损坏文件）。

---

## 二、`pptxgenjs` 避坑清单（踩中就会损坏文件或排版错乱）

1. **先设画布尺寸**：默认 `LAYOUT_16x9` 是 `10" × 5.625"`（不是 13.3"），超出画布的元素会被直接裁掉。
2. **颜色 Hex 严禁带 `#`、严禁 8 位**：写 `"1E2761"`，不要写 `"#1E2761"` 或 `"00000020"`（直接损坏文件！）。透明度用 `transparency: 0-100`（填充/图）或 `opacity: 0-1`（阴影）。
3. **不要复用同一个样式/阴影对象**：`pptxgenjs` 会原地把数值改成 EMU，每次调用 `add*` 必须新建对象。
4. **阴影 `offset` 必须 ≥ 0**：负值损坏文件；向上投影用 `angle: 270` 配正值。
5. **列表用 `bullet: true`，绝不手打 `•`**（否则出双圆点）；数组里除最后一项外都要 `breakLine: true`。
6. **堆叠柱状图 `dataLabelPosition` 只能用 `ctr` / `inEnd` / `inBase`**，`outEnd` 会导致 PowerPoint 报错损坏。
7. **双轴组合图必须同时声明两套 `valAxes` 和 `catAxes`**，少一套 PowerPoint 直接丢掉整张图。
8. **`addText` 非占位符文本框加 `isTextBox: true`**；需要和图形精确对齐时设 `margin: 0` 去掉默认内边距。
9. **每个输出文件新建一个 `new pptxgen()`**，别复用实例。

## 三、视觉设计与去 AI 味红线

### 配色原则
- **主色占 60–70% 视觉权重** + 1–2 个辅色 + 1 个点睛强调色，别平均分配颜色。
- **三明治明暗节奏**：封面和封底用深色背景，正文页用白底（`FFFFFF`）或极浅灰，不要默认浅米色/奶油底（`F5F5DC`/`FAF0E6`）。
- 推荐配色参考：深海藏青（`1E2761` + `CADCFC` + `FFFFFF`）、森林高尔夫绿（`2C5F2D` + `97BC62` + `F5F5F5`，极适合高尔夫主题！）、炭灰极简（`36454F` + `F2F2F2` + `212121`）、青绿信任（`028090` + `00A896` + `02C39A`）。

### 明确禁止的「AI 廉价味」写法
- ❌ **绝不在标题下面画细横线（accent line）**
- ❌ **绝不画装饰性色条/侧边竖条（header/footer color bar、卡片左侧单边彩条）**——区分卡片用浅色底、轻阴影或图标，不要贴彩条
- ❌ **绝不连续多页重复同一种版式**（两栏、大数字指标卡、2×2 网格、对比栏、流程图轮换着用）
- ❌ **绝不做纯文字白底项目符号页**——每页至少一个视觉元素（图表/核心大数字/图标/实拍图）
- ❌ **正文不居中对齐**（正文一律左对齐，只有封面/过场页标题可居中）
- ❌ **字号不低于底线**：标题 `36–44pt` 粗体、小节 `20–24pt`、正文 `14–16pt`（不小于 14pt）、注释 `10–12pt`；页边距 ≥ `0.5"`，模块间距 `0.3–0.5"`。
- ❌ **安全字体**：英文用 Arial / Calibri / Cambria，中文用微软雅黑 / 苹方 / 思源黑体（不用生僻字体，防跨电脑字宽漂移导致溢出）。

## 四、三道验收（缺一不可）

1. **内容查漏**：`python3 scripts/slide_text.py output.pptx`（检查有无残留 `TODO`、`XXX`、`[待填]`）。
2. **结构校验**：`python3 scripts/office/validate.py output.pptx`（改模板时必加 `--original src.pptx`）。
3. **视觉转图检查**：转 PDF 后 `pdftoppm -jpeg -r 150 output.pdf slide`，逐页看 5 件事：**文字是否溢出文本框 / 元素是否重叠 / 页脚是否撞正文 / 同类页标题高度是否一致 / 数字和单位有没有被拆成两行**。
